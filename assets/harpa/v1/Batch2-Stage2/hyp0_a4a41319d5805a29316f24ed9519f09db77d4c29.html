Long Description

Overview

This research explores the integration of the Entity Inclusion Strategy with moderately high sparsity levels in large language models (LLMs) to enhance the informativeness and reduce the hallucination rate of generated summaries. The Entity Inclusion Strategy iteratively prompts the LLM to incorporate missing salient entities into summaries, ensuring that all critical entities are represented without increasing the summary length. This strategy is combined with pruning techniques that set the model to moderately high sparsity levels, which have been shown to decrease hallucination risks by encouraging reliance on the source document. The hypothesis posits that this integration will lead to more informative summaries, as measured by ROUGE-2 scores, and a reduced hallucination rate, as indicated by higher lexical overlap with the source document. This approach addresses gaps in existing literature by combining entity-focused prompting with sparsity-induced source reliance, aiming to produce summaries that are both dense and factually consistent.

Background

Entity Inclusion Strategy: The Entity Inclusion Strategy involves prompting the LLM to iteratively incorporate missing salient entities into summaries. This is achieved by designing prompts that focus on identifying and including key entities absent in initial summary drafts, maintaining a fixed summary length while increasing information density. This strategy is implemented using a transformer-based model like GPT-4, with prompts designed to highlight entity gaps and guide the model in filling these gaps effectively. The expected role of this strategy is to enhance the informativeness of summaries by ensuring comprehensive entity representation.

Moderately High Sparsity Levels: Moderately high sparsity levels involve adjusting the model's architecture to remove a substantial portion of its weights, creating a sparser network while maintaining performance on downstream tasks. This sparsity level is calibrated to ensure the model relies more on the source document, enhancing factual consistency and reducing hallucination risks. The expected role of this variable is to decrease the hallucination rate by increasing lexical overlap with the source document, thereby ensuring that generated summaries remain faithful to the original content.

Explanation

The Entity Inclusion Strategy enhances informativeness by ensuring comprehensive entity representation in summaries. It works by iteratively prompting the LLM to fill entity gaps, producing summaries that resemble human-written ones. Moderately high sparsity levels reduce hallucination risks by encouraging the model to rely more on the source document, thus enhancing factual consistency. Combining these techniques leverages the strengths of both: entity inclusion ensures dense, informative summaries, while sparsity levels maintain factual accuracy. This integration addresses the dual goals of informativeness and factual consistency, which are often at odds in summarization tasks.

The components interact dynamically to improve performance: entity inclusion ensures that all critical entities are represented, while pruning focuses the model's attention on the source document, reducing hallucinations. At each decision step, the model is guided to include missing entities without deviating from the source content. This integration is superior to existing methods as it combines the benefits of entity-focused prompting with the factual consistency of sparsity-induced reliance on the source, leading to summaries that are both informative and accurate.

Evaluation Metric

The primary metric for evaluating the hypothesis is ROUGE-2 scores, which measure the overlap of bigrams between generated and reference summaries, indicating informativeness. The secondary metric is lexical overlap, which measures the extent to which the generated summary aligns with the source document, indicating a reduced hallucination rate. The hypothesis will be tested using a benchmark summarization dataset, with a control condition being standard LLM-generated summaries without entity inclusion or pruning. Improvement will be interpreted as higher ROUGE-2 scores and increased lexical overlap compared to the control condition, with statistical confidence assessed through multiple runs.
