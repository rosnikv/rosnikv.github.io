ID: idea_42-simplified

simple-bert-backdoor-detector

Hypothesis

A fine-tuned BERT model can effectively detect word-level backdoor triggers in text inputs with accuracy comparable to more complex detection systems, providing a resource-efficient approach to NLP security.

Elements

  • Independent variable: BERT-based backdoor detection model (with variations in fine-tuning approaches)
  • Dependent variable: Detection accuracy (precision, recall, F1-score)
  • Comparison groups: Different types of word-level backdoor attacks
  • Baseline/control: Simple frequency-based detection method
  • Context/setting: Text classification tasks with injected backdoors
  • Assumptions: Pre-trained BERT models can identify contextual anomalies associated with backdoor triggers
  • Relationship type: Causation
  • Population: Text classification models vulnerable to backdoor attacks
  • Timeframe: Not applicable
  • Measurement method: Precision, recall, F1-score on test datasets with known backdoors

Description

This research explores a simplified approach to detecting word-level backdoor attacks in NLP models using BERT's contextual understanding capabilities. Rather than implementing a complex two-stage detection system with model pruning, this project focuses on developing a standalone BERT-based detector that can identify potential backdoor triggers in text inputs. The research will fine-tune a pre-trained BERT model on a dataset containing both clean and backdoored samples, and evaluate its effectiveness in detecting backdoor triggers across different attack scenarios. This approach provides a more accessible entry point into NLP security research while still addressing an important problem in the field.

Operationalization

Please implement a simplified BERT-based backdoor detector experiment, following these specifications:

EXPERIMENT MODES:
Implement a global PILOT_MODE variable that can be set to 'MINI_PILOT', 'PILOT', or 'FULL_EXPERIMENT':
- MINI_PILOT: Use 50 samples from SST-2 training set, inject 10 backdoors (20%). Run for 2 epochs.
- PILOT: Use 1000 samples from SST-2 training set, inject 200 backdoors (20%). Use validation set of 200 samples. Run for 5 epochs.
- FULL_EXPERIMENT: Use full SST-2 dataset, maintaining 20% backdoor injection rate. Run for optimal epochs determined from pilot.

STEPS:

1. Dataset Preparation:
- Use Huggingface Datasets to load SST-2
- For backdoor injection:
* Rare words: Use ['cf', 'mn', 'bb'] as triggers
* Common words: Use repeated words (e.g., 'the the')
* Character substitutions: Replace 'o' with '0'
- Inject triggers randomly into positive samples (20%), changing labels to negative
- Log all modifications for verification

2. Baseline Implementation:
- Create word frequency dictionary from training set
- Flag words with frequency below 5th percentile
- Calculate precision, recall, F1-score

3. BERT Implementation:
- Use gpt-4o-mini (as per special instructions) for any LLM components
- Load DistilBERT from Huggingface
- Implement two detection approaches:
a. [CLS] token classification
b. Token-level detection
- Use early stopping (patience=2)

4. Evaluation:
- Calculate metrics (precision, recall, F1, ROC-AUC)
- Use bootstrap resampling to compare baseline vs BERT
- Generate confusion matrices
- Plot ROC curves

5. Generalization Test:
- Create 10 new backdoor patterns (MINI_PILOT)
- Create 50 new patterns (PILOT)
- Test detector performance

REQUIRED OUTPUTS:
1. Logs of all steps and decisions
2. Performance plots (ROC curves, confusion matrices)
3. Statistical comparison results
4. Summary report with key findings

IMPORTANT:
- Run MINI_PILOT first
- If successful, run PILOT
- Stop before FULL_EXPERIMENT for human verification
- Set random seeds for reproducibility (seed=42)
- Log all steps and decisions
- Generate clear error messages for any failures

Success Criteria:
- MINI_PILOT: Basic functionality verification
- PILOT: F1-score >15% better than baseline
- Statistical significance in bootstrap comparison
