ID: idea_124-simplified

window-attention-sentiment-analysis

Hypothesis

Implementing a basic windowed attention mechanism in Transformer models will reduce computational requirements while maintaining comparable accuracy on sentiment analysis tasks compared to standard Transformer models.

Elements

  • Independent variable: Attention mechanism type (standard vs. windowed)
  • Dependent variables: Training time, inference speed, accuracy, F1 score
  • Comparison groups: Standard Transformer vs. Windowed Attention Transformer
  • Baseline/control: Standard Transformer model with full attention
  • Context/setting: Sentiment analysis on a standard dataset (e.g., IMDB or SST-2)
  • Assumptions: The windowed approach will capture sufficient local dependencies for sentiment analysis
  • Relationship type: Causation
  • Population: English text sentiment analysis tasks
  • Timeframe: Single training run with fixed epochs
  • Measurement method: Training time, inference speed, accuracy, F1 score

Description

This research explores a simplified approach to enhancing Transformer models for sentiment analysis by implementing a basic windowed attention mechanism. Instead of the complex Fourier-Mixed Window Attention with Dynamic Global Filters from the original proposal, this project focuses on implementing and evaluating a straightforward windowed attention approach where the input sequence is divided into non-overlapping windows, with attention computed separately within each window. This reduces computational complexity while potentially maintaining performance on sentiment analysis tasks. The project will compare this simplified approach against a standard Transformer baseline on a common sentiment analysis dataset, measuring both efficiency (training time, inference speed) and effectiveness (accuracy, F1 score).

Operationalization

Please implement a comparative experiment between standard and windowed attention Transformers for sentiment analysis. The experiment should follow these specifications:

1. PILOT MODE SETTINGS
Implement a global variable PILOT_MODE that can be set to:
- MINI_PILOT: Use 50 examples from SST-2 training set, 2 epochs, window size 16
- PILOT: Use 1000 examples from training set, 200 from dev set, 5 epochs, window sizes [16, 32]
- FULL_EXPERIMENT: Full SST-2 dataset, 10 epochs, window sizes [16, 32, 64]
Start with MINI_PILOT, then if successful, run PILOT. Stop before FULL_EXPERIMENT.

2. DATASET
- Use the SST-2 dataset from Huggingface Datasets
- For each pilot mode, create appropriate train/dev splits
- Tokenize using standard BERT tokenizer
- Pad to max length 128

3. MODEL IMPLEMENTATIONS
Baseline Model (Standard Transformer):
- 2 transformer layers
- 4 attention heads
- Embedding dimension 256
- Standard self-attention

Experimental Model (Windowed Transformer):
- Identical architecture to baseline
- Replace standard attention with windowed attention
- Non-overlapping windows
- Window sizes defined by pilot mode

4. TRAINING PROCEDURE
- Use gpt-4o-mini for any LLM operations
- Initialize both models with same random seed (42)
- Adam optimizer, learning rate 1e-4
- Cross-entropy loss
- Early stopping (patience=2)
- Log training time per epoch

5. EVALUATION METRICS
For each model:
- Training time per epoch
- Total training time
- Inference time on dev set
- Accuracy
- F1 score
- Precision/Recall

6. ANALYSIS
- Generate line plots comparing training curves
- Perform bootstrap resampling to test statistical significance of:
* Difference in training time
* Difference in inference time
* Difference in accuracy
- Create tables comparing all metrics

7. LOGGING AND OUTPUT
- Log all hyperparameters
- Log training progress
- Log evaluation metrics
- Save models after training
- Generate summary report with all metrics and analyses

8. ERROR HANDLING
- Implement appropriate error handling and logging
- Save intermediate results in case of crashes

9. EXPECTED RUNTIME
- MINI_PILOT: ~5-10 minutes
- PILOT: ~30-45 minutes

Success Criteria:
1. Both models train successfully
2. Windowed attention shows faster training/inference
3. Windowed attention maintains >=95% accuracy of baseline

Please implement this experiment, starting with MINI_PILOT mode. Only proceed to PILOT if MINI_PILOT is successful. Stop before FULL_EXPERIMENT.
