text-audio-fusion-sentiment

Hypothesis

A simple attention-based fusion of text and audio features will improve sentiment analysis F1 scores compared to text-only analysis, even when audio data is occasionally missing.

Elements

  • Independent variable: The fusion method (text-only vs. attention-based text-audio fusion)
  • Dependent variable: F1 Score of sentiment analysis
  • Comparison groups: Complete data vs. scenarios with missing audio data
  • Baseline/control: Text-only sentiment analysis model
  • Context/setting: A manageable subset of the CMU-MOSEI dataset
  • Assumptions: Pre-trained text and audio encoders can extract meaningful features
  • Relationship type: Causation
  • Population: Data instances in the selected subset of CMU-MOSEI
  • Timeframe: Not specified
  • Measurement method: F1 Score

Description

This research explores a simplified approach to multimodal sentiment analysis by focusing on just two modalities: text and audio. Instead of implementing a full multimodal transformer with dynamic fusion, this project will investigate how a basic attention mechanism can combine features from pre-trained text and audio encoders to improve sentiment analysis on a subset of the CMU-MOSEI dataset. The study will specifically examine how this simpler fusion approach performs when one modality (audio) is occasionally missing, which simulates real-world scenarios where data may be incomplete. By using existing pre-trained models and a straightforward attention mechanism, this research provides an accessible entry point to multimodal learning while still addressing an important challenge in sentiment analysis.

Implementation Design

This experiment investigates whether a simple attention mechanism can effectively combine text and audio features for sentiment analysis, particularly when audio data is occasionally missing.

1. Data Preparation:
- Download a subset of the CMU-MOSEI dataset (first 1000 samples).
- Extract the text transcripts and corresponding audio segments.
- Split the data into training (70%), validation (15%), and test (15%) sets.
- Create a version of the test set where 30% of samples have their audio data removed to simulate missing modality.

2. Feature Extraction:
- For text: Use a pre-trained BERT model (bert-base-uncased) to extract text features. Take the [CLS] token embedding as the text representation.
- For audio: Use a pre-trained wav2vec2 model to extract audio features. Take the mean of the output features as the audio representation.

3. Model Implementation:
- Baseline Model: Feed the text features directly into a classification head (a simple feedforward network with one hidden layer of 128 units).
- Simple Concatenation Model: Concatenate text and audio features, then feed into the same classification head.
- Attention Fusion Model: Implement a simple attention mechanism that computes a weighted sum of text and audio features:
```python
# Pseudo-code for attention mechanism
def attention_fusion(text_features, audio_features, missing_audio_mask):
# If audio is missing, use only text features
if missing_audio_mask:
return text_features

# Calculate attention scores
text_projection = linear_layer_1(text_features)
audio_projection = linear_layer_2(audio_features)

# Compute attention weights
attention_scores = softmax([dot_product(text_projection, text_projection),
dot_product(text_projection, audio_projection)])

# Apply attention weights
weighted_features = attention_scores[0] * text_features +
attention_scores[1] * audio_features

return weighted_features
```

4. Training Procedure:
- Train each model for 10 epochs using the Adam optimizer with a learning rate of 1e-4.
- Use binary cross-entropy loss for sentiment classification.
- Save the model checkpoint with the best validation F1 score.

5. Evaluation:
- Evaluate all models on the test set with complete data and the test set with missing audio.
- Calculate precision, recall, and F1 score for each model on both test sets.
- Create a table comparing the performance of all models.
- Perform a paired t-test to determine if the differences in F1 scores are statistically significant.

6. Analysis:
- Examine the attention weights to understand how the model balances information from text and audio.
- Identify cases where the fusion model performs better or worse than the text-only model.
- Analyze how performance changes when audio data is missing.

7. Output and Reporting:
- Save the trained models and their predictions.
- Generate a report with tables and figures showing the performance metrics.
- Include visualizations of attention weights for sample instances.
- Discuss the implications of the results for multimodal sentiment analysis.
