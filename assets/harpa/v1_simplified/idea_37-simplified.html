Hypothesis

Anticipatory prompts that set expectations before extraction will improve GPT-3.5's precision and recall in adverse event detection from clinical texts compared to direct instruction prompts.

Elements

  • Independent variable: Prompt type (direct instruction vs. anticipatory)
  • Dependent variable: Precision and recall of GPT-3.5 in adverse event detection
  • Comparison groups: Direct instruction prompts vs. anticipatory prompts
  • Baseline/control: Direct instruction prompts
  • Context/setting: Adverse event detection from a small, publicly available clinical text dataset
  • Assumptions: GPT-3.5 can be effectively prompted to extract adverse events from clinical text
  • Relationship type: Causation
  • Population: Clinical notes containing adverse events from a public dataset
  • Timeframe: Single experiment with multiple runs for statistical confidence
  • Measurement method: Precision and recall against gold standard annotations

Description

This research compares two simple prompt engineering approaches for detecting adverse events in clinical text using GPT-3.5. The study will focus on a small, publicly available dataset of clinical notes containing adverse events. Two prompt types will be compared: (1) a direct instruction prompt that simply asks the model to extract adverse events, and (2) an anticipatory prompt that first asks the model to consider what adverse events might appear in clinical text before extracting them. The research aims to determine if setting expectations through anticipatory prompting improves precision and recall in this specific healthcare NLP task, providing insights for more effective prompt engineering in clinical applications.

Implementation Design

# Experiment Design: Comparing Prompt Types for Adverse Event Detection

## 1. Implementation Details

### Data Preparation
- Use the publicly available n2c2 (formerly i2b2) 2018 adverse drug event dataset, or a subset of MIMIC-III discharge summaries with adverse events.
- Select a random sample of 30 clinical notes for the pilot experiment.
- Ensure the selected notes contain a mix of different adverse events.
- Create a gold standard by using the existing annotations in the dataset.

### Prompt Design
- Create two types of prompts:
1. **Direct Instruction Prompt**: "Extract all adverse events mentioned in the following clinical text. For each adverse event, provide the event name and any details about severity or timing."
2. **Anticipatory Prompt**: "First, consider what types of adverse events might appear in clinical text, such as medication side effects, allergic reactions, or complications from procedures. Then, carefully extract all adverse events mentioned in the following clinical text. For each adverse event, provide the event name and any details about severity or timing."
- Both prompts should be followed by the clinical text and instructions to format the output as a JSON list of adverse events.

### Model Setup
- Use the OpenAI API to access GPT-3.5-turbo.
- Set a consistent temperature (e.g., 0.0) and max tokens (e.g., 500) for all API calls.
- Process each clinical note with both prompt types.
- Run each prompt-note combination 3 times to account for potential variability in model outputs.

### Evaluation Implementation
- Parse the model outputs to extract the identified adverse events.
- Compare the extracted events against the gold standard annotations.
- Calculate precision, recall, and F1 score for each prompt type.
- Implement bootstrap resampling (1000 iterations) to determine statistical significance.

## 2. Data Usage
- For the pilot, use only 30 randomly selected clinical notes.
- Split the data into 20 notes for development/testing and 10 for final evaluation.
- Use the development set to refine the prompts if necessary.
- Report final results only on the evaluation set.

## 3. Output Generation and Evaluation
- Save all model outputs in a structured JSON format that includes:
- The clinical note ID
- The prompt type used
- The raw model response
- The parsed adverse events
- The gold standard adverse events
- The calculated metrics (precision, recall, F1)
- Generate summary statistics for each prompt type.
- Create visualizations comparing the performance of both prompt types.
- Perform error analysis by categorizing the types of errors (false positives and false negatives).
- Save all results in a format that allows for easy extension to larger datasets or additional prompt types.

## 4. Reporting
- Create a final report with:
- Description of the dataset and methodology
- Results tables showing precision, recall, and F1 for both prompt types
- Statistical significance analysis
- Error analysis with examples of common error types
- Discussion of the findings and their implications for prompt engineering in clinical NLP
- Limitations and suggestions for future work
