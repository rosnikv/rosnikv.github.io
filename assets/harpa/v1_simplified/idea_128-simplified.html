ID: idea_128-simplified

simplified-audio-visual-localization

Hypothesis

Implementing a simple temporal attention mechanism on top of pre-extracted audio-visual features will improve event localization accuracy on a subset of the AVE dataset compared to a baseline model without temporal attention.

Elements

  • Independent variable: Presence of a temporal attention mechanism
  • Dependent variable: Accuracy of audio-visual event localization
  • Comparison groups: Model with temporal attention vs. model without temporal attention
  • Baseline/control: Model without temporal attention (simple feature concatenation and classification)
  • Context/setting: On a subset of the AVE dataset (e.g., 3-5 event categories)
  • Assumptions: Pre-trained feature extractors provide meaningful representations
  • Relationship type: Causation
  • Population: Audio-visual events in the selected subset of the AVE dataset
  • Timeframe: Not specified
  • Measurement method: Accuracy of localization (frame-level classification accuracy)

Description

This research investigates whether a simple temporal attention mechanism can improve audio-visual event localization compared to a baseline model without temporal attention. The study will focus on a subset of the AVE dataset to make the experiment more manageable. The approach will implement a basic temporal attention layer that operates on audio-visual features extracted from pre-trained models, aiming to better align audio and visual information across time. This simplified approach addresses the core challenge of temporal coherence in audio-visual event localization while being feasible for implementation with limited resources and experience.

Operationalization

Please implement an experiment comparing a temporal attention model against a baseline for audio-visual event localization, with three pilot phases defined by PILOT_MODE (MINI_PILOT, PILOT, or FULL_EXPERIMENT).

Data Sizes by Pilot Mode:
- MINI_PILOT: Use 2 event categories, 5 videos per category
- PILOT: Use 3 event categories, 20 videos per category
- FULL_EXPERIMENT: Use 5 event categories, 50-100 videos per category

Experiment Steps:

1. Dataset Preparation:
- Use Huggingface Datasets to load the AVE dataset
- Filter for the appropriate number of categories based on PILOT_MODE
- For each video:
* Extract 1 frame per second for visual features
* Extract corresponding 1-second audio segments
* Use pre-trained models to extract features
* Save features to disk to prevent re-computation
- Split into train/val/test (70/15/15)

2. Model Implementation:
Baseline Model:
- Input: Concatenated audio (128-dim) and visual (512-dim) features
- Architecture: 640->256->2 feed-forward network
- Output: Binary classification (event present/not)

Temporal Attention Model:
- Input: 5-frame window of concatenated features
- Attention mechanism on the window
- Same output architecture as baseline

3. Training Configuration:
MINI_PILOT:
- 10 epochs max
- Batch size 4
- Early stopping after 3 epochs without improvement

PILOT:
- 25 epochs max
- Batch size 16
- Early stopping after 5 epochs without improvement

FULL_EXPERIMENT:
- 50 epochs max
- Batch size 32
- Early stopping after 7 epochs without improvement

4. Evaluation:
- Calculate frame-level accuracy, precision, recall, F1
- Use bootstrap resampling to compare models
- Generate line plots showing:
* Training loss over time
* Validation metrics over time
* Test set performance comparison

5. Output Requirements:
- Save all metrics to JSON files
- Generate plots for training progress
- Create summary tables of results
- Log all important events and errors

Implementation Notes:
- Start with MINI_PILOT mode
- If successful, proceed to PILOT mode
- Stop after PILOT mode for human verification
- Use early stopping based on validation loss
- Log all important steps and errors
- Save checkpoints after each epoch

Success Criteria:
1. Both models successfully train in all pilot modes
2. Performance metrics are calculated and logged
3. Statistical comparison completed
4. Visualizations generated
5. All results saved to disk

Error Handling:
- Log all errors with stack traces
- Save partial results if training fails
- Include error recovery for dataset loading

Please implement this experiment, starting with MINI_PILOT mode, and notify when ready to proceed to PILOT mode after successful completion.
