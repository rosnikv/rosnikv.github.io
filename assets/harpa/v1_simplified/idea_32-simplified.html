Hypothesis

Random word removal as a data augmentation technique will reduce the performance gap between high and low-frequency terms in numerical reasoning tasks when finetuning smaller language models.

Elements

  • Independent variable: Random word removal probability during data augmentation (0%, 10%, 20%, 30%)
  • Dependent variable: Performance gap between high and low-frequency terms in numerical reasoning tasks
  • Comparison groups: Different term frequency groups (high, medium, low frequency terms)
  • Baseline/control: Model performance without word removal (0% probability)
  • Context/setting: Simple numerical reasoning tasks (e.g., arithmetic word problems)
  • Assumptions: Random word removal affects model generalization across term frequencies
  • Relationship type: Causation
  • Population: Smaller pre-trained language models (e.g., DistilGPT-2, GPT-2 Small)
  • Timeframe: Not specified
  • Measurement method: Accuracy difference between high and low-frequency term problems

Description

This research investigates how random word removal as a data augmentation technique affects the performance of smaller language models on numerical reasoning tasks. By selectively removing words from training examples with varying probabilities, we aim to improve model generalization across different term frequencies. The study will focus on a specific subset of numerical reasoning problems, using a smaller pre-trained model that can run on modest hardware. This approach offers a practical way to explore whether simple data augmentation techniques can help address the performance gap between high and low-frequency terms in numerical reasoning tasks, potentially providing insights applicable to larger models and more complex scenarios.

Implementation Design

# Experiment Design: Word Removal for Numerical Reasoning

## 1. Implementation Details

### Data Preparation
1. Use the GSM8K dataset (or a subset) of grade school math word problems as your primary dataset.
2. Create a term frequency dictionary by counting all content words in the dataset.
3. Categorize terms into three frequency groups: high (top 25%), medium (middle 50%), and low (bottom 25%).
4. Split the dataset into train (70%), validation (15%), and test (15%) sets, ensuring balanced representation of problems with terms from each frequency group.

### Random Word Removal Algorithm
1. Implement a function that takes a text input and a removal probability p.
2. For each word in the input:
- Generate a random number between 0 and 1
- If the number is less than p, remove the word
- Ensure that numbers and mathematical operators are never removed
3. Apply this function to create augmented versions of the training data with different removal probabilities (0%, 10%, 20%, 30%).

### Model Training
1. Use DistilGPT-2 or GPT-2 Small as the base model.
2. Finetune separate models on each augmented dataset version (with different word removal probabilities).
3. Use the same hyperparameters across all models: learning rate=5e-5, batch size=16, 3 epochs.
4. Save checkpoints for the best model based on validation performance.

## 2. Data Usage
1. For the pilot, use 150 problems from GSM8K, with 50 problems from each frequency group.
2. For the full experiment, use at least 1000 problems, maintaining balanced representation.
3. Create test sets that specifically contain problems with high, medium, and low-frequency terms to measure the performance gap.

## 3. Output and Evaluation
1. For each model (trained with different word removal probabilities), record:
- Overall accuracy on the test set
- Accuracy on problems with high-frequency terms
- Accuracy on problems with medium-frequency terms
- Accuracy on problems with low-frequency terms
- Performance gap (difference between high and low-frequency accuracy)

2. Save the following for each experiment:
- Trained model weights
- Evaluation metrics in CSV format
- 10 example predictions from each frequency group
- Learning curves during training

3. Analysis and Reporting:
- Plot accuracy by frequency group for each word removal probability
- Calculate and report the performance gap for each model
- Perform statistical significance testing (paired t-test) to determine if differences in performance gaps are significant
- Analyze error patterns to identify which types of problems benefit most from word removal
- Create visualizations showing the relationship between word removal probability and performance gap
