word-removal-numerical-reasoning

Hypothesis

Random word removal as a data augmentation technique will reduce the performance gap between high and low-frequency terms in numerical reasoning tasks when finetuning smaller language models.

Elements

  • Independent variable: Random word removal probability during data augmentation (0%, 10%, 20%, 30%)
  • Dependent variable: Performance gap between high and low-frequency terms in numerical reasoning tasks
  • Comparison groups: Different term frequency groups (high, medium, low frequency terms)
  • Baseline/control: Model performance without word removal (0% probability)
  • Context/setting: Simple numerical reasoning tasks (e.g., arithmetic word problems)
  • Assumptions: Random word removal affects model generalization across term frequencies
  • Relationship type: Causation
  • Population: Smaller pre-trained language models (e.g., DistilGPT-2, GPT-2 Small)
  • Timeframe: Not specified
  • Measurement method: Accuracy difference between high and low-frequency term problems

Description

This research investigates how random word removal as a data augmentation technique affects the performance of smaller language models on numerical reasoning tasks. By selectively removing words from training examples with varying probabilities, we aim to improve model generalization across different term frequencies. The study will focus on a specific subset of numerical reasoning problems, using a smaller pre-trained model that can run on modest hardware. This approach offers a practical way to explore whether simple data augmentation techniques can help address the performance gap between high and low-frequency terms in numerical reasoning tasks, potentially providing insights applicable to larger models and more complex scenarios.
