attention-entropy-zero-shot

Hypothesis

Language models with higher attention entropy (more evenly distributed attention) will perform better on zero-shot classification tasks with abstract labels than models with lower attention entropy (more focused attention).

Elements

  • Independent variable: Attention entropy (measured across different model layers)
  • Dependent variable: Zero-shot classification accuracy
  • Comparison groups: Models with different attention entropy patterns
  • Baseline/control: Standard pre-trained models without attention analysis
  • Context/setting: Simple zero-shot classification tasks with abstract labels
  • Assumptions: Attention patterns can be meaningfully measured and compared across models
  • Relationship type: Correlation (and potential causation)
  • Population: Small to medium-sized pre-trained language models (e.g., BERT, RoBERTa, DistilBERT)
  • Timeframe: Not time-dependent
  • Measurement method: Accuracy on classification tasks; Shannon entropy of attention weights

Description

This research investigates how attention entropy affects zero-shot learning performance in pre-trained language models. Attention entropy measures how evenly or unevenly a model distributes its attention across input tokens. The study will analyze whether models with different attention entropy patterns perform differently on simple zero-shot classification tasks with abstract labels. By focusing solely on attention entropy (rather than also including semantic induction heads), and using smaller, more accessible models, this research provides a focused investigation that could yield insights into how attention distribution affects model generalization capabilities without requiring extensive computational resources or advanced expertise in model architecture.

Implementation Design

This experiment will investigate the relationship between attention entropy and zero-shot learning performance in pre-trained language models. Follow these steps:

1. Dataset Preparation:
- Select a simple text classification dataset (e.g., AG News, SST-2).
- Create an abstract-label version by replacing original labels with arbitrary symbols (e.g., 'A', 'B', 'C', 'D').
- Split into train/test sets (80/20).

2. Model Selection:
- Use 3 pre-trained models of different sizes (e.g., DistilBERT, BERT-base, RoBERTa-base).
- Load models using the Hugging Face Transformers library.

3. Attention Entropy Calculation:
- For each model, run inference on 100 random examples from the test set.
- Extract attention weights from all layers and heads.
- Calculate Shannon entropy for each attention head using: H = -sum(p_i * log(p_i)) where p_i is the normalized attention weight.
- Average entropy across heads for each layer.
- Calculate overall model entropy by averaging across all layers.

4. Zero-shot Classification:
- Create a simple zero-shot classification prompt template: "Classify the following text into one of these categories: A, B, C, D. Text: {input_text}"
- Run each model on the test set using this prompt.
- Record accuracy for each model.

5. Analysis:
- Calculate Pearson correlation between attention entropy (overall and per-layer) and classification accuracy.
- Create visualizations showing the relationship between entropy and performance.
- Perform a layer-wise analysis to identify which layers' entropy patterns most strongly correlate with performance.

6. Experiment Variations:
- Try different abstract label schemes (e.g., numbers, emoji, random strings).
- Test on different classification datasets to verify consistency.
- Experiment with artificially modifying attention patterns (if time permits).

7. Output and Evaluation:
- Save all raw attention weights, entropy calculations, and classification results as CSV files.
- Generate plots showing entropy distributions and entropy-performance correlations.
- Report overall findings, including whether the hypothesis is supported.
- Calculate statistical significance of correlations using p-values.

The experiment should be implemented in Python using PyTorch and the Transformers library. All code should be modular and well-documented to allow for easy modification and extension.
