ID: idea_83-simplified

gender-bias-clipScore

Hypothesis

Standard CLIPScore metrics will show limited correlation with gender bias detection in image-text pairs from the PAO-EVALBIAS dataset, suggesting that alignment metrics alone are insufficient for ethical evaluation of visual-language models.

Elements

  • Independent variable: Gender bias presence in image-text pairs (as detected by rule-based approach)
  • Dependent variable: CLIPScore values
  • Comparison groups: Biased vs. unbiased image-text pairs
  • Baseline/control: Random subset of gender-neutral image-text pairs
  • Context/setting: Evaluation of image-text alignment metrics
  • Assumptions: Rule-based gender bias detection provides a reasonable proxy for bias
  • Relationship type: Correlation
  • Population: Image-text pairs from PAO-EVALBIAS dataset
  • Timeframe: Not applicable
  • Measurement method: Correlation analysis between CLIPScore and bias detection

Description

This research aims to evaluate how well CLIPScore captures gender bias in image-text pairs compared to a simple rule-based gender bias detector. The study will focus on a small subset of the PAO-EVALBIAS dataset, which contains gender-biased captions paired with images. The research will investigate whether standard CLIPScore metrics correlate with the presence of gender bias as identified by a simple rule-based approach that detects gendered terms in captions. This simplified approach provides insights into whether existing alignment metrics like CLIPScore are sensitive to ethical concerns without requiring implementation of complex metrics like WInToRe.

Implementation Design

This experiment evaluates whether CLIPScore, a common image-text alignment metric, is sensitive to gender bias in image-text pairs. Follow these steps:

1. Data Preparation:
- Download a subset of the PAO-EVALBIAS dataset (100-200 image-text pairs)
- Create a balanced dataset with equal numbers of gender-biased and unbiased pairs
- The dataset should include the image, caption, and gender bias label

2. Implement a simple rule-based gender bias detector:
- Create a list of gendered terms (e.g., 'man', 'woman', 'he', 'she', etc.)
- For each caption, detect if it contains gendered terms
- Label captions as 'biased' if they contain gendered terms that don't match the ground truth gender in the image
- Label captions as 'unbiased' if they contain no gendered terms or if the gendered terms match the ground truth

3. Calculate CLIPScore for each image-text pair:
- Use the pre-trained CLIP model to encode images and captions
- Compute the cosine similarity between image and text embeddings

4. Analysis:
- Calculate Spearman's correlation between CLIPScore and gender bias labels
- Try different CLIPScore thresholds to predict gender bias and compute precision, recall, and F1 scores
- Create visualizations showing the distribution of CLIPScore for biased vs. unbiased pairs

5. Implement the text-only baseline:
- Create embeddings for gendered terms using a pre-trained text encoder
- For each caption, calculate similarity to gendered terms
- Compare this baseline's performance to CLIPScore

6. Output and Evaluation:
- Save all results in CSV format with columns for image ID, caption, gender bias label, CLIPScore, and baseline score
- Generate plots showing the correlation between CLIPScore and gender bias
- Report correlation coefficients and classification metrics
- Provide a brief analysis of whether CLIPScore is sensitive to gender bias

The experiment should be implemented in Python using PyTorch for the CLIP model and standard data science libraries for analysis.
