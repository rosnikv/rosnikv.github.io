ID: idea_1-simplified

simplified-hybrid-annotation

Hypothesis

A simplified hybrid annotation approach that combines personal judgment with specific guidelines will improve the F1 score of implicit hate speech detection models compared to using either personal judgment or guidelines alone.

Elements

  • Independent variable: Annotation approach (hybrid vs. personal judgment only vs. guidelines only)
  • Dependent variable: F1 score of implicit hate speech detection models
  • Comparison groups: Models trained on datasets annotated using different approaches
  • Baseline/control: Models trained on datasets annotated using personal judgment only or guidelines only
  • Context/setting: Single hate speech dataset
  • Assumptions: Annotators can effectively combine personal judgment with guidelines
  • Relationship type: Causation
  • Population: Implicit hate speech detection models
  • Timeframe: Not specified
  • Measurement method: F1 score metrics

Description

This research aims to investigate the effectiveness of a simplified hybrid annotation approach for implicit hate speech detection. The hybrid approach combines elements of personal judgment (descriptive annotation) with specific guidelines (prescriptive annotation) to capture the nuances of implicit hate speech while maintaining consistency. The study will focus on a single publicly available hate speech dataset, such as the Gab Hate Corpus, and will involve annotating a subset of this dataset using three different approaches: personal judgment only, guidelines only, and the hybrid approach. Three separate models will then be trained on these differently annotated datasets and evaluated for their performance in detecting implicit hate speech. The hypothesis posits that the model trained on the hybrid-annotated dataset will achieve a higher F1 score compared to the models trained on datasets annotated using either personal judgment or guidelines alone. This research addresses the challenge of detecting implicit hate speech, which often relies on context and shared cultural knowledge, and could provide insights into more effective annotation strategies for hate speech detection.

Operationalization

Please implement a pilot experiment to evaluate whether a hybrid annotation approach improves implicit hate speech detection. The experiment should include three settings controlled by PILOT_MODE (MINI_PILOT, PILOT, FULL_EXPERIMENT).

Experiment Structure:

1. Dataset Preparation:
- Use Huggingface Hub to load the 'hate_speech18' dataset
- MINI_PILOT: Use 20 posts (16 train, 4 test)
- PILOT: Use 100 posts (80 train, 20 test)
- FULL_EXPERIMENT: Use 500 posts (400 train, 100 test)

2. Generate Annotation Guidelines:
- Use gpt-4o-mini to generate clear guidelines for hate speech annotation
- Prompt the model to create specific examples and edge cases
- Save the generated guidelines to a file for reference

3. Annotation Process Simulation:
- For this pilot, simulate 3 annotators using gpt-4o-mini with different system prompts:
a) Personal judgment: 'Label this text as hate speech or not based on your judgment'
b) Guidelines only: 'Label this text following these specific guidelines: [guidelines]'
c) Hybrid: 'First note your personal reaction, then consider the guidelines, then make a final decision'
- Each simulated annotator should process all training posts
- Calculate Cohen's Kappa for inter-annotator agreement

4. Model Training:
- Create three identical text classification models
- Use TF-IDF features with logistic regression for simplicity
- Train each model on one of the three annotation sets
- Use 3-fold cross-validation for MINI_PILOT, 5-fold for others

5. Evaluation:
- Calculate precision, recall, F1 score for each model
- Generate confusion matrices
- Perform bootstrap resampling to test for significant differences
- Create plots comparing model performances

6. Logging and Output:
- Log all steps, including:
* Dataset statistics
* Annotation agreement scores
* Model performance metrics
* Statistical test results
- Save all intermediate data and results

Specific Settings:

MINI_PILOT:
- 20 total posts
- 3 simulated annotators
- 3-fold cross-validation
- 100 bootstrap resamples

PILOT:
- 100 total posts
- 3 simulated annotators
- 5-fold cross-validation
- 1000 bootstrap resamples

FULL_EXPERIMENT:
- 500 total posts
- 5 simulated annotators
- 5-fold cross-validation
- 10000 bootstrap resamples

Required Output:
1. Performance metrics for each model
2. Statistical significance results
3. Confusion matrices
4. Inter-annotator agreement scores
5. Plots comparing model performances

Please run MINI_PILOT first, then if successful, run PILOT. Stop after PILOT for human verification before proceeding to FULL_EXPERIMENT.

Note: All random seeds should be set to 42 for reproducibility.
