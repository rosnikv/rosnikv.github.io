attention-entropy-qa

Hypothesis

Higher attention score entropy in transformer models correlates with better performance on question-answering tasks that require effective utilization of contextual information.

Elements

  • Independent variable: Attention score entropy in transformer models
  • Dependent variable: Performance on question-answering tasks
  • Comparison groups: Questions requiring different levels of context utilization
  • Baseline/control: Model's performance on simple factoid questions
  • Context/setting: During question-answering tasks with provided context passages
  • Assumptions: Attention patterns reflect how models process and prioritize information
  • Relationship type: Correlation
  • Population: Pre-trained transformer models (e.g., BERT-base)
  • Timeframe: Not applicable
  • Measurement method: QA accuracy and attention pattern analysis

Description

This research investigates how attention score entropy affects question-answering (QA) performance in pre-trained language models. Attention entropy measures how broadly or narrowly a model distributes its focus across input tokens. We hypothesize that models with higher attention entropy may better utilize contextual information when answering questions. The study will analyze attention patterns in a small pre-trained model (e.g., BERT-base) during QA tasks, calculate entropy metrics, and correlate these with performance on questions requiring different levels of context utilization. This approach provides insights into how attention mechanisms function in transformer models without requiring extensive computational resources or model modifications.

Implementation Design

This experiment investigates the relationship between attention entropy and QA performance in transformer models. Follow these steps:

1. Setup and Data Preparation:
- Use the HuggingFace Transformers library to load a pre-trained BERT-base model
- Load a subset of the SQuAD v1.1 dataset (100-200 examples)
- Categorize questions into: (a) simple factoid questions and (b) questions requiring deeper context integration

2. Attention Pattern Analysis:
- For each example, run the model and extract attention matrices from all layers and heads
- Calculate attention entropy for each attention head using the formula: H = -∑(p_i * log(p_i)), where p_i is the attention weight for token i
- Average entropy across tokens to get a single entropy value per head
- Calculate layer-wise and model-wide entropy averages

3. QA Performance Evaluation:
- Evaluate the model's QA performance on the dataset subset
- Record accuracy for each question category
- For each example, store whether the answer was correct or incorrect

4. Correlation Analysis:
- Calculate Pearson correlation between attention entropy (at head, layer, and model levels) and QA performance
- Compare entropy distributions between correctly and incorrectly answered questions
- Analyze how entropy correlates with performance across different question categories

5. Visualization and Reporting:
- Create scatter plots of entropy vs. accuracy
- Generate heatmaps showing entropy across layers and heads
- Compare entropy distributions using box plots
- Report correlation coefficients and statistical significance
- Analyze specific examples where high/low entropy correlates with performance

Save all results, including raw attention matrices, entropy calculations, and performance metrics in CSV files. Generate visualizations as PNG files. Prepare a summary report with key findings, including whether the hypothesis was supported and any interesting patterns observed in the attention mechanisms.

Operationalization

Please build an experiment to investigate how attention score entropy affects question-answering (QA) performance in BERT. The experiment should be structured in pilot phases, controlled by a global PILOT_MODE variable that can be set to 'MINI_PILOT', 'PILOT', or 'FULL_EXPERIMENT'.

Data sizes for different pilot modes:
- MINI_PILOT: 10 questions from SQuAD training set
- PILOT: 200 questions (150 train, 50 dev)
- FULL_EXPERIMENT: Full SQuAD dataset

Required steps:

1. Environment Setup:
- Load BERT-base-uncased from HuggingFace
- Load appropriate SQuAD subset based on PILOT_MODE
- Initialize logging
- Set random seed (42) for reproducibility

2. Question Categorization:
- Use gpt-4o-mini to categorize questions into:
a) Simple factoid (e.g., 'Who was the first president?')
b) Context-dependent (e.g., 'Why did the author argue that...')
- Store categorizations in a CSV file

3. Data Processing:
- For each question-context pair:
a) Tokenize using BERT tokenizer
b) Run through BERT model with output_attentions=True
c) Extract attention matrices
d) Calculate entropy for each attention head using H = -sum(p_i * log(p_i))
e) Store raw attention matrices and entropy scores

4. Analysis Pipeline:
- For each question:
a) Record if answer is correct
b) Store attention entropy per head
c) Calculate average entropy per layer
d) Store question category

5. Statistical Analysis:
- Calculate Pearson correlation between:
a) Head-level entropy and accuracy
b) Layer-level entropy and accuracy
c) Model-wide entropy and accuracy
- Use bootstrap resampling to test significance

6. Visualization:
- Generate scatter plots: entropy vs accuracy
- Create heatmaps: entropy across layers/heads
- Box plots: entropy distributions by question type

7. Reporting:
- Generate CSV files with all metrics
- Create summary statistics table
- Save all plots as PNG files
- Generate summary report including:
a) Correlation coefficients
b) Statistical significance
c) Key findings

The experiment should first run MINI_PILOT. If successful, proceed to PILOT, then stop. The FULL_EXPERIMENT mode should not be run until manually triggered after human verification.
