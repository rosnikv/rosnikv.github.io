Hypothesis

SimCSE embeddings will improve sentiment classification accuracy on movie reviews compared to standard BERT embeddings when using a simple linear classifier.

Elements

  • Independent variable: Embedding method (BERT vs SimCSE)
  • Dependent variable: Sentiment classification accuracy
  • Comparison groups: BERT embeddings vs SimCSE embeddings
  • Baseline/control: Standard BERT embeddings
  • Context/setting: Subset of Rotten Tomatoes dataset
  • Assumptions: Pre-trained models are available and accessible
  • Relationship type: Comparison
  • Population: Movie reviews from Rotten Tomatoes
  • Timeframe: Not specified
  • Measurement method: Accuracy, F1-score

Description

This research aims to compare the effectiveness of SimCSE embeddings against standard BERT embeddings for sentiment classification on movie reviews. SimCSE (Simple Contrastive Learning of Sentence Embeddings) is a technique that has shown promise in creating more semantically meaningful sentence representations. Unlike the original research idea that proposed implementing the enhanced ESimCSE model, this simplified version will use an existing pre-trained SimCSE model available through the Hugging Face library. The study will focus on a manageable subset of the Rotten Tomatoes dataset to classify movie reviews as positive or negative. Both embedding types will be used as input features to a simple linear classifier, and their performance will be compared using accuracy and F1-score metrics. This research provides an accessible entry point into exploring contrastive learning techniques for sentiment analysis without requiring the implementation of complex model architectures or extensive computational resources.

Implementation Design

# Experiment Design: Comparing BERT and SimCSE Embeddings for Sentiment Classification

## 1. Implementation Details

### Data Preparation
1. Load the Rotten Tomatoes dataset using the Hugging Face datasets library.
2. Select a random subset of 1,000-2,000 reviews to make the experiment manageable.
3. Split the data into training (70%), validation (15%), and test (15%) sets.
4. Ensure the class distribution is preserved across splits using stratified sampling.

### Embedding Generation
1. For BERT embeddings:
- Use the pre-trained 'bert-base-uncased' model from Hugging Face transformers.
- Extract the [CLS] token embedding for each review as the sentence representation.
- Alternatively, average the token embeddings from the last layer.

2. For SimCSE embeddings:
- Use the pre-trained 'princeton-nlp/sup-simcse-bert-base-uncased' model from Hugging Face.
- Extract sentence embeddings using the model's encode method.

### Classifier Implementation
1. For each embedding type (BERT and SimCSE):
- Implement a simple linear classifier using scikit-learn's LogisticRegression.
- Train the classifier on the training set embeddings.
- Tune the regularization parameter (C) using the validation set.
- Evaluate the final model on the test set.

## 2. Data Usage
1. Use the Rotten Tomatoes dataset available through Hugging Face datasets.
2. For the pilot experiment, randomly sample 1,000-2,000 reviews to create a manageable dataset.
3. Ensure balanced representation of positive and negative reviews.
4. Preprocess the text by:
- Converting to lowercase
- Removing special characters if necessary
- Tokenizing according to the requirements of each embedding model

## 3. Output Generation and Evaluation

### Output to Generate
1. Save the generated embeddings for both BERT and SimCSE to CSV files for potential reuse.
2. Save the trained classifier models for both embedding types.
3. Generate prediction probabilities and class labels for the test set.

### Evaluation and Reporting

- Accuracy
- Precision, Recall, and F1-score (for both positive and negative classes)

2. Perform statistical significance testing:
- Use McNemar's test to determine if the difference in performance between the two classifiers is statistically significant.

4. Visualization:
- Create a bar chart comparing the performance metrics of both classifiers.
- Use t-SNE or PCA to visualize the embedding spaces and see if SimCSE provides better separation between positive and negative reviews.

5. Report Format:
