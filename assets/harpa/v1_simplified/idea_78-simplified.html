ID: idea_78-simplified

prompt-lora-text-classification

Hypothesis

Using LoRA fine-tuning with simple prompt templates will improve classification accuracy on the AG News dataset compared to standard fine-tuning, while requiring fewer trainable parameters.

Elements

  • Independent variable: Fine-tuning method (LoRA with prompt templates vs. standard fine-tuning)
  • Dependent variable: Classification accuracy and number of trainable parameters
  • Comparison groups: LoRA with prompt templates vs. standard fine-tuning
  • Baseline/control: Standard fine-tuning of DistilBERT
  • Context/setting: AG News text classification task
  • Assumptions: LoRA with prompt templates will improve efficiency while maintaining or improving accuracy
  • Relationship type: Causation
  • Population: DistilBERT model
  • Timeframe: Not specified
  • Measurement method: Classification accuracy, parameter count, training time

Description

This research explores a simplified approach to enhancing text classification by combining Low-Rank Adaptation (LoRA) with basic prompt templates. Rather than developing a complex integration of these methods, we focus on applying LoRA to a small pre-trained language model (DistilBERT) and incorporating simple, manually-crafted prompt templates for the AG News classification task. The prompt templates will convert classification into a text completion task (e.g., 'This news article is about [MASK]'). We will compare this approach against standard fine-tuning on the same dataset, measuring both classification accuracy and computational efficiency in terms of trainable parameters and training time. This simplified approach makes the research more accessible while still investigating the core hypothesis that combining parameter-efficient fine-tuning with prompting can improve model performance in resource-constrained settings.

Operationalization

Please implement a pilot-based experiment to evaluate LoRA fine-tuning with prompt templates for text classification. The experiment should have three modes controlled by a global variable PILOT_MODE (options: 'MINI_PILOT', 'PILOT', 'FULL_EXPERIMENT').

Data Configuration by Mode:
- MINI_PILOT: Use 10 examples per class (40 total) from training set
- PILOT: Use 100 examples per class (400 total) from training set
- FULL_EXPERIMENT: Use full training set (120K examples)

Implement three models:
1. Baseline: Standard fine-tuned DistilBERT
2. Experimental: LoRA + Prompt Templates
3. Zero-shot: Pre-trained model with prompts (no fine-tuning)

Prompt template to use: '[CLS] {text} [SEP] This news article is about [MASK].'

Training Configuration by Mode:
- MINI_PILOT: 2 epochs, batch size 4
- PILOT: 3 epochs, batch size 8
- FULL_EXPERIMENT: 5 epochs, batch size 16

LoRA Configuration:
- rank=8
- alpha=16
- target_modules=['q_lin', 'v_lin']
- dropout=0.1

Required Metrics:
1. Classification accuracy
2. Number of trainable parameters
3. Training time per epoch
4. Inference time per example
5. F1 score (macro)
6. Confusion matrix

Required Visualizations:

Execution Flow:
