ID: idea_121-simplified

fixed-length-prompt-transfer

Hypothesis

Soft prompts initialized from pre-trained prompts from similar tasks will demonstrate greater transferability in pre-trained language models compared to randomly initialized prompts, as measured by increased feed-forward layer activation overlap.

Elements

  • Independent variable: Prompt initialization method (pre-trained vs. random)
  • Dependent variable: Transferability of soft prompts
  • Comparison groups: Pre-trained prompt initialization vs. random initialization
  • Baseline/control: Randomly initialized prompts
  • Context/setting: Smaller pre-trained language models (DistilBERT or BERT-base)
  • Assumptions: Increased feed-forward layer activation overlap indicates enhanced transferability
  • Relationship type: Causation
  • Population: NLP tasks from the GLUE benchmark
  • Timeframe: Not applicable
  • Measurement method: Feed-forward layer activation overlap

Description

This research investigates how pre-trained prompt initialization affects the transferability of soft prompts in pre-trained language models (PLMs). Rather than exploring dynamic prompt length, this simplified study focuses on fixed-length prompts initialized from pre-trained prompts from similar tasks versus random initialization. The study will measure transferability through feed-forward layer activation overlap in smaller PLMs like DistilBERT or BERT-base. By focusing on a single variable (initialization method) while keeping prompt length fixed, the research provides a more manageable scope while still addressing an important aspect of prompt transferability. The findings could provide insights into efficient knowledge transfer between related NLP tasks and contribute to more effective prompt engineering practices.

Implementation Design

# Experiment Design: Fixed-Length Prompt Transfer

## 1. Implementation Details

### 1.1 Model Selection
Use DistilBERT as the base pre-trained language model due to its smaller size and faster training time while maintaining reasonable performance. The model can be loaded using the Hugging Face Transformers library.

### 1.2 Prompt Implementation
Implement soft prompts as trainable embedding vectors that are prepended to the input embeddings. Each prompt will have a fixed length of 10 tokens. Create two initialization methods:
- Random initialization: Initialize prompt embeddings randomly using normal distribution
- Pre-trained initialization: Train prompt embeddings on a source task, then use these trained embeddings as initialization for the target task

### 1.3 Activation Tracking
Implement a hook mechanism to track neuron activations in the feed-forward layers of DistilBERT. For each layer, record which neurons are activated (activation value > 0) when processing inputs with the prompt. Calculate the overlap between activations from source and target tasks using the Jaccard similarity coefficient.

### 1.4 Training Procedure
1. Select source task (MNLI) and target task (RTE) from the GLUE benchmark
2. For the pre-trained initialization:
- Train soft prompts on the source task until convergence
- Save the trained prompt embeddings
- Initialize the prompt for the target task using these embeddings
- Fine-tune on the target task
3. For random initialization:
- Initialize prompt embeddings randomly
- Train on the target task
4. During training, track and save feed-forward layer activations
5. After training, calculate activation overlap between source and target tasks

## 2. Data Selection

### 2.1 Tasks
Use the following tasks from the GLUE benchmark:
- MNLI (Multi-Genre Natural Language Inference) as the source task
- RTE (Recognizing Textual Entailment) as the target task

These tasks are related (both involve natural language inference) but differ in size and complexity, making them suitable for testing transferability.

### 2.2 Data Processing
Load the datasets using the Hugging Face Datasets library. Use the standard train/validation splits. For MNLI, use a subset of 10,000 examples for training to reduce computational requirements. For RTE, use the full training set (2,490 examples).

## 3. Output Generation and Evaluation

### 3.1 Data to Save
- Trained prompt embeddings for both initialization methods
- Feed-forward layer activation patterns for both methods
- Training logs including loss and accuracy for each epoch
- Final performance metrics on validation sets
- Activation overlap calculations

### 3.2 Evaluation Procedure
1. Calculate feed-forward layer activation overlap between source and target tasks for both initialization methods
2. Compare task performance (accuracy) on the target task between the two initialization methods
3. Analyze the correlation between activation overlap and task performance
4. Perform statistical significance testing (t-test) to determine if differences in overlap and performance are significant

### 3.3 Results Reporting
1. Create tables showing:
- Activation overlap percentages for each layer and each initialization method
- Task performance metrics for each initialization method
2. Generate visualizations:
- Bar charts comparing activation overlap across layers
- Scatter plot showing correlation between activation overlap and task performance
3. Write a summary of findings addressing the research hypothesis

## 4. Extensions (if time permits)
1. Experiment with different prompt lengths (5, 20 tokens)
2. Test additional task pairs (e.g., QQP→MRPC for paraphrase detection)
3. Try a different base model (BERT-base) to check if findings generalize
