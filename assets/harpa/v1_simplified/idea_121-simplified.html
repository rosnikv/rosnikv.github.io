ID: idea_121-simplified

fixed-length-prompt-transfer

Hypothesis

Soft prompts initialized from pre-trained prompts from similar tasks will demonstrate greater transferability in pre-trained language models compared to randomly initialized prompts, as measured by increased feed-forward layer activation overlap.

Elements

  • Independent variable: Prompt initialization method (pre-trained vs. random)
  • Dependent variable: Transferability of soft prompts
  • Comparison groups: Pre-trained prompt initialization vs. random initialization
  • Baseline/control: Randomly initialized prompts
  • Context/setting: Smaller pre-trained language models (DistilBERT or BERT-base)
  • Assumptions: Increased feed-forward layer activation overlap indicates enhanced transferability
  • Relationship type: Causation
  • Population: NLP tasks from the GLUE benchmark
  • Timeframe: Not applicable
  • Measurement method: Feed-forward layer activation overlap

Description

This research investigates how pre-trained prompt initialization affects the transferability of soft prompts in pre-trained language models (PLMs). Rather than exploring dynamic prompt length, this simplified study focuses on fixed-length prompts initialized from pre-trained prompts from similar tasks versus random initialization. The study will measure transferability through feed-forward layer activation overlap in smaller PLMs like DistilBERT or BERT-base. By focusing on a single variable (initialization method) while keeping prompt length fixed, the research provides a more manageable scope while still addressing an important aspect of prompt transferability. The findings could provide insights into efficient knowledge transfer between related NLP tasks and contribute to more effective prompt engineering practices.

Operationalization

Please create an experiment to investigate how pre-trained prompt initialization affects soft prompt transferability in smaller pre-trained language models. The experiment should be implemented with three pilot modes (MINI_PILOT, PILOT, FULL_EXPERIMENT) with the following specifications:

Global Configuration:
- Set PILOT_MODE as a global string variable with possible values: 'MINI_PILOT', 'PILOT', 'FULL_EXPERIMENT'
- Initially set PILOT_MODE = 'MINI_PILOT'
- Use DistilBERT as the base model
- Fixed prompt length of 10 tokens
- Source task: MNLI
- Target task: RTE

Data Scaling:
MINI_PILOT:
- MNLI: Use 100 training examples
- RTE: Use 50 training examples
- Dev set: 20 examples each
- Training epochs: 2

PILOT:
- MNLI: Use 1000 training examples
- RTE: Use 500 training examples
- Dev set: 100 examples each
- Training epochs: 3

FULL_EXPERIMENT:
- MNLI: Use 10000 training examples
- RTE: Full training set
- Dev set: Full dev sets
- Training epochs: Determined by early stopping

Implementation Steps:
1. Load Datasets:
- Use Huggingface Datasets API to load MNLI and RTE
- Subsample based on PILOT_MODE
- Log dataset statistics

2. Initialize Models:
- Load DistilBERT from Huggingface
- Create two conditions:
a) Random initialization (baseline)
b) Pre-trained initialization (experimental)

3. Implement Activation Tracking:
- Add hooks to feed-forward layers
- Track neurons with activation > 0
- Calculate Jaccard similarity for overlap

4. Training Loop:
- Train source task (MNLI) for pre-trained condition
- Save prompt embeddings
- Train both conditions on target task (RTE)
- Log loss, accuracy per epoch
- Save activation patterns

5. Analysis:
- Calculate activation overlap
- Compare performance metrics
- Run bootstrap significance tests
- Generate visualizations:
* Bar charts of activation overlap
* Performance comparisons
