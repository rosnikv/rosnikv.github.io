ID: idea_14-simplified

basic-shap-bias-detection

Hypothesis

SHAP explanations can effectively identify instances of race-related bias in pre-trained text classification models on the RedditBias dataset, as measured by the correlation between high SHAP values for race-related terms and biased predictions identified through manual annotation.

Elements

  • Independent variable: Application of SHAP explanations to model predictions
  • Dependent variable: Detection of race-related biases in model outputs
  • Comparison groups: Predictions with high SHAP values for race-related terms vs. predictions with low SHAP values for race-related terms
  • Baseline/control: Random selection of predictions (without using SHAP values)
  • Context/setting: A subset of the RedditBias dataset (100-200 examples)
  • Assumptions: ['Pre-trained text classification models contain detectable biases', 'SHAP values accurately reflect feature importance']
  • Relationship type: Correlation
  • Population: Predictions from pre-trained text classification models
  • Timeframe: Single-point analysis
  • Measurement method: Precision and recall of bias detection

Description

This research investigates the effectiveness of SHAP (SHapley Additive exPlanations) explanations in identifying race-related biases in pre-trained text classification models. Using a subset of the RedditBias dataset, the study will analyze how SHAP values highlight the importance of race-related features in model predictions. The research will implement a simple bias detection pipeline that extracts SHAP values for text inputs, identifies potentially biased predictions by examining the contribution of race-related terms to the model's decisions, and evaluates the effectiveness of this approach in detecting biased outputs. This work provides a foundation for understanding how explainability methods can be leveraged for bias detection in NLP systems.

Operationalization

Please implement a bias detection experiment using SHAP explanations on text classification models. The experiment should be implemented with three pilot modes (MINI_PILOT, PILOT, FULL_EXPERIMENT), defined by the PILOT_MODE variable.

Pilot Modes:
- MINI_PILOT: Use 10 examples from training set, 2-minute runtime target
- PILOT: Use 50 examples from training set, 25 from dev set, 30-minute runtime target
- FULL_EXPERIMENT: Use full dataset (to be run only after human verification)

Required Steps:

1. Dataset Preparation:
- Use Huggingface Datasets to load RedditBias dataset
- For MINI_PILOT: Select first 10 examples from training set
- For PILOT: Select first 50 training examples, 25 dev examples
- For FULL_EXPERIMENT: Use complete dataset with proper train/dev/test splits

2. Model Setup:
- Load bert-base-uncased from Huggingface
- Fine-tune on the selected training examples
- Use gpt-4o-mini to help generate a list of race-related terms to track

3. SHAP Analysis:
- Compute SHAP values for each prediction
- Focus on race-related terms identified earlier
- Store SHAP values in CSV format

4. Implement Three Detection Methods:
- Method 1 (Baseline): Random flagging of examples as biased
- Method 2 (Baseline): Keyword-based detection using race-related terms
- Method 3 (Experimental): SHAP-based detection

5. Manual Annotation:
- For MINI_PILOT: Annotate all 10 examples
- For PILOT: Annotate 50 examples
- Use gpt-4o-mini to assist in annotation, but require human verification

6. Evaluation:
- Calculate precision, recall, F1 for each method
- Create visualizations of SHAP values
- Use bootstrap resampling to compare methods

7. Output Requirements:
- Log all major steps and decisions
- Generate CSV files with SHAP values
- Create plots comparing methods
- Output summary statistics

The experiment should first run in MINI_PILOT mode. If successful, proceed to PILOT mode. Stop before FULL_EXPERIMENT mode for human verification.

Success Criteria:
1. All code runs without errors
2. SHAP values are computed correctly
3. All three detection methods are implemented
4. Evaluation metrics are calculated
5. Visualizations are generated
6. Bootstrap comparison shows clear differences between methods

Please implement appropriate error handling and logging throughout. The experiment should be reproducible with the same random seed.
