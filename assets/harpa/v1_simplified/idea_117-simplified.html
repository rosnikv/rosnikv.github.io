Hypothesis

A two-step retrieval approach will improve F1-score in biomedical question-answering tasks compared to a single-time retrieval approach.

Elements

  • Independent variable: Retrieval approach (single-time vs. two-step)
  • Dependent variable: F1-score in biomedical question-answering tasks
  • Comparison groups: Single-time retrieval vs. Two-step retrieval
  • Baseline/control: Single-time retrieval approach
  • Context/setting: Biomedical question-answering tasks using a subset of BioASQ dataset
  • Assumptions: The two-step retrieval approach can be effectively implemented with basic programming skills and limited computational resources
  • Relationship type: causation

  • Timeframe: Not specified
  • Measurement method: F1-score

Description

This research investigates the effectiveness of a simple multi-time retrieval approach compared to single-time retrieval in biomedical question-answering tasks. Rather than implementing a full modular RAG system with multiple external components, this study focuses on comparing a basic two-step retrieval process against the conventional single-step retrieval method. The two-step approach will first retrieve documents based on the initial query, then perform a second retrieval based on the refined context. This simplified approach aims to determine whether even a basic implementation of multi-time retrieval can improve performance on biomedical QA tasks, providing insights into the potential benefits of more complex dynamic retrieval systems while being feasible for implementation with limited resources.

Implementation Design

# Experiment Design: Comparing Single-time vs. Two-step Retrieval for Biomedical QA

## 1. Implementation Details

### A. Retrieval Systems

#### Single-time Retrieval (Baseline)
1. Create a document retrieval function that takes a question as input
2. Use a pre-trained biomedical embedding model (PubMedBERT) to encode the question
3. Calculate similarity scores between the question embedding and document embeddings
4. Retrieve the top-k (k=5) most relevant documents
5. Concatenate these documents and pass them along with the question to the LLM to generate an answer

#### Two-step Retrieval (Experimental)
1. Perform initial retrieval as in the baseline (steps 1-4)
2. Pass the question and the initially retrieved documents to the LLM with a prompt to generate a refined query
3. Use this refined query to perform a second retrieval operation
4. Retrieve the top-k (k=5) most relevant documents based on this refined query
5. Concatenate these documents and pass them along with the original question to the LLM to generate an answer

### B. Answer Generation
1. For both approaches, use the same LLM (GPT-3.5-turbo) with the same prompt template
2. The prompt should instruct the model to answer the biomedical question based on the provided context
3. For factoid questions, instruct the model to provide concise, direct answers

## 2. Data

### A. Dataset Selection
1. Use a subset of the BioASQ dataset, specifically focusing on factoid questions
2. Select 100 questions for the pilot experiment
3. Ensure the questions cover diverse biomedical topics

### B. Document Corpus
1. Use the PubMed abstracts provided with the BioASQ dataset
2. Pre-process the abstracts by removing stop words and applying stemming
3. Create document embeddings using PubMedBERT and store them for efficient retrieval

## 3. Evaluation and Output

### A. Metrics Calculation
1. Calculate F1-score for each approach by comparing generated answers with gold standard answers
2. For factoid questions, exact match and partial match scores should be calculated
3. Calculate retrieval precision and recall for both approaches

### B. Output Generation
1. Save all generated answers in a CSV file with columns: question_id, question, gold_answer, baseline_answer, experimental_answer
2. Save retrieval statistics in a separate CSV file with columns: question_id, baseline_retrieved_docs, experimental_retrieved_docs, relevant_docs

### C. Results Reporting
1. Calculate and report mean F1-scores for both approaches
2. Perform statistical significance testing (paired t-test) to determine if the difference is significant
3. Generate a table comparing the performance metrics of both approaches
4. Perform error analysis on a sample of questions where one approach outperformed the other

## 4. Implementation Steps

1. Set up the environment with required libraries
2. Load and preprocess the BioASQ dataset
3. Implement the document embedding and retrieval functions
4. Implement the single-time retrieval pipeline
5. Implement the two-step retrieval pipeline
6. Set up the evaluation framework
7. Run both approaches on the test set
8. Calculate metrics and perform statistical analysis
9. Generate result tables and visualizations
10. Document findings and insights
