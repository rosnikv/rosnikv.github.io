ID: idea_40-simplified

pruning-for-factual-summarization

Hypothesis

Different pruning techniques and sparsity rates will have varying effects on the factual consistency of a BART model fine-tuned on the XSum dataset, with magnitude-based pruning at moderate sparsity levels (30-50%) maintaining or potentially improving factual consistency compared to the unpruned model.

Elements

  • Independent variables: Pruning technique (magnitude-based, structured, random) and pruning rate (10%, 30%, 50%, 70%)
  • Dependent variables: Factual consistency scores and ROUGE scores
  • Control/baseline: Unpruned BART model fine-tuned on XSum
  • Context/setting: XSum dataset (test split)
  • Population: BART-based abstractive summarization model
  • Measurement methods: FactCC or BERTScore for factual consistency, ROUGE for summary quality

Description

This research investigates how model pruning affects the factual consistency of pre-trained abstractive summarization models. While the original research combined contrastive reward learning with pruning, this simplified approach focuses solely on how different pruning techniques and rates impact a model's tendency to generate factual summaries. The study will use a pre-trained BART model fine-tuned on the XSum dataset, applying various pruning methods at different sparsity levels, and evaluating the resulting models' factual consistency using automated metrics. This research addresses the practical question of whether pruning, typically used for efficiency, might have unexpected benefits or drawbacks for factual consistency in summarization.

Implementation Design

This experiment investigates how different pruning techniques and rates affect the factual consistency of abstractive summarization models. Follow these steps:

1. Setup:
- Install required libraries: transformers, datasets, torch, evaluate, bert_score
- Load a pre-trained BART model fine-tuned on XSum (use 'facebook/bart-large-xsum' from Hugging Face)
- Load the XSum test dataset (or a subset of 1000 examples for faster experimentation)

2. Implement pruning techniques:
- Magnitude-based pruning: Remove weights with the smallest absolute values
- Structured pruning: Remove entire neurons or filters
- Random pruning: Remove weights randomly (as a control)
- For each technique, implement pruning at rates of 10%, 30%, 50%, and 70%

3. Evaluation:
- For each pruned model and the unpruned baseline, generate summaries for the test examples
- Calculate factual consistency using BERTScore (comparing generated summaries to source documents)
- Calculate ROUGE scores (comparing generated summaries to reference summaries)
- Track inference time and model size for each configuration

4. Analysis:
- Compare factual consistency and ROUGE scores across pruning techniques and rates
- Identify if any pruning configuration maintains or improves factual consistency
- Analyze the trade-off between model size/speed and performance
- Perform statistical significance testing (paired t-tests) to validate findings

5. Output and reporting:
- Save all generated summaries in a CSV file with columns for document ID, source text, reference summary, generated summary, and metrics
- Create plots showing the relationship between pruning rate and performance metrics for each technique
- Generate a summary table with all configurations and their performance
- Write a brief report analyzing the findings and their implications

The experiment should be reproducible, so set random seeds appropriately and document all hyperparameters used.
