ID: idea_49-simplified

rule-guided-anyburl

Hypothesis

Implementing a rule-guided path sampling strategy in AnyBURL will improve computational efficiency while maintaining prediction quality in knowledge graph completion on FB15k-237, compared to standard AnyBURL.

Elements

  • Independent variable: Implementation of rule-guided path sampling in AnyBURL
  • Dependent variable: ['Computational efficiency (runtime)', 'Prediction quality (Hits@10, MRR)']
  • Comparison groups: ['AnyBURL with rule-guided path sampling', 'Standard AnyBURL']
  • Baseline/control: Standard AnyBURL
  • Context/setting: Knowledge graph completion on FB15k-237 dataset
  • Assumptions: ['Rule confidence scores from previous iterations are indicative of path quality', 'FB15k-237 is representative of larger knowledge graphs']
  • Relationship type: Causation
  • Population: Knowledge graph completion tasks on FB15k-237
  • Timeframe: Not specified
  • Measurement method: Runtime measurements and standard KG completion metrics (Hits@10, MRR)

Description

This research explores a simplified approach to improving AnyBURL's performance in knowledge graph completion by implementing a rule-guided path sampling strategy. Instead of using complex BERT models and reinforcement learning, this project focuses on developing a heuristic-based approach that prioritizes promising paths based on rule confidence scores from previous iterations. The method aims to enhance computational efficiency by focusing computational resources on paths that have historically produced high-quality rules, potentially reducing runtime while maintaining or improving prediction quality. The research will be conducted on a manageable subset of the FB15k-237 dataset (a smaller version of Freebase), making it feasible for implementation with limited computational resources while still providing meaningful insights into knowledge graph completion techniques.

Operationalization

- Create a global PILOT_MODE variable that can be set to 'MINI_PILOT', 'PILOT', or 'FULL_EXPERIMENT'
- MINI_PILOT should use 1% of FB15k-237 training data, 2 iterations, max path length 2
- PILOT should use 10% of FB15k-237 training data, 3-5 iterations, max path length 3

EXPERIMENT SETUP:
1. Data Preparation:
- Download FB15k-237 dataset
- Split into train/validation/test (80/10/10)
- For MINI_PILOT and PILOT, randomly sample the specified percentage from training data

2. System Configuration:
- Set up standard AnyBURL (baseline)
- Implement rule-guided AnyBURL (experimental):
* Store rule confidence scores between iterations
* Implement path scoring based on previous confidence scores
* Add exploration/exploitation parameter (default: 0.2 exploration)

3. Evaluation Pipeline:
For each PILOT_MODE:
a) Run baseline AnyBURL:
- Log runtime per iteration
- Save rules and their confidence scores
- Calculate Hits@10 and MRR on validation set
b) Run experimental AnyBURL:
- Same measurements as baseline
c) Generate comparison metrics:
- Runtime differences
- Hits@10 and MRR differences

4. Visualization:
- Create line plots comparing runtime per iteration
- Create bar plots comparing Hits@10 and MRR
