ID: idea_123-simplified

factual-consistency-evaluation

Hypothesis

Implementing specific prompt engineering techniques will improve the factual consistency of conversational AI responses, as measured by a binary classification evaluation framework using reference documents.

Elements

  • Independent variable: Prompt engineering techniques (standard prompting vs. factual emphasis prompting)
  • Dependent variable: Factual consistency score of AI-generated responses
  • Comparison groups: Responses generated with standard prompting vs. responses generated with factual emphasis prompting
  • Baseline/control: Standard prompting without factual emphasis
  • Context/setting: Question-answering tasks with reference documents
  • Assumptions: Pre-trained language models have sufficient knowledge to generate factually consistent responses when properly prompted
  • Relationship type: Causation
  • Population: Conversational AI responses to factual questions
  • Timeframe: Not time-dependent
  • Measurement method: Binary classification of response-document consistency

Description

This research explores a simplified approach to improving factual consistency in conversational AI systems. Rather than implementing both Factual Ablation and Edge Computing, this study focuses solely on developing and evaluating a lightweight factual consistency evaluation framework. The research will implement a binary classifier to assess whether AI-generated responses align with provided reference documents. Using pre-trained language models and publicly available datasets, the study will measure how different prompt engineering techniques affect factual consistency scores. This approach reduces technical complexity while still addressing the important challenge of ensuring AI systems provide factually accurate information.

Implementation Design

This experiment evaluates how prompt engineering techniques affect factual consistency in AI-generated responses. Follow these steps:

1. Data Preparation:
- Download the FEVER dataset (Fact Extraction and VERification), which contains claims and evidence documents.
- Select 100 claim-evidence pairs for the pilot study.
- Split into 70% training and 30% testing sets.

2. Factual Consistency Classifier:
- Fine-tune a pre-trained BERT model to classify whether a response is consistent with a reference document.
- Use the training portion of your dataset to fine-tune the model.
- The input format should be: [CLS] reference_document [SEP] response [SEP]
- The output is a binary classification: consistent (1) or inconsistent (0).
- Evaluate the classifier on the test set to ensure it achieves at least 75% accuracy.

3. Prompt Engineering Techniques:
- Implement two prompting approaches:
a. Standard prompting: "Answer the following question based on your knowledge: [QUESTION]"
b. Factual emphasis prompting: "Answer the following question accurately based on the provided information. Only include facts that are supported by the reference document: [REFERENCE_DOCUMENT]. Question: [QUESTION]"

4. Response Generation:
- Use GPT-3.5-turbo to generate responses for each question in the test set using both prompting techniques.
- Store the generated responses along with the corresponding questions and reference documents.

5. Evaluation:
- Pass each (reference document, generated response) pair through your factual consistency classifier.
- Calculate the factual consistency score (percentage of responses classified as consistent) for each prompting technique.
- Calculate precision, recall, and F1 score for each approach.

6. Analysis:
- Compare the factual consistency scores between the two prompting techniques.
- Perform statistical significance testing (e.g., paired t-test) to determine if the difference is statistically significant.
- Conduct error analysis on inconsistent responses to identify common patterns of factual errors.

7. Output and Reporting:
- Save all generated responses, consistency scores, and evaluation metrics to CSV files.
- Create visualizations comparing the performance of the two prompting techniques.
- Write a brief report summarizing the methodology, results, and conclusions.

The experiment should be implemented in Python using the Hugging Face Transformers library for the BERT model and the OpenAI API for GPT-3.5-turbo. All code should be modular and well-documented to facilitate future extensions.

a) Baseline (standard prompting):

Your task is to verify claims using only the provided evidence, without any external knowledge.\n\nClaim: [CLAIM]\nEvidence: [EVIDENCE]\n\nAnalyze if the claim is supported or refuted by the evidence.
