Hypothesis

Prompt tuning with GPT-2 small (124M) will result in improved BLEU scores for text completion tasks compared to zero-shot prompting.

Elements

  • Independent variable: Prompt tuning with GPT-2 small
  • Dependent variable: BLEU scores for text completion tasks
  • Comparison groups: Prompt tuning with GPT-2 small vs. zero-shot prompting
  • Baseline/control: Zero-shot prompting with GPT-2 small
  • Context/setting: Text completion tasks on a curated subset of the CNN/Daily Mail dataset
  • Assumptions: BLEU scores are a valid measure of performance improvement
  • Relationship type: causation
  • Population: News articles from CNN/Daily Mail dataset (subset of 100-200 articles)
  • Timeframe: Not time-dependent
  • Measurement method: BLEU scores

Description

This research investigates the effectiveness of prompt tuning on the smaller GPT-2 model (124M parameters) for text completion tasks. Prompt tuning is a parameter-efficient fine-tuning method that only updates a small set of continuous prompt embeddings while keeping the pre-trained model frozen. This study will compare prompt tuning against a baseline of zero-shot prompting on a small, well-defined dataset of text completion tasks. The research aims to determine whether prompt tuning with minimal trainable parameters can improve text completion performance as measured by BLEU scores, providing insights into efficient adaptation methods for smaller language models.

Implementation Design

# Experiment Design: Prompt Tuning for Text Completion with GPT-2 Small

## 1. Implementation Details

### 1.1 Model Setup
- Use the GPT-2 small model (124M parameters) from Hugging Face's Transformers library.
- For the prompt tuning approach:
- Initialize a set of 20 trainable prompt embeddings (soft prompts) with random values.
- These embeddings will be prepended to the input embeddings.
- Only these prompt embeddings will be updated during training, while the GPT-2 model parameters remain frozen.
- For the baseline approach:
- Use the same GPT-2 small model with zero-shot prompting (no parameter updates).

### 1.2 Dataset Preparation
- Download a subset of the CNN/Daily Mail dataset using the Hugging Face datasets library.
- Select 100-200 articles for the full experiment (50 for the pilot).
- For each article:
- Use the first paragraph as the input prompt.
- Use the second paragraph as the target completion.
- Split the dataset into 80% training and 20% test sets.

### 1.3 Training Process
- For prompt tuning:
- Train the prompt embeddings for 10 epochs using the training set.
- Use a learning rate of 0.01 with Adam optimizer.
- Use a batch size of 4 (adjust based on available GPU memory).
- Use cross-entropy loss between the model's predictions and the target completions.
- For zero-shot baseline:
- No training is needed; the model will be used as-is.

## 2. Experiment Execution

### 2.1 Pilot Experiment
- Run the pilot with 50 articles.
- Train the prompt tuning model as described above.
- Generate completions using both the prompt-tuned model and the zero-shot baseline.
- Calculate BLEU scores and perplexity for both approaches.
- If the pilot shows promising results, proceed to the full experiment.

### 2.2 Full Experiment
- Expand to the full dataset of 100-200 articles.
- Repeat the training and evaluation process.
- Conduct an ablation study by varying the number of trainable prompt tokens (5, 10, 20, 50) to analyze the impact of prompt length.

## 3. Evaluation and Output

### 3.1 Metrics Calculation
- Calculate BLEU scores using the NLTK library, comparing generated completions against reference second paragraphs.
- Calculate perplexity on the test set for both approaches.

### 3.2 Output Generation
- Save the trained prompt embeddings to a file for future use.
- Save all generated completions from both approaches in a CSV file with columns: article_id, input_paragraph, reference_completion, prompt_tuned_completion, zero_shot_completion.
- Generate a results summary JSON file containing:
- Average BLEU scores for both approaches
- Average perplexity for both approaches
- Standard deviations for all metrics
- p-values from statistical significance tests

### 3.3 Analysis and Reporting
- Perform a paired t-test to determine if the difference in BLEU scores is statistically significant.
- Create visualizations comparing the performance of both approaches.
- Analyze examples where prompt tuning performs particularly well or poorly compared to the baseline.
- Report the number of trainable parameters in prompt tuning vs. the total model parameters to highlight parameter efficiency.

## 4. Implementation Notes
- Use PyTorch for implementing the prompt tuning mechanism.
- Use Hugging Face's Transformers library for loading and using the GPT-2 model.
- Use NLTK for calculating BLEU scores.
- All code should be organized in modular functions with clear documentation.
- Save checkpoints during training to prevent data loss.
- Log all experimental details including random seeds for reproducibility.
