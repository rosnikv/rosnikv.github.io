ID: idea_137-simplified

temporal-qa-enhancement

Hypothesis

Adding explicit temporal context to questions through prompt engineering will improve the accuracy of pre-trained language models on temporally-sensitive questions in the CommonsenseQA dataset.

Elements

  • Independent variable: Presence of explicit temporal context in questions
  • Dependent variable: Accuracy on temporally-sensitive questions from CommonsenseQA
  • Comparison groups: Questions with vs. without explicit temporal context
  • Baseline/control: Standard prompting without temporal context
  • Context/setting: Subset of CommonsenseQA dataset focusing on temporal questions
  • Assumptions: Pre-trained language models have implicit temporal knowledge that can be better accessed with explicit prompting
  • Relationship type: Causation
  • Population: Pre-trained language models (specifically GPT-3.5-turbo)
  • Timeframe: Not applicable
  • Measurement method: Accuracy on temporally-sensitive questions

Description

This research explores how adding simple temporal context to questions can improve commonsense question answering. Rather than implementing complex Temporal Knowledge Graphs, this project focuses on augmenting existing pre-trained language models with basic temporal information through prompt engineering. The study will examine whether adding explicit temporal markers (like 'before', 'after', 'during') to questions in the CommonsenseQA dataset improves model performance. This approach requires minimal resources while still addressing the important challenge of temporal reasoning in language models, potentially yielding insights about how simple modifications can enhance model performance on time-sensitive questions.

Operationalization

Please build an experiment to test whether adding explicit temporal context to questions improves performance on commonsense QA tasks. The experiment should support three modes (MINI_PILOT, PILOT, FULL_EXPERIMENT) with the following specifications:

MINI_PILOT (Debug/Verification, ~5min runtime):
- Use 10 questions from CommonsenseQA training set
- Filter for temporal questions (containing words: before, after, during, while, then)
- Test both baseline (original) and experimental (temporal-enhanced) versions

PILOT (Preliminary Results, ~1hr runtime):
- Use 100 questions from training set for initial testing
- Use 50 questions from dev set for evaluation
- Same filtering and testing as mini-pilot

FULL_EXPERIMENT (Complete Study, multiple hours):
- Use 1000 questions from training set
- Use 200 questions from dev set for evaluation
- Use 200 questions from test set for final evaluation

Specific Implementation Requirements:

1. DATA PREPARATION
- Use Huggingface Datasets to load CommonsenseQA
- Filter for temporal questions using regex pattern matching
- For each question, create two versions:
* Baseline: Original question
* Experimental: Add explicit temporal framing
Example:
Original: "What happens after turning on the shower?"
Enhanced: "Consider the temporal sequence: What happens AFTER turning on the shower? Think about the order of events."

2. MODEL SETUP
- Use gpt-4o-mini (replacing GPT-3.5-turbo per special instructions)
- Create consistent prompting template:
Baseline: "Answer this commonsense question: [QUESTION]"
Experimental: "Answer this temporal commonsense question, paying attention to the sequence of events: [QUESTION]"

3. EVALUATION
- For each question:
* Record original question, enhanced question, model answers, correct answer
* Calculate accuracy for both conditions
- Use bootstrap resampling to test statistical significance
- Generate plots comparing accuracies

4. OUTPUT
- Save results to CSV with columns:
* question_id, original_question, enhanced_question, original_answer, enhanced_answer, correct_answer, original_correct, enhanced_correct
- Generate summary statistics:
* Overall accuracy for both conditions
* Bootstrap confidence intervals
* Effect size estimates
- Create accuracy comparison plot

IMPORTANT NOTES:
1. Start with MINI_PILOT mode
2. If successful, proceed to PILOT mode
3. Stop after PILOT mode - do not proceed to FULL_EXPERIMENT
4. Log all major steps and any errors
5. Include seed values for reproducibility

Success Criteria:
1. Successfully loads and filters CommonsenseQA dataset
2. Generates enhanced versions of questions
3. Obtains model responses for both conditions
4. Calculates accuracy and statistical significance
5. Generates all required outputs and visualizations
