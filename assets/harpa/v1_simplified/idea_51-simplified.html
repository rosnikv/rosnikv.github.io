ID: idea_51-simplified

simplified-span-aste

Hypothesis

Incorporating span-level interaction components into a basic LSTM model will significantly improve the precision of aspect sentiment triplet extraction for multi-word expressions compared to standard LSTM models without span-level modeling.

Elements

  • Independent variable: Incorporation of span-level interaction components into LSTM model
  • Dependent variable: Precision of aspect sentiment triplet extraction
  • Comparison groups: LSTM with span-level interaction vs. standard LSTM model
  • Baseline/control: Standard LSTM model without span-level modeling
  • Context/setting: Multi-word expressions in the SemEval dataset
  • Assumptions: The span-level interaction will lead to meaningful improvement
  • Relationship type: Causation
  • Population: Text samples from SemEval dataset
  • Timeframe: Not specified
  • Measurement method: Precision, recall, and F1 score for aspect sentiment triplet extraction

Description

This research explores a simplified approach to aspect sentiment triplet extraction (ASTE) by focusing on span-level interactions for multi-word expressions. Rather than implementing a full Syntax-Enhanced Graph Convolutional Network, this project will enhance a basic LSTM-based model with a span representation component that explicitly models interactions between aspect and opinion spans. The research aims to demonstrate that even a simpler model architecture can achieve meaningful improvements in ASTE performance when incorporating span-level interactions, particularly for multi-word expressions. The study will use a subset of the SemEval dataset to evaluate the effectiveness of the proposed approach compared to a standard LSTM baseline without span-level modeling.

Operationalization

Please implement a pilot experiment comparing a baseline LSTM model against an enhanced LSTM model with span-level interaction components for aspect sentiment triplet extraction (ASTE). The experiment should follow these specifications:

1. PILOT MODES AND DATASET:
Implement three pilot modes (controlled by PILOT_MODE global variable):
- MINI_PILOT: Use 50 sentences from SemEval 2014 Task 4 (Restaurant domain) training set
- PILOT: Use 500 sentences from training set, evaluate on 100 sentences from dev set
- FULL_EXPERIMENT: Use full dataset (but do not implement this mode yet)

Use the Huggingface Datasets API to load the SemEval dataset.

2. MODEL IMPLEMENTATIONS:
a) Baseline LSTM:
- Bidirectional LSTM taking GloVe embeddings (100d) as input
- Single feed-forward layer for classification
- BIO tagging scheme for aspects and opinions

b) Enhanced LSTM with Span Interaction:
- Same base architecture as baseline
- Add span representation layer that:
* Identifies spans from BIO tags
* Creates span representations using max-pooling
* Computes simple attention between aspect/opinion spans

3. TRAINING PROCEDURE:
- MINI_PILOT: 5 epochs
- PILOT: 10 epochs
- Use validation set for early stopping
- Use gpt-4o-mini for any LLM components

4. EVALUATION AND ANALYSIS:
a) For each model, compute:
- Precision, recall, F1 for aspect extraction
- Precision, recall, F1 for opinion extraction
- Precision, recall, F1 for complete triplets

b) Error Analysis:
- Categorize errors (missed spans, wrong boundaries, etc)
- Compare performance on single vs multi-word expressions

c) Statistical Testing:
- Use bootstrap resampling to test significance
- Generate performance comparison plots

5. OUTPUT REQUIREMENTS:
a) Save to results directory:
- Model checkpoints
- Performance metrics (JSON)
- Error analysis report (JSON)
- Visualization PDFs

b) Log File Requirements:
- Training progress
- Validation metrics
- Error examples
- Final test results

6. EXECUTION ORDER:
1. Run MINI_PILOT first
2. If successful, run PILOT
3. Stop before FULL_EXPERIMENT

Please implement this experiment focusing on clean code organization and proper error handling. Use the logger for all important events and error cases. Generate clear visualizations comparing model performance.
