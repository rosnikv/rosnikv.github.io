ID: idea_84-simplified

DBT-Enhanced-Prompting

Hypothesis

Incorporating Dialectical Behavior Therapy (DBT) principles into prompts for large language models will enhance their performance on empathy-based tasks compared to standard prompting approaches.

Elements

  • Independent variable: Prompting strategy (Standard vs. DBT-enhanced)
  • Dependent variable: Performance on empathy-based tasks
  • Comparison groups: Standard prompting vs. DBT-enhanced prompting
  • Baseline/control: Standard prompting approach
  • Context/setting: Large language models (specifically one accessible model like GPT-3.5-turbo)
  • Assumptions: DBT principles can be effectively incorporated into prompts
  • Relationship type: Causation
  • Population: Single large language model
  • Timeframe: Not specified
  • Measurement method: Automated metrics and small-scale evaluation

Description

This research explores how incorporating principles from Dialectical Behavior Therapy (DBT) into prompting strategies can enhance the empathetic capabilities of large language models. Rather than implementing the full integration of DBT with Tree of Thought prompting, this simplified study focuses on comparing standard prompts with DBT-enhanced prompts across a small set of empathy-based scenarios. DBT principles such as Wise Mind (balancing emotional and logical reasoning) and Validation (acknowledging emotions) will be incorporated into prompt templates. The research aims to determine whether these DBT-enhanced prompts lead to responses that are perceived as more empathetic, balanced, and helpful when dealing with emotionally complex scenarios. This approach addresses the need for more empathetic AI interactions while being feasible for implementation with limited resources and technical expertise.

Operationalization

Please create an experiment to evaluate how DBT-enhanced prompting affects LLM empathy. The experiment should support three modes (PILOT_MODE): MINI_PILOT, PILOT, and FULL_EXPERIMENT.

Scenarios and Prompts:
1. Create emotional scenarios:
MINI_PILOT: 3 scenarios (grief, anxiety, frustration)
PILOT: 5 scenarios (adding disappointment, anger)
FULL_EXPERIMENT: 10 scenarios (adding loneliness, fear, shame, guilt, joy)

2. For each scenario, create two prompt types:
a. Standard prompt: "Please respond empathetically to the following situation: [scenario]"
b. DBT-enhanced prompt: "Using principles from Dialectical Behavior Therapy, please respond to the following situation. Balance logical understanding (Wise Mind) with emotional validation, acknowledge the person's feelings without judgment (Validation), and offer practical effectiveness. Situation: [scenario]"

3. Run configurations:
MINI_PILOT: 3 runs per scenario-prompt combination
PILOT: 5 runs per scenario-prompt combination
FULL_EXPERIMENT: 10 runs per scenario-prompt combination

Experiment Flow:
1. Initialize the logger for debugging and progress tracking
2. Use gpt-4o-mini for all LLM calls (as specified in conditioning)
3. For each scenario:
a. Run standard prompt multiple times
b. Run DBT-enhanced prompt multiple times
c. Store responses in a structured format

Analysis:
1. Implement automated metrics:
a. Use WordNet to identify and count empathetic phrases
b. Count emotional acknowledgments
c. Calculate response length

2. Create evaluation scores (1-5 scale):
a. Validation score
b. Balance score
c. Helpfulness score

3. Statistical Analysis:
a. Use bootstrap resampling to compare standard vs DBT-enhanced prompts
b. Generate p-values for significance testing

4. Visualization:
a. Create bar plots comparing metrics between conditions
b. Include error bars for variation

Output Requirements:
1. Save all raw responses to a JSON file
2. Generate CSV with metrics and scores
3. Create PDF with visualization plots
4. Generate summary report including:
- Descriptive statistics
- Statistical test results
- Example responses
- Limitations discussion

Pilot Process:
1. Run MINI_PILOT first
2. If successful, run PILOT
3. Stop after PILOT (await human verification before FULL_EXPERIMENT)

Success Criteria:
1. All responses successfully collected
2. Metrics calculated without errors
3. Statistical analysis completed
4. Visualizations generated
5. Summary report produced
