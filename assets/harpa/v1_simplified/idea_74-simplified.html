ID: idea_74-simplified

minhash-semantic-comparison

Hypothesis

Semantic deduplication will be more effective than MinHash deduplication at preserving semantic diversity while reducing redundancy in a text corpus, leading to improved novelty in text generated by a language model fine-tuned on the deduplicated data.

Elements

  • Independent variable: Deduplication method (MinHash vs. semantic)
  • Dependent variable: Text novelty and repetition in generated content
  • Comparison groups: MinHash deduplication vs. semantic deduplication
  • Baseline/control: No deduplication (original corpus)
  • Context/setting: Small text corpus (e.g., subset of Wikipedia or news articles)
  • Assumptions: Both deduplication methods can be effectively implemented with limited computational resources
  • Relationship type: Comparative effectiveness
  • Population: Small language model fine-tuned on deduplicated data
  • Timeframe: Short-term experiment (1-2 months)
  • Measurement method: N-gram overlap and repetition metrics

Description

This research compares the effectiveness of MinHash deduplication versus semantic deduplication on a small corpus of text data. Rather than combining both methods into a hybrid approach, this simplified study focuses on implementing each method separately and evaluating their individual impact on text novelty and repetition. The research will use a pre-existing text dataset (such as a subset of Wikipedia or a small collection of news articles) and apply both deduplication techniques independently. The effectiveness of each method will be measured by examining the reduction in dataset size, the diversity of remaining content, and the impact on a small fine-tuned language model's ability to generate novel text without repetition.

Implementation Design

This experiment compares MinHash and semantic deduplication methods on a small text corpus. Follow these steps:

1. Data Preparation:
- Download a subset of Wikipedia articles (approximately 5,000 articles) using the Wikipedia API
- Preprocess the text by removing HTML tags, citations, and special characters
- Split each article into paragraphs to create the document units for deduplication

2. Implement MinHash Deduplication:
- Use the datasketch library to implement MinHash with 128 hash functions
- Create MinHash signatures for each paragraph
- Use Locality Sensitive Hashing (LSH) with a Jaccard similarity threshold of 0.7 to identify near-duplicates
- Remove identified duplicates to create the MinHash-deduplicated corpus

3. Implement Semantic Deduplication:
- Use the sentence-transformers library to generate embeddings for each paragraph using the 'all-MiniLM-L6-v2' model
- Calculate cosine similarity between paragraph embeddings
- Set a similarity threshold of 0.85 to identify semantic duplicates
- Remove identified duplicates to create the semantically-deduplicated corpus

4. Create Baseline Corpus:
- Randomly sample the original corpus to create a random-reduced corpus with the same size as the deduplicated corpora

5. Evaluate Corpus Characteristics:
- Calculate corpus reduction rate for each method
- Measure n-gram diversity (for n=1,2,3,4) in each corpus
- Visualize the distribution of document similarities in each corpus

6. Fine-tune Language Models:
- Use the Hugging Face Transformers library to fine-tune DistilGPT-2 on each corpus (original, MinHash-deduplicated, semantically-deduplicated, and random-reduced)
- Use the same hyperparameters for all fine-tuning runs (3 epochs, batch size 4, learning rate 5e-5)

7. Evaluate Generated Text:
- Generate 100 text samples from each fine-tuned model using the same prompts
- Calculate repetition rate by measuring the percentage of repeated n-grams in generated text
- Measure novelty by calculating n-gram overlap between generated text and training corpus

8. Analysis and Reporting:
- Compare the performance of each deduplication method using the metrics defined above
- Create visualizations showing the differences in corpus characteristics and model performance
- Perform statistical significance testing (t-tests) to determine if differences are statistically significant
- Write a report summarizing the findings, including tables and figures

Save all intermediate results (deduplicated corpora, model checkpoints, evaluation metrics) for potential follow-up experiments. Document any challenges or limitations encountered during implementation.

Operationalization

Please implement a comparison study of MinHash versus semantic deduplication methods, structured as a series of pilot experiments. The experiment should include a global PILOT_MODE variable with three settings: 'MINI_PILOT', 'PILOT', and 'FULL_EXPERIMENT'. The implementation should automatically stop after the PILOT phase.

Pilot Configurations:
- MINI_PILOT: Use 50 Wikipedia articles, 2 prompts for generation, 1 training epoch
- PILOT: Use 500 Wikipedia articles, 10 prompts, 2 training epochs
- FULL_EXPERIMENT: Use 5000 articles, 100 prompts, 3 training epochs

Implementation Steps:

1. Dataset Preparation:
- Use the Huggingface Datasets API to load a subset of Wikipedia articles
- MINI_PILOT: 50 random articles
- PILOT: 500 random articles
- FULL_EXPERIMENT: 5000 random articles
- Split articles into paragraphs (documents)
- Clean text (remove markup, citations)

2. Implement Deduplication Methods:
a) MinHash:
- Use datasketch library
- 32 hash functions for MINI_PILOT, 64 for PILOT, 128 for FULL_EXPERIMENT
- Jaccard similarity threshold: 0.7
b) Semantic:
- Use gpt-4o-mini to generate embeddings (via LLM proxy)
- Cosine similarity threshold: 0.85
c) Random baseline:
- Randomly sample same number of documents as removed by deduplication

3. Evaluation Pipeline:
For each corpus (original, MinHash, semantic, random):
a) Calculate metrics:
- Corpus reduction rate
- N-gram diversity (n=1,2,3)
- Generate text using gpt-4o-mini
- Calculate repetition rate in generated text
b) Create visualizations:
- Line plots of n-gram diversity
- Corpus size reduction comparison
- Repetition rates comparison

4. Statistical Analysis:
- Use bootstrap resampling to compare methods
- Calculate p-values for differences between methods
- Create summary tables of results
