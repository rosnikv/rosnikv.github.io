ID: idea_22-simplified

simplified-ted-summarization

Hypothesis

Incorporating basic LDA topic modeling into the TED summarization process will improve the quality of scientific abstract summaries compared to using the standard TED model alone, as measured by ROUGE scores and a simplified coherence evaluation.

Elements

  • Independent variable: Integration of LDA topic modeling with TED summarization
  • Dependent variable: Quality of generated summaries
  • Comparison groups: TED model with LDA topic integration vs. standard TED model
  • Baseline/control: Standard TED model
  • Context/setting: Summarization of scientific abstracts from open-access repositories
  • Assumptions: LDA topic modeling can effectively identify key themes in scientific abstracts
  • Relationship type: Causation
  • Population: Scientific abstracts (100-200 samples)
  • Timeframe: Not applicable
  • Measurement method: ROUGE-1, ROUGE-2, ROUGE-L scores, and a simplified coherence checklist

Description

This research explores a simplified approach to improving scientific text summarization by enhancing the TED model with basic topic modeling techniques. Rather than implementing full unsupervised domain adaptation, this study will focus on using Latent Dirichlet Allocation (LDA) to identify key topics in scientific articles and incorporate this information into the TED model's summarization process. The research will evaluate whether this lightweight topic-aware approach improves summary quality compared to the standard TED model when applied to a small, curated dataset of scientific abstracts from open-access repositories. This simplified approach maintains the core hypothesis that topic awareness improves summarization while being feasible for implementation with limited computational resources and programming experience.

Implementation Design

This experiment will evaluate whether incorporating basic topic modeling can improve the TED model's summarization of scientific abstracts. Follow these steps:

1. Data Collection and Preparation:
- Download 100-200 scientific abstracts from arXiv or PubMed Central (open-access repositories)
- Focus on a specific domain (e.g., computer science or biology)
- Split the data into training (70%), validation (15%), and test (15%) sets
- For each abstract, use the title and first 1-2 sentences as the reference summary

2. Implement the Standard TED Model (Baseline):
- Use the Hugging Face transformers library to load a pre-trained TED model
- Fine-tune the model on the training set of scientific abstracts
- Generate summaries for the test set
- Calculate ROUGE-1, ROUGE-2, and ROUGE-L scores against reference summaries

3. Implement LDA Topic Modeling:
- Use the gensim library to train an LDA model on the training set
- Experiment with different numbers of topics (5, 10, 15) and select the best performing one on the validation set
- For each abstract, extract the top 3 topics and their associated keywords

4. Implement the Topic-Aware TED Model:
- Modify the TED model's input by prepending the top 3 topics and their keywords to each abstract
- Format: "TOPICS: [topic1_keywords], [topic2_keywords], [topic3_keywords]. ABSTRACT: [abstract_text]"
- Fine-tune this modified model on the training set
- Generate summaries for the test set
- Calculate ROUGE-1, ROUGE-2, and ROUGE-L scores against reference summaries

5. Implement a Simple Coherence Evaluation:
- Create a checklist with 3 items: (1) Does the summary contain keywords from the top topics? (2) Does the summary avoid contradictions? (3) Does the summary follow a logical flow?
- Evaluate 30 randomly selected summaries from each model using this checklist

6. Analysis and Reporting:
- Compare ROUGE scores between the standard TED and topic-aware TED using paired t-tests
- Report mean and standard deviation for each metric
- Create bar charts comparing performance across models
- Analyze the coherence evaluation results
- Provide 3-5 example summaries from each model with their corresponding abstracts and topics
- Discuss limitations and potential improvements

Output Format:
- Save all generated summaries in a CSV file with columns for abstract_id, original_abstract, reference_summary, standard_ted_summary, topic_aware_ted_summary
- Save ROUGE scores in a separate CSV file
- Create a simple report (PDF or Markdown) with the analysis, charts, and example summaries

Note: If computational resources are limited, reduce the dataset size further or use a smaller variant of the TED model.

Operationalization

Please implement a pilot experiment to evaluate whether incorporating LDA topic modeling into TED model summarization improves the quality of scientific abstract summaries. The experiment should support three modes (PILOT_MODE): MINI_PILOT, PILOT, and FULL_EXPERIMENT.

Data Sizes by Mode:
- MINI_PILOT: 10 abstracts total (7 train, 3 dev)
- PILOT: 50 abstracts total (35 train, 15 dev)
- FULL_EXPERIMENT: 200 abstracts (140 train, 30 dev, 30 test)

Implementation Steps:

1. Setup and Configuration:
- Create a global PILOT_MODE variable defaulting to 'MINI_PILOT'
- Initialize logger for tracking experiment progress
- Set random seed (42) for reproducibility

2. Data Collection:
- Use Huggingface Datasets to load scientific papers (e.g., arxiv-metadata-oai-snapshot)
- Filter for computer science papers with abstracts between 100-500 words
- Extract required number of abstracts based on PILOT_MODE
- For each abstract, use title + first sentence as reference summary
- Split into train/dev(/test) sets based on mode

3. Model Implementation:
- Use gpt-4o-mini as the base summarization model for both conditions
- Baseline condition: Direct summarization with prompt 'Please summarize the following scientific abstract in 2-3 sentences: {abstract}'
- Experimental condition:
* First call: 'Please identify 3 main topics in this abstract, with 2-3 keywords each: {abstract}'
* Second call: 'Please summarize the following scientific abstract in 2-3 sentences. Focus on these key topics: {topics}\n\nAbstract: {abstract}'

4. Evaluation Pipeline:
- For each abstract in evaluation set:
* Generate baseline summary
* Generate topic-aware summary
* Calculate ROUGE-1, ROUGE-2, ROUGE-L scores against reference summary
* Have gpt-4o-mini evaluate coherence using checklist:
- Contains key topic keywords (0/1)
- Avoids contradictions (0/1)
- Follows logical flow (0/1)

5. Analysis:
- Calculate mean and std dev of ROUGE scores for each condition
- Use bootstrap resampling to compare conditions
- Generate plots comparing ROUGE scores
- Save example outputs (3 for MINI_PILOT, 5 for PILOT, 10 for FULL_EXPERIMENT)

Required Output Files:
1. experiment_log.txt: Detailed logging of all steps
2. summaries.csv: Columns for abstract_id, original_abstract, reference_summary, baseline_summary, experimental_summary, rouge_scores, coherence_scores
3. analysis.txt: Statistical results and key findings
4. plots/rouge_comparison.pdf: Bar plots of ROUGE scores

Execution Flow:
1. Start with MINI_PILOT mode
2. If successful, proceed to PILOT mode
3. Stop after PILOT mode - require manual verification before FULL_EXPERIMENT

Error Handling:
- Log all errors with full stack traces
- Save partial results if experiment fails
- Include error recovery for API timeouts/failures

Note: All LLM calls should use gpt-4o-mini through the proxy server, with appropriate error handling and rate limiting.
