ID: idea_108-simplified

simplified-summarization-evaluation

Hypothesis

Using RoBERTa embeddings to compute semantic similarity between source documents and candidate summaries will enable better selection of factually consistent and semantically rich summaries compared to selection based on traditional metrics like ROUGE alone.

Elements

  • Independent variable: Method of selecting the best summary from multiple candidates (RoBERTa-based semantic similarity vs. ROUGE-based selection)
  • Dependent variable: Factual consistency and semantic richness of selected summaries
  • Comparison groups: RoBERTa-based selection vs. ROUGE-based selection
  • Baseline/control: ROUGE-based selection of summaries
  • Context/setting: CNN/DailyMail dataset (or a small subset for pilot testing)
  • Assumptions: Pre-trained summarization models can generate diverse candidate summaries; semantic similarity correlates with summary quality
  • Relationship type: Causation
  • Population: News articles from CNN/DailyMail dataset
  • Timeframe: Not time-dependent
  • Measurement method: ROUGE, BERTScore, and manual inspection of a small sample

Description

This research explores a simplified approach to improving abstractive summarization by focusing on evaluation rather than complex model training. The project will investigate whether using RoBERTa embeddings to evaluate and select candidate summaries can improve factual consistency and semantic richness compared to traditional methods. Instead of implementing complex policy gradient training, the research will use an existing pre-trained summarization model (like BART or T5) to generate multiple candidate summaries, and then apply RoBERTa-based semantic similarity scoring to select the best summary. This approach reduces implementation complexity while still addressing the important challenge of improving summary quality through better evaluation techniques.

Implementation Design

This experiment will investigate whether using RoBERTa embeddings to select high-quality summaries from multiple candidates can improve summarization quality compared to traditional ROUGE-based selection.

1. Implementation:
a. Use the Hugging Face Transformers library to load a pre-trained summarization model (BART-large-CNN is recommended as it's already fine-tuned for summarization).
b. Load the RoBERTa-base model for computing embeddings.
c. Implement a function to generate multiple candidate summaries for each input document by varying decoding parameters (temperature, top-p, etc.).
d. Implement two selection methods:
- ROUGE-based: Select the summary with the highest ROUGE-L score compared to the reference summary (for training/validation) or the highest ROUGE-1 score compared to the source document (for testing).
- RoBERTa-based: Compute the cosine similarity between the RoBERTa embeddings of the source document and each candidate summary, and select the summary with the highest similarity score.

2. Data:
a. Use the CNN/DailyMail dataset from the Hugging Face datasets library.
b. For the pilot experiment, randomly select 200 articles from the validation set.
c. For each article, generate 5 candidate summaries using different decoding parameters.

3. Evaluation:
a. For each article, select the best summary using both selection methods.
b. Compute ROUGE scores (ROUGE-1, ROUGE-2, ROUGE-L) for both sets of selected summaries against reference summaries.
c. Compute BERTScore for both sets of selected summaries against reference summaries.
d. Manually evaluate factual consistency for a random subset of 20 articles by comparing the selected summaries to the source documents.
e. Use paired t-tests to determine if there are statistically significant differences between the two selection methods.
f. Save all generated summaries, selected summaries, and evaluation metrics in a CSV file for further analysis.

4. Analysis:
a. Compare the average ROUGE and BERTScore metrics between the two selection methods.
b. Analyze cases where the two selection methods choose different summaries, and identify patterns in these differences.
c. Examine whether RoBERTa-based selection tends to favor summaries with better factual consistency based on manual evaluation.

5. Extensions (if time permits):
a. Experiment with different embedding models beyond RoBERTa-base (e.g., BERT, DeBERTa).
b. Try different similarity metrics beyond cosine similarity (e.g., dot product, euclidean distance).
c. Combine ROUGE and embedding-based scores with different weights to see if a hybrid approach performs better.

Operationalization

Please create an experiment to evaluate whether RoBERTa embeddings can better select high-quality summaries compared to ROUGE-based selection. The experiment should have three pilot modes (MINI_PILOT, PILOT, FULL_EXPERIMENT), with the following specifications:

PILOT SETTINGS:
- MINI_PILOT: Use 10 articles from CNN/DailyMail training set
- PILOT: Use 100 articles from training set for initial testing, 50 articles from validation set for evaluation
- FULL_EXPERIMENT: Use full dataset (but do not implement this mode yet)

CORE STEPS:
1. Dataset Preparation:
- Use Huggingface Datasets to load CNN/DailyMail dataset
- For each pilot mode, select appropriate subset of articles
- Log the article IDs used for reproducibility

2. Summary Generation:
- For each article, generate 5 candidate summaries using gpt-4o-mini
- Vary temperature settings (0.3, 0.5, 0.7, 0.9, 1.1) to ensure diversity
- Store all generated summaries

3. Summary Selection Methods:
a. ROUGE-based (Baseline):
- Compute ROUGE-1, ROUGE-2, ROUGE-L scores between each candidate and source
- Select summary with highest ROUGE-L score
b. RoBERTa-based (Experimental):
- Get embeddings for source text and each candidate using gpt-4o-mini
- Compute cosine similarity between source and each candidate
- Select summary with highest similarity score

4. Evaluation:
- For each article, store:
* Source text
* All candidate summaries
* Selected summary from each method
* ROUGE scores
* Embedding similarity scores
- Compute summary statistics:
* Average ROUGE scores for each method
* Average similarity scores for each method
* Number of times each method selected different summaries

5. Statistical Analysis:
- Use bootstrap resampling to compare ROUGE scores between methods
- Generate plots showing score distributions
- Save all results to CSV files

1. A results.csv file containing:
- Article ID

2. A summary.txt file containing:
