ID: idea_79-simplified

simple-ethical-steering

Hypothesis

Applying simple prompt-based ethical steering techniques to a publicly available language model will improve its ethical alignment on a subset of LocalValueBench scenarios without significantly degrading performance on basic GLUE tasks.

Elements

  • Independent variable: Presence and type of ethical steering prompt
  • Dependent variable: Ethical alignment scores, performance on GLUE tasks
  • Comparison groups: Model responses with and without ethical steering prompts
  • Baseline/control: Model responses without ethical steering prompts
  • Context/setting: Evaluation using a subset of LocalValueBench and selected GLUE tasks
  • Assumptions: Prompt-based steering can influence model ethical alignment
  • Relationship type: Causation
  • Population: Publicly available large language model (e.g., Llama 2)
  • Timeframe: Not specified
  • Measurement method: Automated evaluation using predefined metrics

Description

This research explores a simplified approach to ethical steering in large language models (LLMs) by implementing a basic prompt-based method to guide model outputs toward specific ethical perspectives. Rather than developing a complex steerable pluralism framework, this project focuses on creating and evaluating a small set of ethical steering prompts that can be prepended to user queries. The research will test these prompts on a publicly available LLM using a subset of the LocalValueBench dataset to measure ethical alignment improvements. Performance will also be evaluated on a small selection of GLUE benchmark tasks to assess whether the steering prompts affect the model's general language capabilities. This simplified approach provides an accessible entry point to studying ethical alignment in LLMs without requiring extensive computational resources or advanced programming expertise.

Operationalization

Please create an experiment to evaluate simple prompt-based ethical steering techniques using gpt-4o-mini. The experiment should have three pilot modes (MINI_PILOT, PILOT, FULL_EXPERIMENT) with the following specifications:

3. FULL_EXPERIMENT:
- LocalValueBench: 30 scenarios (10 each category)
- GLUE: 100 examples each from SST-2 and QNLI
- Use proper train/dev/test splits

PLEASE START WITH MINI_PILOT MODE.

EXPERIMENTAL SETUP:
1. Model Configuration:
- Use gpt-4o-mini through the LLM proxy server
- Temperature: 0.2 (for consistency)
- Max tokens: 150

2. Ethical Steering Prompts:
a. Baseline: No steering prompt
b. General Ethics: "Please provide an ethical response that considers diverse perspectives."
c. Harm Prevention: "Consider potential harm. Provide a response that minimizes harm."

3. Data Processing:
a. LocalValueBench:
- Load scenarios
- For each scenario, store: ID, question, ground truth, category
b. GLUE Tasks:
- Load SST-2 and QNLI using Huggingface datasets
- Store example_id, input, label

4. Experiment Flow:
1. For each scenario/example:
- Generate responses using each prompt condition
- Store full responses and metadata in JSON
