ID: idea_75-simplified

audio-visual-emotion-recognition

Hypothesis

A weighted voting scheme for decision-level fusion of audio and visual signals will significantly improve the accuracy of recognizing basic emotions (joy, surprise, and disgust) in video content, compared to using either audio or visual signals alone.

Elements

  • Independent variable: Weighting strategy for decision-level fusion of audio and visual signals
  • Dependent variable: Accuracy of recognizing basic emotions (joy, surprise, and disgust)
  • Comparison groups: Weighted fusion vs. audio-only vs. visual-only
  • Baseline/control: Using audio-only and visual-only classifiers
  • Context/setting: Video content from the CREMA-D dataset
  • Assumptions: Pre-extracted features from audio and visual modalities are available and informative for emotion recognition
  • Relationship type: Causation
  • Population: Actors in the CREMA-D dataset
  • Timeframe: Not applicable (cross-sectional analysis)
  • Measurement method: Accuracy, precision, recall, and F1-score of emotion recognition

Description

This research aims to explore the effectiveness of decision-level fusion of audio and visual signals for emotion recognition in video content. Instead of incorporating EMG data, which requires specialized equipment, this simplified study focuses on optimizing the fusion of readily available audio and visual features using a weighted voting scheme. The research will investigate whether different weighting strategies for audio and visual modalities can significantly improve emotion recognition accuracy for basic emotions (joy, surprise, and disgust) compared to using either modality alone. The study will utilize pre-extracted features from the CREMA-D dataset, which contains audio-visual recordings of actors expressing various emotions, making it accessible for researchers with limited resources. This approach addresses the practical challenge of multimodal emotion recognition while maintaining scientific rigor and potential for meaningful contributions to the field.

Implementation Design

This experiment will investigate whether weighted decision-level fusion of audio and visual signals improves emotion recognition accuracy compared to single-modality approaches.

1. Data Preparation:
- Download the CREMA-D dataset, which contains audio-visual recordings of actors expressing different emotions.
- Extract a subset focusing on three emotions: joy, surprise, and disgust.
- Split the data into training (70%), validation (15%), and test (15%) sets, ensuring balanced representation of emotions.
- For audio modality, extract standard features such as MFCCs, spectral centroid, and zero-crossing rate using the librosa library.
- For visual modality, extract facial landmarks or use pre-trained models to obtain facial expression features from key frames.

2. Baseline Models Implementation:
- Implement an audio-only classifier using scikit-learn's Random Forest with the extracted audio features.
- Implement a visual-only classifier using the same algorithm with the extracted visual features.
- Train both models on the training set and tune hyperparameters using the validation set.
- Evaluate both models on the test set using accuracy, precision, recall, and F1-score metrics.

3. Decision-Level Fusion Implementation:
- Implement a decision-level fusion approach that combines the predictions from both modalities.
- Start with a simple voting scheme where both modalities have equal weight (0.5 each).
- Implement a grid search to find optimal weights for each modality (e.g., testing weights from 0.1 to 0.9 in increments of 0.1).
- The final emotion prediction is determined by the weighted sum of confidence scores from each modality.

4. Evaluation:
- Evaluate the fusion model on the test set using the same metrics as the baselines.
- Compare the performance of the fusion model against both baselines.
- Conduct statistical significance testing (e.g., McNemar's test) to determine if improvements are statistically significant.
- Analyze which emotions benefit most from the fusion approach and which weighting strategy performs best overall.

5. Output and Reporting:
- Save the trained models and optimal weights for future use.
- Generate confusion matrices for all three approaches (audio-only, visual-only, and fusion).
- Create visualizations comparing performance across different emotions and approaches.
- Prepare a detailed report including methodology, results, and analysis of findings.
- Include a discussion of limitations and potential future improvements.

The code should be modular, well-documented, and include error handling. Use pandas for data manipulation, scikit-learn for machine learning models, and matplotlib/seaborn for visualizations. All results should be saved in CSV format for easy analysis, and figures should be saved as high-resolution PNG files.
