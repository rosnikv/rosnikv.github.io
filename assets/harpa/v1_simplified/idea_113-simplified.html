BM25-ChatGPT-Retrieval

Hypothesis

Augmenting a BM25 retrieval system with ChatGPT-generated synthetic documents will improve retrieval performance in a specific scientific domain compared to a standard BM25 baseline.

Elements

  • Independent variable: Augmentation of BM25 retrieval with ChatGPT-generated synthetic documents
  • Dependent variable: Retrieval performance (precision and recall)
  • Comparison groups: BM25 with synthetic documents vs. standard BM25
  • Baseline/control: Standard BM25 retrieval system
  • Context/setting: A specific scientific domain (e.g., renewable energy or computational biology)
  • Assumptions: ChatGPT can generate relevant synthetic documents that enhance retrieval
  • Relationship type: Causation
  • Population: Scientific documents in the chosen domain
  • Timeframe: Not time-dependent
  • Measurement method: Precision, recall, and F1 score on a test set of queries

Description

This research explores how ChatGPT-generated synthetic documents can enhance a traditional BM25 retrieval system in a specific scientific domain. Instead of implementing complex neural retrieval models like ColBERT, this study focuses on improving the widely-used and computationally efficient BM25 algorithm by augmenting its document collection with synthetic content. The research will use ChatGPT to generate domain-specific documents based on a set of seed queries or topics, which will then be added to the retrieval corpus. The hypothesis is that these synthetic documents will help bridge vocabulary gaps and provide additional relevant content that improves both precision and recall in retrieval tasks. The study will compare the performance of a standard BM25 system against a BM25 system augmented with synthetic documents on a small set of test queries. This approach is novel yet accessible, requiring minimal computational resources while still addressing an important challenge in information retrieval for specialized domains.

Operationalization

Please implement a BM25 retrieval experiment that compares standard BM25 against BM25 augmented with synthetic documents. The experiment should follow these specifications:

1. PILOT SETTINGS
Implement a global variable PILOT_MODE that can be set to one of: ['MINI_PILOT', 'PILOT', 'FULL_EXPERIMENT']

For MINI_PILOT:
- Use 10 scientific papers from the 'machine learning' category on arXiv
- Generate 2 synthetic documents using gpt-4o-mini from 1 seed topic
- Test with 3 queries
- Maximum of top-5 results per query

For PILOT:
- Use 50 scientific papers from the 'machine learning' category
- Generate 10 synthetic documents from 3 seed topics
- Test with 10 queries
- Maximum of top-10 results per query

For FULL_EXPERIMENT:
- Use 200 scientific papers
- Generate 30 synthetic documents from 10 seed topics
- Test with 20 queries
- Maximum of top-20 results per query

2. DATA COLLECTION
- Use the Huggingface Datasets API to get arXiv papers in the machine learning domain
- For each paper, extract the title and abstract
- Store in a JSON format with fields: {id, title, abstract}

3. QUERY GENERATION
- For MINI_PILOT, use these 3 fixed queries:
* "deep learning optimization techniques"
* "neural network architectures"
* "machine learning evaluation metrics"
- For PILOT and FULL_EXPERIMENT, manually create more queries

4. SYNTHETIC DOCUMENT GENERATION
- Use gpt-4o-mini to generate synthetic documents
- Prompt template: "Write a detailed scientific abstract about [topic] in the style of an arXiv paper. Include key terminology and concepts. The abstract should be 150-200 words."
- Store generated documents in the same format as the original corpus

5. IMPLEMENTATION STEPS
a) Preprocess all documents:
- Convert to lowercase
- Remove special characters
- Tokenize
- Remove stopwords

b) Implement two conditions:
- Baseline: Standard BM25 on original corpus
- Experimental: BM25 on original corpus + synthetic documents

c) For each query:
- Run both conditions
- Store top-k results (k depends on PILOT_MODE)
- Calculate precision, recall, F1 at each rank

d) Analysis:
- Compare performance metrics between conditions
- Use bootstrap resampling to test statistical significance
- Generate plots showing:
* Average precision/recall/F1 at each rank
* Per-query performance comparison

6. REQUIRED OUTPUT
- Save all generated synthetic documents
- Save all retrieval results
- Generate performance comparison plots
- Statistical analysis results
- Log file with full experimental details

7. EXECUTION ORDER
1. Run MINI_PILOT first
2. If successful, run PILOT
3. Stop after PILOT (await human verification before FULL_EXPERIMENT)

Each pilot stage should output:
- Basic statistics of the corpus
- Number of synthetic documents generated
- Average precision/recall/F1 scores
- Statistical comparison results
- Any errors or warnings encountered

Please implement the experiment following these specifications, starting with MINI_PILOT mode.
