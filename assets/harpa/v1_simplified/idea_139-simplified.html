ID: idea_139-simplified

task-similarity-finetuning

Hypothesis

Training a BERT model on semantically similar tasks (measured by cosine similarity of task descriptions) before finetuning on a target task will improve performance and sample efficiency compared to training on randomly selected tasks.

Elements

  • Independent variable: Task selection method (similarity-based vs. random)
  • Dependent variable: Task-specific accuracy and sample efficiency
  • Comparison groups: Similarity-based task selection vs. random task selection
  • Baseline/control: Random task selection
  • Context/setting: During finetuning on GLUE benchmark tasks
  • Assumptions: Task descriptions can effectively capture task similarity
  • Relationship type: Causation
  • Population: BERT-base model
  • Timeframe: During finetuning
  • Measurement method: Accuracy on target tasks and number of examples needed to reach performance threshold

Description

This research investigates whether grouping similar NLP tasks together during BERT model finetuning improves performance compared to random task selection. Instead of implementing a complex hierarchical clustering approach, this simplified study uses basic cosine similarity between task descriptions to identify related tasks. The research focuses on a small subset of GLUE benchmark tasks, measuring whether training on similar tasks first leads to better performance and reduced training examples needed for target tasks. This approach maintains the core insight of the original research - that task similarity can be leveraged to improve model performance - while significantly reducing implementation complexity and computational requirements.

Implementation Design

This experiment investigates whether training on similar tasks improves BERT finetuning performance. Follow these steps:

1. Task Selection and Representation:
- Select 4 GLUE benchmark tasks: SST-2 (sentiment analysis), QNLI (question-answering/natural language inference), RTE (textual entailment), and MRPC (paraphrase detection).
- Create a short description (2-3 sentences) for each task explaining its objective and data characteristics.
- Use a pre-trained BERT model to generate embeddings for each task description by averaging the token embeddings of the description text.
- Calculate cosine similarity between all pairs of task descriptions.

2. Experimental Setup:
- For each of the 4 tasks (as target tasks), create two experimental conditions:
a) Similarity-based: Train first on the most similar task (based on cosine similarity), then finetune on the target task.
b) Random: Train first on a randomly selected task (different from the target), then finetune on the target task.
- Also include a direct finetuning baseline where the model is trained directly on the target task without intermediate training.
- Use BERT-base-uncased as the base model for all experiments.
- For each condition, train 3 models with different random seeds to account for variance.

3. Training Procedure:
- For intermediate training (similarity-based or random), use 100% of the training data for the selected task.
- For target task finetuning, create learning curves by training with 10%, 25%, 50%, and 100% of the available training data.
- Use standard hyperparameters: learning rate of 2e-5, batch size of 16, and train for 3 epochs.

4. Evaluation:
- Evaluate each model on the validation set of the target task.
- Record accuracy (or F1 score for MRPC) for each data percentage point.
- Calculate sample efficiency by determining how many examples are needed to reach 90% of the maximum performance achieved with 100% of the data.

5. Analysis and Reporting:
- For each target task, compare the performance of similarity-based, random, and direct finetuning approaches.
- Create learning curve plots showing performance vs. training data size for each condition.
- Conduct t-tests to determine if differences between conditions are statistically significant.
- Calculate and report the average improvement in accuracy and sample efficiency across all tasks.
- Analyze which task pairs benefit most from similarity-based training.

6. Data Management:
- Save all model checkpoints after intermediate training and after target task finetuning.
- Record all evaluation metrics in CSV files with columns for task, condition, seed, data percentage, and performance.
- Save the cosine similarity matrix for task descriptions for future reference.

The experiment should be implemented using the Hugging Face Transformers library for model loading and training, and standard Python libraries (numpy, scipy, matplotlib) for analysis and visualization.

Operationalization

- QNLI: "A question-answering task where the goal is to determine if a given sentence contains the answer to a question."
- RTE: "A textual entailment task where the goal is to determine if one sentence logically follows from another."
