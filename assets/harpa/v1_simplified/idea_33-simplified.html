ID: idea_33-simplified

simplified-fairfil-feedback

Hypothesis

Incorporating simple user feedback to adjust FairFil's debiasing parameters will improve bias mitigation in pre-trained language models compared to using FairFil with default settings, while maintaining comparable task performance.

Elements

  • Independent variable: Method of bias mitigation (FairFil with user feedback vs. FairFil with default settings)
  • Dependent variable: Bias mitigation effectiveness and language model performance
  • Comparison groups: FairFil with user feedback vs. FairFil with default settings
  • Baseline/control: FairFil with default settings
  • Context/setting: Small pre-trained language model (e.g., BERT-base)
  • Assumptions: User feedback can meaningfully inform parameter adjustments in FairFil
  • Relationship type: Causation
  • Population: Pre-trained language models (specifically BERT-base)
  • Timeframe: Not applicable
  • Measurement method: SEAT bias scores and accuracy on standard NLP tasks

Description

This research explores a simplified approach to enhancing bias mitigation in language models by incorporating basic user feedback with FairFil. Rather than building a complex interactive system, this study focuses on collecting static user feedback on a small set of biased examples, then using this feedback to adjust FairFil's debiasing parameters. The research will evaluate whether this lightweight feedback integration improves bias mitigation compared to using FairFil with default settings, while maintaining model performance on standard NLP tasks. This approach provides a more accessible entry point to studying human-in-the-loop debiasing without requiring extensive resources or advanced programming skills.

Operationalization

Please implement a pilot experiment to evaluate whether simple user feedback can enhance FairFil's bias mitigation in language models. The experiment should have three pilot modes (MINI_PILOT, PILOT, FULL_EXPERIMENT), with the following specifications:

PILOT MODES:
- MINI_PILOT: Use 5 gender-biased examples, 2 users for feedback, evaluate on 10 SEAT examples and 20 SST-2 examples
- PILOT: Use 20 gender-biased examples, 3-5 users for feedback, evaluate on 50 SEAT examples and 100 SST-2 examples
- FULL_EXPERIMENT: Use all examples, 10+ users, full evaluation (but don't run this yet)

STEPS:

1. Environment Setup:
- Create a PILOT_MODE variable initialized to 'MINI_PILOT'
- Install and import required libraries (transformers, numpy, pandas)
- Initialize logging using the Logger/Debugging codeblock

2. Data Loading:
- Use Huggingface Hub API to load:
* BERT-base-uncased model
* SEAT dataset (gender bias subset)
* SST-2 dataset
- Sample appropriate subset based on PILOT_MODE

3. Baseline Models Setup:
- Initialize unmodified BERT-base
- Initialize FairFil with default settings
- Save initial model states

4. User Feedback Collection:
- Use gpt-4o-mini to simulate user feedback on biased examples
- For each example, collect bias ratings (1-5 scale)
- Store feedback in a structured format
- Number of examples based on PILOT_MODE

5. FairFil Parameter Adjustment:
- Calculate average bias ratings
- Map ratings to FairFil parameter adjustments
- Create feedback-adjusted FairFil version

6. Evaluation Pipeline:
- For each model (unmodified, default FairFil, feedback FairFil):
* Run SEAT evaluations
* Run SST-2 evaluations
* Log performance metrics

7. Analysis:
- Use bootstrap resampling to compare:
* Bias scores between conditions
* Task performance between conditions
- Create line plots showing:
* Bias reduction across conditions
* Task performance maintenance

8. Output Generation:
- Save all results as CSV files
- Generate summary statistics
- Create visualization plots
- Output detailed log of experiment progress

IMPORTANT NOTES:
- Start with MINI_PILOT mode
- If successful, proceed to PILOT mode
- Stop before FULL_EXPERIMENT (await human verification)
- Use gpt-4o-mini for all LLM calls
- Log all steps and intermediate results
- Include error handling and validation checks

SUCCESS CRITERIA:
- Statistical significance in bias reduction
- Task performance within 2% of baseline
- Clean execution of all pipeline stages

OUTPUT FORMAT:
- Results directory with:
* Raw data CSVs
* Performance metrics
* Statistical analysis
* Visualization plots
* Detailed experiment log
