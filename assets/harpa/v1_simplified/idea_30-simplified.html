ID: idea_30-simplified

pruning-for-factual-summarization

Hypothesis

Structured pruning of attention heads in a pre-trained abstractive summarization model will reduce non-factual hallucinations on the XSUM dataset while maintaining comparable ROUGE scores to the unpruned model.

Elements

  • Independent variable: Level of structured pruning (number of attention heads removed)
  • Dependent variables: 1) Factuality of generated summaries, 2) ROUGE scores
  • Comparison groups: Unpruned model vs. models with different levels of pruning
  • Baseline/control: Original unpruned summarization model
  • Context/setting: Abstractive summarization on a subset of the XSUM dataset
  • Assumptions: Attention heads contribute differently to factuality and some can be removed without degrading performance
  • Relationship type: Causation
  • Population: News articles from the XSUM dataset
  • Timeframe: Not time-dependent
  • Measurement method: Entity-level factuality classification and ROUGE scores

Description

This research investigates how structured pruning affects factual hallucinations in abstractive summarization models. By removing specific attention heads from a pre-trained summarization model and evaluating on a subset of the XSUM dataset, we aim to determine if simpler model architectures can reduce non-factual content generation. The study will compare pruned models against the original unpruned model, measuring both factuality of generated summaries and overall summary quality. This approach builds on emerging evidence that overparameterized models may be more prone to hallucination, and that strategic pruning might improve factual consistency without significant performance degradation.

Implementation Design

This experiment investigates how structured pruning affects factual hallucinations in abstractive summarization. Follow these steps:

1. Setup and Data Preparation:
- Install required libraries: transformers, datasets, torch, numpy, rouge-score, nltk
- Load a pre-trained BART-base model fine-tuned on XSUM from Hugging Face
- Load a subset of 500 examples from the XSUM test set
- Split this into a development set (100 examples) and test set (400 examples)

2. Attention Head Analysis:
- Implement a function to extract and visualize attention weights from all heads
- For each attention head, calculate the average attention weight across the development set
- Rank heads by their average attention weight
- Identify candidate heads for pruning (lowest average attention)

3. Pruning Implementation:
- Create a function to prune specific attention heads by setting their weights to zero
- Create four model variants: unpruned (baseline), 10% pruned, 20% pruned, and 30% pruned
- For each pruned variant, remove the corresponding percentage of heads with lowest average attention

4. Evaluation Setup:
- Implement an entity extraction function using NLTK's named entity recognition
- Create an entity-matching function that checks if entities in the summary appear in the source
- Set up ROUGE score calculation using the rouge-score library

5. Experiment Execution:
- For each model variant, generate summaries for all test examples
- Calculate entity-level factuality: percentage of summary entities present in source
- Calculate ROUGE-1, ROUGE-2, and ROUGE-L scores against reference summaries
- Perform statistical significance testing (paired t-test) between baseline and pruned models

6. Analysis and Reporting:
- Create tables comparing factuality scores and ROUGE metrics across models
- Generate visualizations showing the relationship between pruning level and metrics
- Perform qualitative analysis on 10 examples where pruning significantly improved factuality
- Save all generated summaries, metrics, and analysis in a structured format
- Write a brief report summarizing findings, including whether the hypothesis was supported

The output should include CSV files with all metrics, JSON files with generated summaries, and Python notebooks documenting the analysis process and results.

Operationalization

Please create an experiment to investigate how structured pruning of attention heads affects factual hallucinations in abstractive summarization models. The experiment should be implemented in three pilot stages (MINI_PILOT, PILOT, and FULL_EXPERIMENT), controlled by a global PILOT_MODE variable.

Stage Definitions:
- MINI_PILOT: Use 10 articles from XSUM training set, test 2 pruning levels (0% and 20%)
- PILOT: Use 100 articles from training set for analysis, 50 from dev set for evaluation, test 4 pruning levels (0%, 10%, 20%, 30%)
- FULL_EXPERIMENT: Use full dataset as specified in original design

Implementation Steps:

1. Setup and Configuration:
- Create global PILOT_MODE variable with possible values: MINI_PILOT, PILOT, FULL_EXPERIMENT

- Load BART-base model fine-tuned on XSUM using Huggingface Hub

- Create pruned model variants based on PILOT_MODE

4. Entity Extraction Setup:
- Use NLTK to implement named entity recognition
