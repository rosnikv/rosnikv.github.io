ID: idea_98-simplified

simple-data-cleaning-for-translation

Hypothesis

Applying rule-based data cleaning techniques to a parallel corpus before fine-tuning a pre-trained machine translation model will improve BLEU scores compared to fine-tuning on the uncleaned dataset.

Elements

  • Independent variable: Application of rule-based data cleaning techniques
  • Dependent variable: BLEU score of machine translation tasks
  • Comparison groups: Fine-tuning with cleaned data vs. fine-tuning with uncleaned data
  • Baseline/control: Fine-tuning on uncleaned data
  • Context/setting: Single language pair translation (e.g., English-French)
  • Assumptions: Rule-based cleaning can effectively improve data quality
  • Relationship type: Causation
  • Population: Sentences in the selected language pair
  • Timeframe: Not specified
  • Measurement method: BLEU score

Description

This research investigates whether a simple rule-based data cleaning approach can improve machine translation performance when combined with a pre-trained translation model. Instead of using complex LLM-based cleaning and domain-specific adapters, this study focuses on implementing basic text preprocessing techniques (removing duplicates, fixing common errors, normalizing text) on a single language pair dataset before fine-tuning a pre-trained translation model. The research aims to quantify the impact of these accessible data cleaning methods on translation quality as measured by BLEU score, providing insights into the value of data preprocessing in resource-constrained machine translation scenarios.

Operationalization

Please implement an experiment to evaluate whether simple rule-based data cleaning improves machine translation performance. The experiment should support three modes (PILOT_MODE): MINI_PILOT, PILOT, and FULL_EXPERIMENT.

Pilot Settings:
- MINI_PILOT: Use 100 sentence pairs for training, 20 each for validation/test
- PILOT: Use 1000 sentence pairs for training, 100 each for validation/test
- FULL_EXPERIMENT: Use full dataset (80/10/10 split)

Implementation Steps:

1. Dataset Loading:
- Use the Huggingface Datasets API to load WMT14 English-French dataset
- Create train/validation/test splits based on PILOT_MODE
- Log the number of examples in each split

2. Data Cleaning:
Implement these cleaning rules:
- Remove duplicate sentence pairs
- Fix punctuation (remove multiple spaces, normalize periods/commas)
- Normalize capitalization (sentence case)
- Remove pairs where length ratio > 3:1
- Remove pairs with HTML tags
Log the number of examples affected by each rule

3. Model Setup:
- Load Helsinki-NLP/opus-mt-en-fr from Huggingface
- Create two identical instances
- Set hyperparameters:
* MINI_PILOT: 2 epochs, batch_size=4
* PILOT: 3 epochs, batch_size=8
* FULL_EXPERIMENT: 5 epochs, batch_size=16

4. Training Loop:
- Train baseline model on uncleaned data
- Train experimental model on cleaned data
- Log training time and perplexity per epoch
- Save checkpoints after each epoch

5. Evaluation:
- Calculate BLEU scores using SacreBLEU
- Perform bootstrap resampling to test significance
- Create plots comparing:
* BLEU scores (baseline vs experimental)
* Training perplexity over time
* Data cleaning impact (% removed by each rule)

6. Analysis Requirements:
- Log detailed statistics about cleaning impact
- Generate summary tables of results
- For MINI_PILOT: Show 5 example translations
- For PILOT/FULL: Show 20 example translations

IMPORTANT NOTES:
1. Start with MINI_PILOT mode
2. If successful, proceed to PILOT mode
3. Stop after PILOT mode (await human verification)
4. Log all major steps and decisions
5. Save all intermediate data and models

Output Requirements:
1. results.json: Contains all metrics and statistics
2. plots/: Directory with all visualization PDFs
3. logs/: Directory with detailed execution logs
4. models/: Directory with saved model checkpoints
5. data/: Directory with processed datasets

Error Handling:
- Log all errors with stack traces
- Save partial results if execution fails
- Include error recovery procedures

Validation Steps:
1. Verify data cleaning doesn't remove too much data (>50% is error)
2. Confirm BLEU score calculations are valid
3. Verify statistical testing is correctly applied
