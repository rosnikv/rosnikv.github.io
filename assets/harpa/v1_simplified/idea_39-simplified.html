retrieval-augmented-english-semantic-search

Hypothesis

Encoder language models will demonstrate improved semantic search performance when using retrieval-augmented contexts compared to non-augmented contexts, as measured by precision and recall on English language datasets.

Elements

  • Independent variable: Retrieval-augmented contexts (present vs. absent)
  • Dependent variable: Semantic search performance (precision and recall)
  • Comparison groups: Retrieval-augmented contexts vs. non-augmented contexts
  • Baseline/control: Non-augmented contexts
  • Context/setting: English language semantic search tasks
  • Assumptions: Pre-trained encoder models can effectively represent semantic information
  • Relationship type: Causal
  • Population: Encoder language models (BERT, Sentence-BERT)
  • Timeframe: Not applicable
  • Measurement method: Precision and recall

Description

This research investigates how retrieval-augmented contexts affect the performance of encoder language models in semantic search tasks. Rather than evaluating across 200+ languages, this study focuses on English language data using a subset of the MINERS benchmark or similar publicly available datasets. The research will compare the semantic search performance of encoder models (like BERT or Sentence-BERT) with and without retrieval-augmented contexts, measuring precision and recall. By limiting the scope to a single language and using pre-trained models, this project becomes feasible for a researcher with limited resources while still addressing an important question about improving semantic search capabilities through retrieval augmentation.

Operationalization

Please create an experiment to evaluate how retrieval-augmented contexts impact semantic search performance in English. The experiment should follow these specifications:

1. EXPERIMENT MODES:
Implement a global PILOT_MODE variable with three settings:
- MINI_PILOT: Use 20 sentence pairs from STS-B training set
- PILOT: Use 200 sentence pairs from training set, 100 from dev set
- FULL_EXPERIMENT: Use full dataset (but don't run this automatically)

2. DATASET PREPARATION:
- Use the Huggingface Datasets API to load the STS-B (Semantic Textual Similarity Benchmark) dataset
- For MINI_PILOT: Use first 20 sentence pairs from training set
- For PILOT: Use first 200 pairs from training, 100 from dev
- Convert similarity scores (0-5) to binary relevance (relevant if score >= 3.5)

3. MODEL SETUP:
- Use 'all-MiniLM-L6-v2' from sentence-transformers
- Log all model loading and initialization steps

4. BASELINE IMPLEMENTATION:
- For each query sentence:
* Generate embedding using Sentence-BERT
* Calculate cosine similarity with all candidate sentences
* Rank by similarity
* Calculate precision/recall/F1 at k=1,5,10

5. RETRIEVAL-AUGMENTED IMPLEMENTATION:
- For each query:
* Find top-3 similar sentences from training set
* Create augmented query: "Query: [original] Context: [similar1] [similar2] [similar3]"
* Generate embedding for augmented query
* Calculate cosine similarity with candidates
* Rank and evaluate as in baseline

6. EVALUATION:
- Calculate precision/recall/F1 at k=1,5,10
- Use bootstrap resampling to test statistical significance
- Create line plots comparing metrics between approaches
- Save all results to CSV files

7. EXECUTION ORDER:
1. Run MINI_PILOT first (20 pairs)
2. If successful, run PILOT (200 train, 100 dev pairs)
3. Stop before FULL_EXPERIMENT (await human verification)

8. REQUIRED OUTPUTS:
- Log file with all major steps and any errors
- CSV files with raw results (embeddings, scores)
- PDF plots comparing performance metrics
- Statistical test results
- Summary report with key findings

Note: Use gpt-4o-mini for any LLM components (though these should be minimal in this experiment).

Please implement this experiment, focusing first on the MINI_PILOT to verify functionality, then proceeding to PILOT if successful.
