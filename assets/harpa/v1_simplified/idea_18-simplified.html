ID: idea_18-simplified

simple-monolingual-ner-enhancement

Hypothesis

Incorporating basic syntactic features (dependency relations and part-of-speech tags) as additional input to a pre-trained language model will improve NER performance compared to using the pre-trained language model alone.

Elements

  • Independent variable: Incorporation of basic syntactic features (dependency relations and part-of-speech tags) as additional input
  • Dependent variable: Named entity recognition performance (F1 score)
  • Comparison groups: Model with syntactic features vs. model without syntactic features
  • Baseline/control: Pre-trained language model without syntactic features
  • Context/setting: English language NER task using CoNLL-2003 dataset
  • Assumptions: Syntactic information provides complementary information to the contextual embeddings from the pre-trained language model
  • Relationship type: Causation
  • Population: English text with named entities
  • Timeframe: Not time-dependent
  • Measurement method: F1 score on NER task

Description

This research explores enhancing Named Entity Recognition (NER) performance by incorporating basic syntactic information into a pre-trained language model. Instead of focusing on complex multilingual scenarios with graph attention networks, this simplified approach will use dependency parsing information to augment a monolingual BERT model for NER tasks. The research will investigate whether adding simple syntactic features (such as dependency relations and part-of-speech tags) as additional input features can improve NER performance compared to using the pre-trained language model alone. This approach reduces computational complexity while still exploring the core hypothesis that syntactic information can enhance NER performance.

Implementation Design

This experiment will investigate whether incorporating basic syntactic features can improve NER performance compared to using a pre-trained language model alone.

1. Implementation Details:
a. Use the transformers library to load a pre-trained BERT-base-uncased model.
b. Use spaCy to extract dependency parsing information and POS tags from the input text.
c. Create two model variants:
- Baseline: Fine-tune BERT-base for NER without syntactic features.
- Enhanced: Fine-tune BERT-base for NER with syntactic features added.
d. For the enhanced model, represent syntactic features as follows:
- Convert dependency relation types to one-hot encodings.
- Convert POS tags to one-hot encodings.
- Concatenate these features with the BERT token embeddings before passing them to the classification layer.
e. Implement a simple CRF model with hand-crafted features as a secondary baseline.

2. Data:
a. Use the CoNLL-2003 English dataset, which contains news articles annotated with four entity types (PER, LOC, ORG, MISC).
b. Split the data into training (80%), validation (10%), and test (10%) sets if not already provided.
c. For the pilot experiment, use only 20% of the training data.

3. Output and Evaluation:
a. Save the trained models and their predictions on the test set.
b. Calculate and report precision, recall, and F1 score for each entity type and the micro-average across all types.
c. Perform statistical significance testing (bootstrap resampling) to determine if the performance difference between the baseline and enhanced models is significant.
d. Conduct an error analysis to identify specific cases where the enhanced model performs better or worse than the baseline.
e. Generate visualizations comparing the performance of the models across different entity types.

The experiment should be implemented in Python using PyTorch. All code, trained models, and results should be saved in a structured manner to facilitate reproducibility and further analysis.

Operationalization

Please implement a Named Entity Recognition (NER) enhancement experiment that compares a baseline BERT model against an enhanced version incorporating syntactic features. The experiment should follow these specifications:

1. PILOT MODE IMPLEMENTATION:
Create a global variable PILOT_MODE that can be set to one of three values:
- MINI_PILOT: Use 50 sentences from training set
- PILOT: Use 1000 sentences from training set, 200 from dev set
- FULL_EXPERIMENT: Use complete dataset
The experiment should start with MINI_PILOT, then if successful, proceed to PILOT, then stop.

2. DATA PREPARATION:
a) Load the CoNLL-2003 dataset using the Huggingface Datasets library
b) For each sentence:
- Extract dependency relations and POS tags using spaCy
- Convert to one-hot encodings
- Create input features for both baseline and enhanced models

3. MODEL IMPLEMENTATIONS:
a) Baseline BERT:
- Use BERT-base-uncased from Huggingface
- Fine-tune for NER task
b) Enhanced BERT:
- Same as baseline, but concatenate syntactic features with BERT embeddings
c) CRF Baseline:
- Implement simple CRF with basic features

4. TRAINING PROCEDURE:
For MINI_PILOT:
- Train for 2 epochs
- Batch size: 8
- Learning rate: 2e-5
For PILOT:
- Train for 5 epochs
- Batch size: 16
- Learning rate: 2e-5

5. EVALUATION:
a) Calculate precision, recall, F1 for each entity type
b) Use bootstrap resampling to test significance
c) Generate plots comparing model performance

6. REQUIRED OUTPUT:
a) Training logs showing loss curves
b) Evaluation metrics for each model:
- Overall F1, precision, recall
- Per-entity-type metrics
- Statistical significance results
c) Performance comparison plots
