ID: idea_114-simplified

entity-guided-summarization

Hypothesis

A two-step entity-guided prompting approach will produce summaries that are more informative and exhibit fewer hallucinations compared to standard single-prompt summarization, as measured by ROUGE-2 scores and entity overlap metrics.

Elements

  • Independent variable: Summarization method (entity-guided prompting vs. standard prompting)
  • Dependent variable: Summary informativeness and hallucination rate
  • Comparison groups: Summaries produced by entity-guided prompting vs. standard prompting
  • Baseline/control: Summaries generated using standard prompting
  • Context/setting: Document summarization tasks using publicly available datasets
  • Assumptions: Off-the-shelf LLMs can be effectively guided through carefully designed prompts
  • Relationship type: Causation
  • Population: News articles and scientific abstracts from public datasets
  • Timeframe: Not time-dependent
  • Measurement method: ROUGE-2 scores for informativeness, entity overlap for hallucination rate

Description

This research investigates whether a simple entity-guided prompting approach can improve the factual consistency and informativeness of summaries generated by off-the-shelf language models. Rather than implementing complex pruning techniques, this study focuses on developing a straightforward two-step prompting strategy: first identifying key entities in a source document, then explicitly instructing the model to include these entities when generating a summary. This approach aims to reduce hallucinations and improve informativeness by ensuring that important named entities from the source document are preserved in the summary, without requiring model modifications or specialized training.

Implementation Design

This experiment will compare entity-guided prompting against standard prompting for document summarization. Follow these steps:

1. Data Preparation:
- Select 100 articles from the CNN/Daily Mail dataset (available via HuggingFace)
- Split into 80 for main evaluation and 20 for prompt development

2. Entity Extraction:
- Use spaCy's named entity recognition to extract named entities from each source document
- Filter to keep only person, organization, location, and date entities
- Store the list of entities for each document

3. Implement two summarization approaches:
a. Baseline: Standard prompting
- Prompt: "Summarize the following text in 3-4 sentences: [SOURCE_TEXT]"
b. Entity-guided: Two-step prompting
- Step 1: Extract entities (already done in step 2)
- Step 2: Prompt: "Summarize the following text in 3-4 sentences. Make sure to include these key entities in your summary: [ENTITY_LIST]. Text: [SOURCE_TEXT]"

4. Generate summaries:
- Use GPT-3.5-Turbo API with temperature=0.3
- Generate one summary per approach for each document
- Store all generated summaries with their corresponding document IDs and approach labels

5. Evaluation:
- Calculate ROUGE-2 scores between generated summaries and reference summaries
- Calculate entity overlap: percentage of source document entities present in each summary
- Perform paired t-tests to determine statistical significance of differences
- Create visualizations comparing the two approaches

6. Analysis:
- Identify patterns in which types of documents benefit most from entity guidance
- Examine cases where entity-guided approach performs worse
- Analyze relationship between entity overlap and ROUGE scores

7. Output:
- Save all generated summaries in a CSV file with columns for document ID, approach, summary text
- Save evaluation metrics in a separate CSV with columns for document ID, approach, ROUGE-1, ROUGE-2, ROUGE-L, entity overlap
- Generate a summary report with key findings, statistical analysis, and visualizations
