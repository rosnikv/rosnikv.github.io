ID: idea_107-simplified

simple-attention-rnn-recommender

Hypothesis

Adding a simple attention mechanism to a vanilla RNN will improve recommendation accuracy on session-based movie recommendation tasks compared to a standard RNN without attention, as measured by precision@k and recall@k on the MovieLens 100K dataset.

Elements

  • Independent variable: Addition of a simple attention mechanism to a vanilla RNN
  • Dependent variable: Recommendation accuracy (precision@k and recall@k)
  • Comparison groups: RNN with attention vs. RNN without attention
  • Baseline/control: Vanilla RNN without attention
  • Context/setting: MovieLens 100K dataset with artificially created sessions
  • Assumptions: User interactions can be meaningfully grouped into sessions based on timestamps
  • Relationship type: Causation
  • Population: Users in the MovieLens 100K dataset
  • Timeframe: Not time-dependent; using existing dataset
  • Measurement method: Precision@k and recall@k for k=5,10,20

Description

This research explores a simplified approach to enhancing recommendation systems by integrating a basic attention mechanism with a vanilla RNN for session-based recommendations. Rather than implementing complex linear attention mechanisms, this project focuses on adding a straightforward attention layer to a standard RNN architecture to improve recommendation accuracy while maintaining reasonable computational efficiency. The study will use a small subset of the MovieLens dataset (100K version instead of 1M) to make the experiment more manageable with limited computational resources. By comparing this attention-enhanced RNN against a baseline vanilla RNN, the research aims to quantify the benefits of even simple attention mechanisms in recommendation tasks, providing insights that could inform more complex implementations in the future.

Implementation Design

## Experiment Design: Simple Attention RNN for Movie Recommendations

### 1. Data Preparation
- Download the MovieLens 100K dataset (https://grouplens.org/datasets/movielens/100k/)
- Create artificial sessions from the rating data by grouping user interactions by user ID and sorting by timestamp
- Consider interactions within a 24-hour window as a single session
- Split sessions into training (70%), validation (10%), and test (20%) sets
- Create input sequences of length 5 (use the first 4 items to predict the 5th item)

### 2. Model Implementation

#### Baseline RNN Model
- Implement a simple RNN model using PyTorch or TensorFlow
- Architecture:
- Embedding layer (movie_id → embedding_dim=50)
- GRU layer (hidden_dim=100, single layer)
- Fully connected output layer (hidden_dim → num_movies)
- Softmax activation

#### Attention-Enhanced RNN Model
- Extend the baseline RNN with a simple attention mechanism:
- Collect hidden states from all time steps
- Compute attention scores using a simple dot product between the last hidden state and all previous hidden states
- Apply softmax to get attention weights
- Create a context vector as the weighted sum of hidden states
- Concatenate the context vector with the last hidden state
- Pass through a fully connected layer to get predictions

### 3. Training Procedure
- Use cross-entropy loss
- Adam optimizer with learning rate 0.001
- Batch size of 64
- Train for 20 epochs with early stopping (patience=3) based on validation loss
- Record training time for each model

### 4. Evaluation
- For each test session, use the first 4 items as input and predict the 5th item
- Calculate precision@k and recall@k for k=5,10,20
- Record inference time for each model
- Compare the performance of both models using paired t-tests
- Create visualizations showing:
- Learning curves (training and validation loss)
- Bar charts comparing precision and recall metrics
- Attention weight visualizations for sample sessions

### 5. Output and Reporting
- Save trained models in PyTorch/TensorFlow format
- Generate a CSV file with all evaluation metrics
- Create a report with:
- Experiment setup and methodology
- Quantitative results (tables and charts)
- Qualitative analysis of attention patterns
- Discussion of findings and limitations
- Suggestions for future improvements

### 6. Code Organization
- Create modular code with separate files for:
- data_preprocessing.py: Data loading and session creation
- models.py: Model architectures
- train.py: Training loop and validation
- evaluate.py: Test set evaluation
- utils.py: Helper functions and metrics
- main.py: Script to run the entire pipeline

Operationalization

Data Requirements:

2. Create sessions by grouping user interactions within 24-hour windows

- Embedding layer (movie_id -> 32 dims)

- Simple dot-product attention over GRU hidden states
