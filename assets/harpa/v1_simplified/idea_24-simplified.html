Simple-HARGPT-Sleep-Analysis

Hypothesis

Using simple statistical feature extraction on sleep pattern data before analysis with a large language model will produce more accurate and interpretable health insights compared to using raw sleep data directly.

Elements

  • Independent variable: Data preprocessing approach (raw data vs. feature-extracted data)
  • Dependent variables: Accuracy of insights and interpretability score
  • Comparison groups: LLM analysis with raw data vs. LLM analysis with feature-extracted data
  • Baseline/control: LLM analysis with raw sleep data
  • Context/setting: Analysis of publicly available sleep pattern datasets
  • Assumptions: The LLM can process both raw and feature-extracted data to generate health insights
  • Relationship type: Causation
  • Population: Sleep monitoring datasets from public repositories
  • Timeframe: Short-term study (1-2 months)
  • Measurement method: Accuracy against expert-labeled data and user interpretability ratings

Description

This research explores the effectiveness of using a pre-trained large language model (LLM) with simple feature extraction techniques to analyze sleep pattern data. The study will focus on extracting basic statistical features from publicly available sleep datasets and using these features with prompt engineering to generate interpretable insights about sleep quality and patterns. The research will compare the performance of using raw data directly with the LLM versus using extracted features, evaluating both the accuracy of the insights and their interpretability to non-expert users.

Operationalization

Please create an experiment to compare LLM analysis of raw sleep data versus feature-extracted sleep data, with the following specifications:

## Experiment Mode
Implement three experimental modes controlled by a global variable PILOT_MODE:
1. MINI_PILOT: Process 5 sleep sessions, 10 expert-annotated insights each
2. PILOT: Process 25 sleep sessions, 10 expert-annotated insights each
3. FULL_EXPERIMENT: Process all 100 sleep sessions

Initially run only MINI_PILOT. If successful, proceed to PILOT, then stop.

## Data Processing
1. Load the Sleep-EDF dataset
2. For each sleep session:
- Raw condition: Downsample to 1 sample/minute
- Feature condition: Calculate per 30-min window:
* Mean, median, std
* Min/max values
* Peak count (>1.5 std)
* Signal energy
* Zero-crossing rate

## LLM Analysis
Use gpt-4o-mini (as specified) with two prompt templates:
1. Raw: "Analyze this sleep data (one measurement per minute) and provide 3 specific insights about sleep quality: [DATA]"
2. Feature: "Analyze these statistical features from a 30-minute window of sleep data and provide 3 specific insights about sleep quality: [FEATURES]"

## Evaluation
1. Accuracy (vs expert annotations):
- Binary score (0/1) for each insight
- Calculate mean accuracy per condition

2. Interpretability:
Score each insight 1-5 on:
- Clarity
- Specificity
- Actionability
Calculate mean interpretability score

## Statistical Analysis
Use bootstrap resampling to compare:
1. Accuracy between conditions
2. Interpretability between conditions

## Visualization
Create line plots showing:
1. Accuracy comparison
2. Interpretability comparison
3. Combined performance plot

## Output
1. CSV files with raw results
2. Summary statistics
3. Visualization PDFs
4. Log file with full execution details

## Required Validation
MINI_PILOT must demonstrate:
1. Successful data loading
2. Feature extraction working
3. LLM calls working
4. Evaluation metrics calculating
5. Basic plots generating

PILOT must additionally show:
1. Statistical significance testing working
2. Full result storage/loading working
3. Comprehensive visualization generation

Please implement this experiment, starting with MINI_PILOT mode.
