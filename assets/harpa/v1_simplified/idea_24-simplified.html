Simple-HARGPT-Sleep-Analysis

Hypothesis

Using simple statistical feature extraction on sleep pattern data before analysis with a large language model will produce more accurate and interpretable health insights compared to using raw sleep data directly.

Elements

  • Independent variable: Data preprocessing approach (raw data vs. feature-extracted data)
  • Dependent variables: Accuracy of insights and interpretability score
  • Comparison groups: LLM analysis with raw data vs. LLM analysis with feature-extracted data
  • Baseline/control: LLM analysis with raw sleep data
  • Context/setting: Analysis of publicly available sleep pattern datasets
  • Assumptions: The LLM can process both raw and feature-extracted data to generate health insights
  • Relationship type: Causation
  • Population: Sleep monitoring datasets from public repositories
  • Timeframe: Short-term study (1-2 months)
  • Measurement method: Accuracy against expert-labeled data and user interpretability ratings

Description

This research explores the effectiveness of using a pre-trained large language model (LLM) with simple feature extraction techniques to analyze sleep pattern data. The study will focus on extracting basic statistical features from publicly available sleep datasets and using these features with prompt engineering to generate interpretable insights about sleep quality and patterns. The research will compare the performance of using raw data directly with the LLM versus using extracted features, evaluating both the accuracy of the insights and their interpretability to non-expert users.

Implementation Design

# Simple-HARGPT-Sleep-Analysis Experiment Design

## Overview
This experiment compares the effectiveness of using a large language model (LLM) to analyze sleep pattern data in two conditions: (1) using raw time-series data directly, and (2) using simple statistical features extracted from the data.

## Data
1. Use the 'Sleep-EDF' dataset from PhysioNet (https://physionet.org/content/sleep-edfx/1.0.0/) which contains polysomnographic sleep recordings.
2. For the pilot, select 100 random sleep sessions that have expert annotations about sleep quality and patterns.
3. Each sleep session should include at least 6 hours of continuous data.

## Implementation Steps

### 1. Data Preprocessing
- Load the sleep data using the `mne` Python package which supports EDF format.
- For the raw data condition: Downsample the data to 1 sample per minute and convert to a simple time-series format.
- For the feature extraction condition, calculate the following features for each 30-minute window:
- Mean, median, and standard deviation of the signal
- Minimum and maximum values
- Number of peaks (values above 1.5 standard deviations from the mean)
- Signal energy (sum of squared values)
- Zero-crossing rate

### 2. LLM Setup
- Use OpenAI's GPT-4 API through the `openai` Python package.
- Create two prompt templates:
- Raw data prompt: "Analyze this sleep pattern data and provide insights about sleep quality and potential issues: [RAW_DATA]"
- Feature-extracted prompt: "Analyze these statistical features from sleep pattern data and provide insights about sleep quality and potential issues: [FEATURES]"

### 3. Experiment Execution
- For each sleep session in your dataset:
- Process the data to create both raw and feature-extracted versions
- Send both versions to the LLM using their respective prompts
- Store the generated insights for both conditions
- Compare against expert annotations (ground truth)

### 4. Evaluation
- Accuracy evaluation:
- Create a simple binary scoring system where each insight is marked as correct or incorrect based on agreement with expert annotations
- Calculate accuracy as (number of correct insights) / (total number of insights)
- Interpretability evaluation:
- Create a rubric to score each insight on a 1-5 scale for:
- Clarity: How easy is it to understand the insight?
- Specificity: How specific and detailed is the insight?
- Actionability: Does the insight suggest clear actions or implications?
- Calculate an overall interpretability score as the average of these three dimensions

### 5. Analysis
- Calculate mean and standard deviation of accuracy and interpretability scores for both conditions
- Perform a paired t-test to determine if differences between conditions are statistically significant
- Create visualizations comparing the performance of both approaches

### 6. Output and Reporting
- Save all generated insights, accuracy scores, and interpretability scores to CSV files
- Generate a summary report with key findings, including:
- Average accuracy and interpretability scores for both conditions
- Statistical significance of differences
- Examples of insights from both conditions for the same sleep session
- Recommendations for which approach is more effective

## Code Structure
1. `data_loader.py`: Functions to load and preprocess the Sleep-EDF dataset
2. `feature_extraction.py`: Functions to extract statistical features from sleep data

5. `main.py`: Script to run the entire experiment
