Layer-Specific-Editing-GPT2

Hypothesis

Applying Layer-Specific Parameter Adjustment to middle layers of GPT-2 will result in higher editing success rates and better generalization across paraphrased prompts compared to uniform editing across all layers when tested on financial fact datasets.

Elements

  • Independent variable: Layer selection for parameter adjustment (middle layers vs. all layers uniformly)
  • Dependent variable: Editing success rate and generalization score across paraphrased prompts
  • Comparison groups: Middle layers editing vs. uniform editing across all layers
  • Baseline/control: Uniform editing across all layers
  • Context/setting: Financial fact datasets
  • Assumptions: Middle layers contain more factual knowledge representations than other layers
  • Relationship type: Causation
  • Population: GPT-2 small model applied to financial datasets
  • Timeframe: Not applicable
  • Measurement method: Editing success rate and generalization score

Description

This research investigates the effectiveness of Layer-Specific Parameter Adjustment for knowledge editing in GPT-2 models, focusing specifically on the finance domain. By targeting specific layers within the model architecture for parameter modification, we aim to improve the model's ability to integrate new knowledge while preserving existing information. This approach is inspired by techniques like Rank-One Model Editing (ROME) but simplified to focus on identifying which layers are most effective for knowledge editing. The study will use a curated dataset of financial facts and evaluate performance through metrics like editing success rate and generalization across paraphrased prompts. This research provides insights into how targeted parameter adjustments in language models can enhance knowledge editing capabilities, with potential applications in maintaining up-to-date financial information in AI systems.

Operationalization

Please implement an experiment to evaluate Layer-Specific Parameter Adjustment in GPT-2 models for knowledge editing in the finance domain. The experiment should be implemented with three pilot modes (MINI_PILOT, PILOT, FULL_EXPERIMENT), defined as follows:

PILOT MODES:
- MINI_PILOT: Use 5 financial facts, 2 paraphrases each, test on training set only
- PILOT: Use 25 financial facts, 3 paraphrases each, test on training and dev sets
- FULL_EXPERIMENT: Use 50 financial facts, 5 paraphrases each, proper train/dev/test split

STEP 1 - DATASET GENERATION:
1. Use the Data Generation with LLM codeblock to create financial facts dataset:
- Format: {"original_fact": "X is Y", "edited_fact": "X is Z", "prompt": "What is X?", "paraphrases": [...]}
- Example prompt for gpt-4o-mini: "Generate a financial fact about [company/metric], then generate an updated version of this fact, and 3 different ways to ask about this fact."
- Validate generated facts to ensure they're suitable for editing

STEP 2 - MODEL SETUP:
1. Load GPT-2 small model from HuggingFace
2. Create two editing approaches:
- Baseline: Uniform editing across all 12 layers
- Experimental: Editing only middle layers (4,5,6)

STEP 3 - EVALUATION PIPELINE:
1. For each fact:
- Apply editing method (baseline or experimental)
- Test with original prompt
- Test with paraphrased prompts
- Reset model to original state
2. Calculate metrics:
- Editing Success Rate = (successful edits / total edits) * 100
- Generalization Score = (successful paraphrase recalls / total paraphrases) * 100

STEP 4 - ANALYSIS:
1. Use Non-parametric Bootstrap Resampling to compare:
- Editing Success Rate between conditions
- Generalization Score between conditions
2. Create visualizations using MatPlotLib Line Plot:
- Success rates over different facts
- Generalization scores comparison

- Visualization plots
