PET-Stance-Detection

Hypothesis

Pattern-Exploiting Training with sentiment-based patterns will improve the macro F1 score of stance detection models in English social media texts compared to a standard BERT baseline.

Elements

  • Independent variable: Application of Pattern-Exploiting Training with sentiment-based patterns
  • Dependent variable: Macro F1 score of stance detection models
  • Comparison groups: Models with Pattern-Exploiting Training vs. standard BERT baseline
  • Baseline/control: Standard BERT baseline
  • Context/setting: English social media texts
  • Assumptions: The application of Pattern-Exploiting Training will lead to improvement
  • Relationship type: Causation
  • Population: Stance detection models in English social media
  • Timeframe: Not specified
  • Measurement method: Macro F1 score

Description

This research explores the application of Pattern-Exploiting Training (PET) to enhance stance detection in English social media texts. PET is a technique that converts input examples into cloze-style questions, which can help the model better understand the relationship between sentiment and stance. By designing patterns that incorporate sentiment cues, the model is expected to capture nuanced sentiment expressions that are crucial for accurate stance detection. This approach is particularly relevant for social media texts, where language is often informal and sentiment expressions are diverse. The research will focus on a single language (English) and a single technique (PET) to make it more manageable for an undergraduate or MSc research assistant. The hypothesis is that PET with sentiment-based patterns will improve the macro F1 score of stance detection models compared to a standard BERT baseline. This simplified approach removes the complexity of cross-lingual analysis and the integration of multiple advanced techniques, while still maintaining the potential for a novel and impactful contribution to the field of stance detection.

Implementation Design

This experiment will investigate whether Pattern-Exploiting Training (PET) can improve stance detection in English social media texts compared to a standard BERT baseline. Follow these steps to implement the experiment:

1. Data Preparation:
- Use the SemEval-2016 Task 6 dataset (Subtask A: Supervised Stance Detection), which contains tweets labeled with stance (favor, against, or neutral) towards specific targets.
- Split the dataset into training (70%), validation (15%), and test (15%) sets, ensuring balanced distribution of stance labels.
- Preprocess the tweets by removing URLs, converting to lowercase, and tokenizing.

2. BERT Baseline Implementation:
- Use the Hugging Face Transformers library to load the pre-trained BERT-base-uncased model.
- Add a classification head on top of BERT for the stance detection task (3 classes: favor, against, neutral).
- Fine-tune the model on the training set using the AdamW optimizer with a learning rate of 2e-5 and batch size of 16 for 4 epochs.
- Use early stopping based on validation performance to prevent overfitting.
- Save the best model based on validation macro F1 score.

3. PET Implementation:
- Design sentiment-based patterns for PET. For example:
- "The tweet '{tweet}' expresses a [MASK] stance towards {target}."
- "The author of '{tweet}' is [MASK] {target}."
- "'{tweet}' [MASK] support {target}."
- Map the [MASK] token to the appropriate verbalizers for each stance class:
- favor: "positive", "supporting", "does"
- against: "negative", "opposing", "doesn't"
- neutral: "neutral", "indifferent", "may"
- Implement PET using the Hugging Face Transformers library and the same BERT-base-uncased model.
- Train the PET model on the training set using the same optimization parameters as the baseline.
- Save the best model based on validation macro F1 score.

4. Evaluation:
- Evaluate both models on the test set, calculating precision, recall, and F1 score for each class.
- Calculate the macro F1 score (average of F1 scores across all classes) as the primary metric.
- Perform bootstrap resampling (1000 iterations) to assess the statistical significance of any performance differences.
- Conduct an error analysis to identify the types of examples where PET performs better or worse than the baseline.

5. Output and Reporting:
- Save the predictions of both models on the test set in CSV format.
- Generate confusion matrices for both models.
- Create a table comparing the performance metrics (precision, recall, F1) for each class and the macro F1 score.
- Plot the learning curves (training and validation loss/accuracy) for both models.
- Write a brief report summarizing the findings, including whether the hypothesis was supported, the statistical significance of the results, and insights from the error analysis.

The experiment should be implemented in Python, using PyTorch for the neural network models and scikit-learn for evaluation metrics. All code should be well-documented and organized into modular functions for data loading, model training, evaluation, and visualization.
