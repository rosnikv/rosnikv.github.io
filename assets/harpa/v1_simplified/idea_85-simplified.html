prompt-enhanced-mwp-solver

Hypothesis

Structured prompt templates that highlight key entities and emphasize the question will improve the accuracy of language model-based Math Word Problem solvers on the SVAMP dataset compared to standard prompting approaches.

Elements

  • Independent variable: Prompt template structure (different ways of formatting the input)
  • Dependent variable: Accuracy of Math Word Problem solvers
  • Comparison groups: Different prompt template structures vs. standard prompting
  • Baseline/control: Standard prompting approach (presenting the problem as-is)
  • Context/setting: SVAMP dataset (or a manageable subset)
  • Assumptions: Language models can be effectively guided through prompt engineering
  • Relationship type: Causation
  • Population: Math Word Problem instances in the SVAMP dataset
  • Timeframe: Not specified
  • Measurement method: Comparison of accuracy metrics

Description

This research investigates how prompt engineering techniques can improve the performance of Math Word Problem (MWP) solvers. Rather than implementing a complex graph-based encoding system, this study focuses on developing and testing different prompt templates that guide language models to better understand and solve math word problems. The research will explore how structuring prompts to highlight key entities, relationships, and the question itself affects solver accuracy on the SVAMP dataset. By systematically comparing different prompt structures, the study aims to identify effective strategies for enhancing MWP solver performance without requiring extensive computational resources or advanced graph neural network implementations.

Operationalization

Please build an experiment to test whether different prompt templates improve math word problem solving accuracy. The experiment should follow these specifications:

PILOT MODES:
- MINI_PILOT: Use 10 random problems from SVAMP training set
- PILOT: Use 100 random problems from SVAMP training set, and 50 from dev set
- FULL_EXPERIMENT: Use full SVAMP dataset
Start with MINI_PILOT, then if successful, run PILOT. Stop before FULL_EXPERIMENT.

DATASET:
1. Use Huggingface Datasets to load SVAMP dataset
2. For each pilot mode, randomly sample appropriate number of problems
3. Store problem text, equation, and answer

PROMPT TEMPLATES:
1. Baseline Template:
- Present problem as-is
- Add only: 'Solve this math word problem:'

2. Question-First Template:
- Extract question from problem
- Format as: 'Question: [QUESTION]\nContext: [REMAINING TEXT]\nSolve this step by step:'

3. Entity-Highlight Template:
- Identify numbers and associated objects
- Format as: 'Important Information:\n- [NUMBER1] [OBJECT1]\n- [NUMBER2] [OBJECT2]\n\nQuestion: [QUESTION]\nSolve this step by step:'

IMPLEMENTATION:
1. For each problem:
- Apply each template
- Use gpt-4o-mini for all LLM calls
- Extract numerical answer from response
- Compare to ground truth
- Log full prompt, response, extracted answer, and correctness

EVALUATION:
1. Calculate for each template:
- Accuracy (% correct)
- Average response time
- Average token usage

2. Statistical Analysis:
- Use bootstrap resampling to compare templates
- Calculate 95% confidence intervals

3. Visualization:
- Bar plot of accuracies with error bars
- Line plot of accuracy by problem type

OUTPUT:
1. JSON file containing:
- All prompts, responses, and evaluations
- Summary statistics
- Statistical test results

2. PDF files containing:
- Accuracy comparison plots
- Error analysis visualizations

3. Log file containing:
- All experiment parameters
- Any errors or warnings
- Timing information

The experiment should first run MINI_PILOT. If successful (no errors, reasonable outputs), proceed to PILOT. Stop before FULL_EXPERIMENT and await human verification.
