Hypothesis

Low-Rank Adaptation (LoRA) will demonstrate improved accuracy and consistency in editing commonsense knowledge in GPT-2 Small compared to traditional fine-tuning, while requiring fewer computational resources.

Elements

  • Independent variable: Knowledge editing method (LoRA vs. traditional fine-tuning)
  • Dependent variables: 1) Accuracy of edited knowledge, 2) Consistency of knowledge across contexts, 3) Computational resources required
  • Comparison groups: LoRA-edited model vs. traditionally fine-tuned model
  • Baseline/control: Unmodified GPT-2 Small model
  • Context/setting: Editing commonsense knowledge in GPT-2 Small
  • Assumptions: LoRA can be effectively applied to edit commonsense knowledge
  • Relationship type: Causation
  • Population: GPT-2 Small model
  • Timeframe: Two-week evaluation period
  • Measurement method: Comparison of accuracy, consistency, and computational resource metrics

Description

This research investigates the effectiveness of Low-Rank Adaptation (LoRA) for editing commonsense knowledge in smaller language models. Rather than combining multiple complex techniques, this study focuses solely on LoRA as a lightweight approach to knowledge editing. The research will evaluate how well LoRA can update specific commonsense facts in a small pre-trained language model (GPT-2 Small) compared to traditional fine-tuning methods. By focusing on a smaller model and a single editing technique, this research provides an accessible entry point to knowledge editing research while still addressing the important challenge of maintaining accurate commonsense knowledge in language models.

Implementation Design

# Experiment Design: Evaluating LoRA for Commonsense Knowledge Editing

## 1. Implementation Details

### A. Models to Implement
1. **Baseline Model**: Unmodified GPT-2 Small
- Load the pre-trained GPT-2 Small model using the Hugging Face Transformers library
- No modifications to this model

2. **Fine-tuned Model**: GPT-2 Small with traditional fine-tuning
- Fine-tune the model on a dataset of commonsense knowledge statements
- Use standard fine-tuning procedures with a low learning rate (1e-5)
- Train for 3 epochs on the knowledge dataset

3. **LoRA Model**: GPT-2 Small with LoRA adaptation
- Implement LoRA using the PEFT library from Hugging Face
- Configure LoRA with rank=8, alpha=16, and target modules=['q_proj', 'v_proj']
- Train on the same knowledge dataset as the fine-tuned model
- Use the same learning rate and number of epochs

### B. Knowledge Editing Algorithm
1. **Knowledge Dataset Creation**:
- Create a dataset of 50 commonsense knowledge statements (for the full experiment) or 10 statements (for the pilot)
- Each statement should be a simple factual assertion (e.g., "The sky is blue", "Water freezes at 0 degrees Celsius")
- Format each statement as a completion task: "Question: What color is the sky? Answer: The sky is blue."

2. **LoRA Implementation**:
```python
from peft import get_peft_model, LoraConfig, TaskType

# Define LoRA configuration
lora_config = LoraConfig(
r=8, # rank
lora_alpha=16,
target_modules=["q_proj", "v_proj"],
lora_dropout=0.05,
bias="none",
task_type=TaskType.CAUSAL_LM
)

# Get PEFT model
lora_model = get_peft_model(base_model, lora_config)

# Train the model
trainer = Trainer(
model=lora_model,
train_dataset=knowledge_dataset,
args=training_args,
data_collator=data_collator,
)
trainer.train()
```

## 2. Data to Use

### A. Knowledge Dataset
- For the pilot: Create 10 commonsense knowledge statements
- For the full experiment: Create 50 commonsense knowledge statements
- Each statement should be something that the base model might get wrong or be uncertain about
- Example statements:
- "The capital of France is Paris."
- "Water boils at 100 degrees Celsius at sea level."
- "The Earth orbits around the Sun."
- "Humans have two lungs."

### B. Evaluation Dataset
- Create 5 different phrasings/questions for each knowledge statement
- Example for "The capital of France is Paris":
1. "What is the capital of France?"
2. "Which city serves as France's capital?"
3. "Paris is the capital of which country?"
4. "Name the capital city of France."
5. "Which European city is the capital of France?"

## 3. Output Generation and Evaluation

### A. Model Evaluation
1. **Accuracy Evaluation**:
- For each model (baseline, fine-tuned, LoRA), evaluate responses to all questions
- Score each response as correct (1) or incorrect (0)
- Calculate accuracy as percentage of correct responses

2. **Consistency Evaluation**:
- For each knowledge fact, check if all 5 question variations receive consistent answers
- Score consistency as percentage of facts where all questions received consistent answers

3. **Computational Efficiency Measurement**:
- Record training time for both fine-tuning and LoRA methods
- Measure peak memory usage during training
- Count number of parameters updated in each method
