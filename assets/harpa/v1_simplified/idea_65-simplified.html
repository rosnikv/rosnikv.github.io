ID: idea_65-simplified

middle-context-attention

Hypothesis

Modifying BERT's attention mechanism to emphasize middle-context information will improve narrative understanding performance on short stories, as measured by F1 score on a question-answering task, compared to the unmodified BERT model.

Elements

  • Independent variable: Modification of BERT's attention weights to emphasize middle-context information
  • Dependent variable: Narrative understanding performance on short stories
  • Comparison groups: Modified BERT model vs. unmodified BERT model
  • Baseline/control: Unmodified BERT model
  • Context/setting: Question-answering tasks on short narrative texts
  • Assumptions: Middle-context information is important for narrative understanding and can be emphasized through simple attention weight modifications
  • Relationship type: Causation
  • Population: Short narrative texts from a public dataset
  • Timeframe: Not applicable
  • Measurement method: F1 score on question-answering tasks

Description

This research explores a simplified approach to enhancing BERT's narrative understanding by focusing on middle-context information. Rather than implementing a full hierarchical attention mechanism, this project will modify a pre-trained BERT model by adjusting the attention weights to emphasize tokens in the middle of input sequences. This approach is motivated by the observation that middle-context information is often crucial for understanding narratives but may be underrepresented in standard attention mechanisms. The project will implement a straightforward attention modification layer that can be added on top of a pre-trained BERT model, requiring minimal architectural changes while potentially yielding meaningful improvements in narrative understanding tasks.

Operationalization

Please implement an experiment to test whether modifying BERT's attention mechanism to emphasize middle-context information improves narrative understanding. The experiment should support three pilot modes (set via PILOT_MODE global variable):

1. MINI_PILOT:
- Use only 10 questions from SQuAD's training set
- Train for 1 epoch
- Batch size of 2
- Evaluate on same 10 questions
- Generate basic visualizations of attention patterns
- Run bootstrap with 100 samples

2. PILOT:
- Use 200 questions from SQuAD's training set
- Train for 2 epochs
- Batch size of 8
- Evaluate on 50 questions from validation set
- Generate detailed visualizations
- Run bootstrap with 500 samples

3. FULL_EXPERIMENT (not to be run initially):
- Use full SQuAD dataset
- Train for 3 epochs
- Batch size of 16
- Full evaluation protocol
- Complete analysis suite

Implementation Steps:

1. Dataset Loading:
- Use the Huggingface Datasets API to load SQuAD
- Filter for questions about narratives/stories
- Split according to pilot mode
- Log dataset statistics

2. Model Implementation:
- Load BERT-base using Huggingface
- Implement Gaussian attention weighting:
* w(i) = exp(-((i-μ)²)/(2σ²))
* μ = sequence_length/2
* σ = sequence_length/4
- Create toggle for attention modification

3. Training Loop:
- Train baseline (unmodified BERT)
- Train experimental (with middle-context attention)
- Log training metrics every 10 steps
- Save best checkpoint based on validation

4. Evaluation:
- Calculate F1, accuracy, exact match
- Run bootstrap resampling
- Generate attention pattern visualizations
- Log all metrics and statistical tests

5. Required Outputs:
- Training/validation curves
- Performance metrics table
- Statistical significance results
- Attention pattern visualizations
- Detailed log file

The experiment should first run MINI_PILOT. If successful, proceed to PILOT. Stop before FULL_EXPERIMENT for human verification.

Use gpt-4o-mini for any LLM calls. Log all major steps and errors comprehensively. Generate clear visualizations of attention patterns and performance metrics.
