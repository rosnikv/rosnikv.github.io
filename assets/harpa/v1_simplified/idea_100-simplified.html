ID: idea_100-simplified

rouge-hallu-evaluation

Hypothesis

Integrating ROUGE Score and a simplified entity-based hallucination detection method into a unified evaluation framework will provide more comprehensive and reliable LLM evaluations than using either metric individually.

Elements

  • Independent variable: Integration of ROUGE Score and entity-based hallucination detection
  • Dependent variable: Comprehensiveness and reliability of LLM evaluations
  • Comparison groups: Unified evaluation framework vs. individual metrics
  • Baseline/control: Using each metric individually
  • Context/setting: LLM evaluations on a curated dataset
  • Assumptions: Integration will lead to more informative evaluations
  • Relationship type: Comparative analysis
  • Population: Text generation tasks with factual content
  • Timeframe: Not specified
  • Measurement method: Assessment of content quality and factual accuracy

Description

This research aims to develop a focused evaluation framework for Large Language Models (LLMs) by integrating two complementary metrics: ROUGE Score and a simplified hallucination detection method. The ROUGE Score will measure token overlap between generated and reference texts, while the hallucination detection will focus on identifying named entity inconsistencies in generated content. By combining these two metrics, the framework will provide a balanced evaluation of LLMs, addressing both content quality and factual accuracy. The research will involve implementing these metrics in a Python-based framework, testing them on a small, well-defined dataset, and comparing the results to evaluations using each metric individually. The expected outcome is a practical evaluation tool that offers insights into LLM performance across multiple dimensions, potentially guiding future model improvements.

Operationalization

Please implement a dual-metric LLM evaluation framework that combines ROUGE Score with entity-based hallucination detection. The experiment should support three pilot modes (PILOT_MODE: str = 'MINI_PILOT' | 'PILOT' | 'FULL_EXPERIMENT').

Pilot Configurations:
- MINI_PILOT: Use 5 examples each from CNN/Daily Mail and SQuAD datasets. Generate responses using gpt-4o-mini. Human evaluation on 4 examples total. Run time ~5-10 minutes.
- PILOT: Use 50 examples each from CNN/Daily Mail and SQuAD datasets. Generate responses using gpt-4o-mini. Human evaluation on 20 examples total. Run time ~1-2 hours.
- FULL_EXPERIMENT: Use full experiment configuration (500 examples each). Do not implement yet - will be manually triggered after pilot validation.

Implementation Steps:

1. Dataset Preparation:
- Use the Huggingface Datasets API to load CNN/Daily Mail and SQuAD datasets
- For CNN/Daily Mail: Select examples with clear reference summaries
- For SQuAD: Select question-answer pairs with context
- Log the number of examples loaded and basic statistics

2. Text Generation:
- Use gpt-4o-mini through the LLM proxy server
- For summarization: Generate summaries of CNN/Daily Mail articles
- For QA: Generate answers to SQuAD questions
- Store generated texts alongside references

3. Metric Implementation:
- ROUGE Score: Calculate ROUGE-1, ROUGE-2, and ROUGE-L F1 scores
- Entity Detection: Extract named entities from both generated and reference texts
- Calculate entity precision/recall/F1 between generated and reference entities
- Implement two combination methods:
a) Simple average of normalized scores
b) Weighted average (weights: [0.7, 0.3] for ROUGE and entity scores)

4. Evaluation Process:
- Calculate individual metrics (ROUGE, entity) for each example
- Calculate combined metrics using both methods
- For human evaluation subset:
* Present pairs of texts (generated vs reference)
* Collect ratings (1-5) for content quality and factual accuracy
* Store ratings in a structured format

5. Analysis:
- Use bootstrap resampling to compare:
* Individual metrics vs combined metrics
* Simple average vs weighted combination
* Performance across tasks (summarization vs QA)
- Generate plots showing score distributions
- Calculate correlations between human and automated scores

Required Outputs:
1. results.json: Contains all raw scores and statistics
2. plots/: Directory containing:
- metric_distributions.pdf: Score distributions
- correlation_plots.pdf: Human vs automated scores
3. logs/: Directory containing detailed execution logs

Special Instructions:
- Start with MINI_PILOT mode
- If successful, proceed to PILOT mode
- Stop after PILOT mode completion
- Log all major steps and any errors
- Save intermediate results frequently

Baselines:
