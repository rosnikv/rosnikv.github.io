ID: idea_109-simplified

basic-prompt-tuned-summarization

Hypothesis

Carefully designed domain-specific prompts will improve ROUGE scores for scientific document summarization compared to generic prompting approaches when using the same pre-trained language model.

Elements

  • Independent variable: Prompt design (domain-specific vs. generic)
  • Dependent variable: Summary quality measured by ROUGE scores
  • Comparison groups: Summaries generated using domain-specific prompts vs. summaries generated using generic prompts
  • Baseline/control: Summaries generated using generic prompts
  • Context/setting: Scientific document summarization
  • Assumptions: Pre-trained language models are sensitive to prompt design
  • Relationship type: Causation
  • Population: Scientific documents (limited to a manageable subset)
  • Timeframe: Not specified
  • Measurement method: ROUGE scores for summarization performance

Description

This research explores the effectiveness of simple prompt-tuning techniques for improving scientific document summarization. Rather than implementing complex dynamic weight visualization, this study focuses on comparing different prompt templates for guiding pre-trained language models to generate better scientific summaries. The research will test a small set of carefully designed prompts that incorporate domain-specific cues for scientific text, and evaluate their impact on summary quality using standard metrics. This approach provides a straightforward yet potentially impactful investigation into how prompt engineering can improve domain-specific summarization without requiring extensive computational resources or advanced technical expertise.

Operationalization

Please create an experiment to evaluate how domain-specific prompts affect scientific document summarization quality. The experiment should follow these specifications:

PILOT MODES:
- MINI_PILOT: Use 10 scientific papers from training set
- PILOT: Use 100 papers (60 train, 20 dev, 20 test)
- FULL_EXPERIMENT: Use full dataset (not implemented in this phase)

DATA PREPARATION:
1. Use the Huggingface Datasets API to load the 'arxiv_dataset' or 'pubmed_rct' dataset
2. Each document should have both full text and abstract (reference summary)
3. Filter to ensure documents are in English and have both text fields
4. For MINI_PILOT, randomly select 10 training examples
5. For PILOT, randomly select 100 examples and split 60/20/20

PROMPT TEMPLATES:
1. Baseline (generic) prompt:
"Summarize the following scientific text: [TEXT]"

2. Domain-specific prompts:
a. "Create a concise scientific abstract highlighting the methodology, results, and implications of this research: [TEXT]"
b. "As a scientific researcher, summarize the key findings, methods, and significance of this study: [TEXT]"
c. "Extract the main hypothesis, experimental approach, results, and conclusions from this scientific paper: [TEXT]"

EXPERIMENT STEPS:
1. Initialize logger and load dataset
2. For each document:
- Generate summary using gpt-4o-mini with each prompt template
- Calculate ROUGE-1, ROUGE-2, ROUGE-L scores against reference summary
- Store results in a structured format

3. Analysis:
- Calculate mean/std of ROUGE scores for each prompt type
- Use bootstrap resampling to test statistical significance
- Generate plots comparing ROUGE scores across prompts
- Save example summaries and their scores

REQUIRED OUTPUTS:
1. JSON file containing:
- All generated summaries
- ROUGE scores for each summary
- Prompt templates used
- Statistical test results

2. Plots:
- Box plots of ROUGE scores by prompt type
- Bar plots of mean scores with error bars

3. Log file with:
- Full experimental setup
- All error messages
- Progress updates
- Final results summary

RUNNING THE EXPERIMENT:
1. Start with MINI_PILOT mode
2. If successful, proceed to PILOT mode
3. Stop after PILOT mode for human verification

EVALUATION CRITERIA:
1. Required:
- Successfully generates summaries
- Calculates ROUGE scores
- Performs statistical comparison
- Creates visualizations
- Provides example summaries

2. Optional:
- Summary length analysis
- Scientific terminology analysis
