Hypothesis

Implementing a simple contrastive learning approach with a pre-trained BERT model will improve precision and recall in evidence retrieval for multi-hop question answering tasks on a subset of the HotpotQA dataset compared to a standard BM25 retrieval baseline.

Elements

  • Independent variable: Retrieval method (contrastive learning with BERT vs. BM25 baseline)
  • Dependent variable: Precision and recall in evidence retrieval
  • Comparison groups: Contrastive learning with BERT vs. BM25 baseline
  • Baseline/control: BM25 retrieval algorithm
  • Context/setting: Multi-hop question answering tasks on a subset of the HotpotQA dataset
  • Assumptions: The implementation of the contrastive learning approach will be feasible with limited computational resources
  • Relationship type: Causation
  • Population: A subset of tasks within the HotpotQA dataset (e.g., 1000 examples)
  • Timeframe: Not specified
  • Measurement method: Precision, recall, and F1 metrics

Description

This research explores a simplified approach to improving evidence retrieval for multi-hop question answering by implementing a basic contrastive learning technique on top of pre-trained language models. Rather than developing a complex Entity-centered Fusion Encoder, this project focuses on using existing BERT-based models with a straightforward contrastive learning objective to distinguish between relevant and irrelevant evidence passages. The study will use a subset of the HotpotQA dataset to evaluate whether this lightweight approach can improve precision and recall in evidence retrieval compared to a standard retrieval baseline. This simplified approach makes the research more accessible while still addressing the important challenge of improving evidence retrieval for multi-hop question answering.

# Simplified Evidence Retrieval with Contrastive Learning

## Experiment Design

### 1. Data Preparation
- Download the HotpotQA dataset from the official source (https://hotpotqa.github.io/)
- Select a subset of 1000 examples from the training set for training and 200 examples from the development set for evaluation
- For each question in the dataset, identify the supporting facts (positive examples) and non-supporting facts (negative examples)
- Create training pairs consisting of (question, positive example) and (question, negative example)

### 2. Model Implementation

#### BM25 Baseline
- Implement the BM25 retrieval algorithm using the `rank_bm25` Python package
- For each question, retrieve the top-10 passages from the candidate pool
- Evaluate the precision, recall, and F1 score of the retrieved passages

#### BERT Baseline
- Use the pre-trained BERT-base model from Hugging Face's Transformers library
- Fine-tune the model on the HotpotQA subset to predict relevance scores for (question, passage) pairs
- Use binary cross-entropy loss for training
- For each question, retrieve the top-10 passages based on relevance scores
- Evaluate the precision, recall, and F1 score of the retrieved passages

#### Contrastive Learning Model
- Use the pre-trained BERT-base model from Hugging Face's Transformers library
- Implement a simple contrastive learning approach:
- For each question, create triplets of (question, positive passage, negative passage)
- Encode the question and passages using BERT
- Calculate the similarity between the question and each passage using cosine similarity
- Apply a contrastive loss function that maximizes the similarity between the question and positive passage while minimizing the similarity between the question and negative passage
- Use the following contrastive loss function: L = max(0, margin - sim(q, pos) + sim(q, neg))
- Train the model for 5 epochs with a batch size of 16
- For each question, retrieve the top-10 passages based on similarity scores
- Evaluate the precision, recall, and F1 score of the retrieved passages

### 3. Evaluation
- For each model (BM25, BERT baseline, Contrastive Learning), calculate:
- Precision@10: The proportion of correctly retrieved evidence in the top-10 results
- Recall@10: The proportion of all relevant evidence retrieved in the top-10 results
- F1@10: The harmonic mean of precision and recall
- Perform statistical significance testing using paired t-tests to compare the performance of the models
- Create visualizations to compare the performance of the models

### 4. Analysis
- Analyze the types of questions where the contrastive learning approach performs better or worse than the baselines
- Examine examples where the contrastive learning approach succeeds but the baselines fail, and vice versa
- Discuss the limitations of the approach and potential improvements

### 5. Output and Reporting
- Save the trained models and their predictions
- Generate a report with the following sections:
- Introduction and motivation
- Methodology
- Results
- Analysis
- Conclusion and future work
- Include tables and figures to illustrate the results

### Data Loading and Preprocessing
```python
import json
import random
import numpy as np
import torch
from torch.utils.data import Dataset, DataLoader

# Load HotpotQA dataset
def load_hotpotqa_subset(file_path, num_examples):
with open(file_path, 'r') as f:
data = json.load(f)

# Randomly select a subset of examples
subset = random.sample(data, min(num_examples, len(data)))

processed_data = []
for example in subset:
question = example['question']
supporting_facts = []
for title, sent_id in example['supporting_facts']:
for context in example['context']:
if context[0] == title:
if sent_id < len(context[1]):
supporting_facts.append(context[1][sent_id])

# Get non-supporting facts as negative examples
non_supporting_facts = []
for context in example['context']:
for sent in context[1]:
if sent not in supporting_facts:
non_supporting_facts.append(sent)

# Limit the number of negative examples to balance the dataset
if len(non_supporting_facts) > len(supporting_facts) * 3:
non_supporting_facts = random.sample(non_supporting_facts, len(supporting_facts) * 3)

processed_data.append({
'question': question,
'supporting_facts': supporting_facts,
'non_supporting_facts': non_supporting_facts
})

return processed_data

# Create dataset class for contrastive learning
class ContrastiveDataset(Dataset):
def __init__(self, data, tokenizer, max_length=512):
self.data = data
self.tokenizer = tokenizer
self.max_length = max_length
self.examples = self._create_examples()

def _create_examples(self):
examples = []
for item in self.data:
question = item['question']
for pos in item['supporting_facts']:
for neg in item['non_supporting_facts']:
examples.append((question, pos, neg))
return examples

def __len__(self):
return len(self.examples)

def __getitem__(self, idx):
question, pos, neg = self.examples[idx]

q_encoding = self.tokenizer(question, max_length=self.max_length, padding='max_length', truncation=True, return_tensors='pt')
pos_encoding = self.tokenizer(pos, max_length=self.max_length, padding='max_length', truncation=True, return_tensors='pt')
neg_encoding = self.tokenizer(neg, max_length=self.max_length, padding='max_length', truncation=True, return_tensors='pt')

return {
'q_input_ids': q_encoding['input_ids'].squeeze(),
'q_attention_mask': q_encoding['attention_mask'].squeeze(),
'pos_input_ids': pos_encoding['input_ids'].squeeze(),
'pos_attention_mask': pos_encoding['attention_mask'].squeeze(),
'neg_input_ids': neg_encoding['input_ids'].squeeze(),
'neg_attention_mask': neg_encoding['attention_mask'].squeeze()
}
```

### BM25 Baseline Implementation
```python
from rank_bm25 import BM25Okapi

def evaluate_bm25(data, top_k=10):
results = []

for example in data:
question = example['question']
supporting_facts = example['supporting_facts']

# Create corpus of all passages
corpus = supporting_facts + example['non_supporting_facts']

# Tokenize corpus
tokenized_corpus = [doc.lower().split() for doc in corpus]

# Create BM25 model
bm25 = BM25Okapi(tokenized_corpus)

# Tokenize query
tokenized_query = question.lower().split()

# Get top-k documents
doc_scores = bm25.get_scores(tokenized_query)
top_indices = np.argsort(doc_scores)[::-1][:top_k]
retrieved_docs = [corpus[i] for i in top_indices]

# Calculate metrics
true_positives = len(set(retrieved_docs) & set(supporting_facts))
precision = true_positives / len(retrieved_docs) if retrieved_docs else 0
recall = true_positives / len(supporting_facts) if supporting_facts else 0
f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0

results.append({
'precision': precision,
'recall': recall,
'f1': f1
})

# Calculate average metrics
avg_precision = sum(r['precision'] for r in results) / len(results)
avg_recall = sum(r['recall'] for r in results) / len(results)
avg_f1 = sum(r['f1'] for r in results) / len(results)

return {
'precision': avg_precision,
'recall': avg_recall,
'f1': avg_f1,
'individual_results': results
}
```

### Contrastive Learning Model Implementation
```python
import torch
import torch.nn as nn
import torch.optim as optim
from transformers import BertModel, BertTokenizer

class ContrastiveModel(nn.Module):
def __init__(self, model_name='bert-base-uncased'):
super(ContrastiveModel, self).__init__()
self.bert = BertModel.from_pretrained(model_name)
self.dropout = nn.Dropout(0.1)
self.projection = nn.Linear(self.bert.config.hidden_size, 768)

def forward(self, input_ids, attention_mask):
outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask)
cls_output = outputs.last_hidden_state[:, 0, :]
cls_output = self.dropout(cls_output)
projection = self.projection(cls_output)
return projection

def train_contrastive_model(train_dataloader, model, device, num_epochs=5, margin=0.5):
optimizer = optim.Adam(model.parameters(), lr=2e-5)
model.train()

for epoch in range(num_epochs):
total_loss = 0
for batch in train_dataloader:
# Move batch to device
q_input_ids = batch['q_input_ids'].to(device)
q_attention_mask = batch['q_attention_mask'].to(device)
pos_input_ids = batch['pos_input_ids'].to(device)
pos_attention_mask = batch['pos_attention_mask'].to(device)
neg_input_ids = batch['neg_input_ids'].to(device)
neg_attention_mask = batch['neg_attention_mask'].to(device)

# Forward pass
q_emb = model(q_input_ids, q_attention_mask)
pos_emb = model(pos_input_ids, pos_attention_mask)
neg_emb = model(neg_input_ids, neg_attention_mask)

# Normalize embeddings
q_emb = nn.functional.normalize(q_emb, p=2, dim=1)
pos_emb = nn.functional.normalize(pos_emb, p=2, dim=1)
neg_emb = nn.functional.normalize(neg_emb, p=2, dim=1)

# Calculate similarities
pos_sim = torch.sum(q_emb * pos_emb, dim=1)
neg_sim = torch.sum(q_emb * neg_emb, dim=1)

# Calculate loss
loss = torch.mean(torch.clamp(margin - pos_sim + neg_sim, min=0))

# Backward pass and optimization
optimizer.zero_grad()
loss.backward()
optimizer.step()

total_loss += loss.item()

print(f'Epoch {epoch+1}/{num_epochs}, Loss: {total_loss/len(train_dataloader)}')

return model

def evaluate_contrastive_model(data, model, tokenizer, device, top_k=10):
model.eval()
results = []

for example in data:
question = example['question']
supporting_facts = example['supporting_facts']

# Create corpus of all passages
corpus = supporting_facts + example['non_supporting_facts']

# Encode question
q_encoding = tokenizer(question, max_length=512, padding='max_length', truncation=True, return_tensors='pt')
q_input_ids = q_encoding['input_ids'].to(device)
q_attention_mask = q_encoding['attention_mask'].to(device)

with torch.no_grad():
q_emb = model(q_input_ids, q_attention_mask)
q_emb = nn.functional.normalize(q_emb, p=2, dim=1)

# Calculate similarity scores for all passages
similarities = []
for passage in corpus:
p_encoding = tokenizer(passage, max_length=512, padding='max_length', truncation=True, return_tensors='pt')
p_input_ids = p_encoding['input_ids'].to(device)
p_attention_mask = p_encoding['attention_mask'].to(device)

with torch.no_grad():
p_emb = model(p_input_ids, p_attention_mask)
p_emb = nn.functional.normalize(p_emb, p=2, dim=1)
sim = torch.sum(q_emb * p_emb, dim=1).item()

similarities.append(sim)

# Get top-k passages
top_indices = np.argsort(similarities)[::-1][:top_k]
retrieved_docs = [corpus[i] for i in top_indices]

# Calculate metrics
true_positives = len(set(retrieved_docs) & set(supporting_facts))
precision = true_positives / len(retrieved_docs) if retrieved_docs else 0
recall = true_positives / len(supporting_facts) if supporting_facts else 0
f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0

results.append({
'precision': precision,
'recall': recall,
'f1': f1
})

# Calculate average metrics
avg_precision = sum(r['precision'] for r in results) / len(results)
avg_recall = sum(r['recall'] for r in results) / len(results)
avg_f1 = sum(r['f1'] for r in results) / len(results)

return {
'precision': avg_precision,
'recall': avg_recall,
'f1': avg_f1,
'individual_results': results
}
```

### Main Experiment Script
```python
import torch
from transformers import BertTokenizer
from torch.utils.data import DataLoader
import matplotlib.pyplot as plt
import numpy as np
from scipy import stats

def main():
# Set random seed for reproducibility
torch.manual_seed(42)
np.random.seed(42)
random.seed(42)

# Set device
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Load data
train_data = load_hotpotqa_subset('hotpot_train_v1.1.json', 1000)
test_data = load_hotpotqa_subset('hotpot_dev_v1.1.json', 200)

print(f'Loaded {len(train_data)} training examples and {len(test_data)} test examples')

# Evaluate BM25 baseline
print('Evaluating BM25 baseline...')
bm25_results = evaluate_bm25(test_data)
print(f'BM25 Results - Precision: {bm25_results["precision"]:.4f}, Recall: {bm25_results["recall"]:.4f}, F1: {bm25_results["f1"]:.4f}')

# Initialize tokenizer and model for contrastive learning
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = ContrastiveModel().to(device)

# Create dataset and dataloader
train_dataset = ContrastiveDataset(train_data, tokenizer)
train_dataloader = DataLoader(train_dataset, batch_size=16, shuffle=True)

# Train contrastive model
print('Training contrastive model...')
model = train_contrastive_model(train_dataloader, model, device)

# Evaluate contrastive model
print('Evaluating contrastive model...')
contrastive_results = evaluate_contrastive_model(test_data, model, tokenizer, device)
print(f'Contrastive Results - Precision: {contrastive_results["precision"]:.4f}, Recall: {contrastive_results["recall"]:.4f}, F1: {contrastive_results["f1"]:.4f}')

# Perform statistical significance testing
bm25_f1_scores = [r['f1'] for r in bm25_results['individual_results']]
contrastive_f1_scores = [r['f1'] for r in contrastive_results['individual_results']]

t_stat, p_value = stats.ttest_rel(contrastive_f1_scores, bm25_f1_scores)
print(f'Paired t-test: t={t_stat:.4f}, p={p_value:.4f}')

# Create visualization
metrics = ['Precision', 'Recall', 'F1']
bm25_values = [bm25_results['precision'], bm25_results['recall'], bm25_results['f1']]
contrastive_values = [contrastive_results['precision'], contrastive_results['recall'], contrastive_results['f1']]

x = np.arange(len(metrics))
width = 0.35

fig, ax = plt.subplots(figsize=(10, 6))
ax.bar(x - width/2, bm25_values, width, label='BM25')
ax.bar(x + width/2, contrastive_values, width, label='Contrastive Learning')

ax.set_ylabel('Score')
ax.set_title('Performance Comparison')
ax.set_xticks(x)
ax.set_xticklabels(metrics)
ax.legend()

plt.tight_layout()
plt.savefig('results_comparison.png')
plt.show()

# Save model
torch.save(model.state_dict(), 'contrastive_model.pt')

if __name__ == '__main__':
main()
```
