ID: idea_72-simplified

prompt-tuning-federated-learning

Hypothesis

Implementing prompt tuning in a simplified federated learning setup will improve model performance (accuracy and F1-score) on multilingual text classification tasks compared to standard fine-tuning, while requiring fewer trainable parameters.

Elements

  • Independent variable: Training approach (prompt tuning vs. standard fine-tuning)
  • Dependent variable: Model performance (accuracy, F1-score) and parameter efficiency (number of trainable parameters)
  • Comparison groups: Prompt tuning vs. standard fine-tuning
  • Baseline/control: Standard fine-tuning in the same federated learning setup
  • Context/setting: Multilingual text classification tasks
  • Assumptions: Pre-trained language models can be effectively adapted for multilingual tasks
  • Relationship type: Causation
  • Population: Multilingual text classification datasets
  • Timeframe: Not specified
  • Measurement method: Accuracy, F1-score, trainable parameter count

Description

This research explores the effectiveness of prompt tuning in a simplified federated learning environment for multilingual text classification tasks. Instead of implementing the full FedPerfix framework, this study focuses on comparing prompt tuning against standard fine-tuning in a basic federated learning setup. Prompt tuning involves adding and optimizing a small set of continuous task-specific vectors (prompts) that are prepended to the input while keeping the pre-trained model frozen. This approach potentially offers parameter efficiency advantages in federated learning scenarios where communication costs and client heterogeneity are concerns. The research will simulate a federated learning environment with clients representing different languages, using publicly available multilingual text classification datasets. The experiment will measure both performance metrics (accuracy and F1-score) and efficiency metrics (number of trainable parameters) to evaluate whether prompt tuning provides advantages over standard fine-tuning in this simplified federated learning context. This research could provide valuable insights into parameter-efficient adaptation methods for multilingual federated learning, which is particularly relevant for resource-constrained environments.

Operationalization

Please implement a pilot experiment to evaluate prompt tuning versus standard fine-tuning in a simplified federated learning setup for multilingual text classification. The experiment should follow these specifications:

1. PILOT MODES
Implement a global variable PILOT_MODE that can be set to one of: ['MINI_PILOT', 'PILOT', 'FULL_EXPERIMENT']

For MINI_PILOT:
- Use 2 languages (English and German)
- 50 examples per language
- 2 federated learning rounds
- 10 prompt tokens
- Maximum 5 training epochs per round

For PILOT:
- Use 3 languages (English, German, French)
- 500 examples per language
- 5 federated learning rounds
- Test prompt token sizes [10, 50]
- Maximum 10 training epochs per round

For FULL_EXPERIMENT (not to be run initially):
- Use 4 languages (English, German, French, Japanese)
- Full dataset
- 20 federated learning rounds
- Test prompt token sizes [10, 20, 50, 100]
- Maximum 20 training epochs per round

2. DATASET
- Use the XNLI dataset from Huggingface
- For each language:
* Split into train (70%), validation (15%), test (15%)
* Ensure balanced class distribution
* Log the exact splits for reproducibility

3. MODEL IMPLEMENTATIONS
Baseline (Standard Fine-tuning):
- Use distilbert-base-multilingual-cased
- Add classification head
- Fine-tune last two layers + classification head

Experimental (Prompt Tuning):
- Same base model, frozen
- Add trainable prompt tokens
- Only tune the prompt tokens

4. FEDERATED LEARNING
- Each language is one client
- In each round:
* Train on local data
* Average parameters (prompt vectors or model weights)
* Evaluate on validation set
- Log parameter counts and communication costs

5. EVALUATION
- For each approach, report:
* Accuracy and F1-score per language
* Number of trainable parameters
* Training time and memory usage
- Create plots comparing:
* Performance across languages
* Learning curves
* Parameter efficiency
- Perform bootstrap resampling to test for significant differences

6. EXECUTION ORDER
1. Run MINI_PILOT first
2. If successful, run PILOT
3. Stop after PILOT (await human verification)

7. LOGGING AND OUTPUT
- Log all hyperparameters
- Save model checkpoints
- Generate plots for:
* Performance by language
* Learning curves
* Parameter counts
- Output a summary JSON with all metrics

Please implement this experiment, focusing on careful evaluation and clear logging of results. The goal is to verify that the implementation works correctly in MINI_PILOT, then gather preliminary results in PILOT to assess whether the approach shows promise before proceeding to the full experiment.
